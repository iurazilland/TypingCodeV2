# TypingCode V2 🚀

> **블록 코딩(Visual Block)과 텍스트 타이핑(Typing Code)을 결합한 차세대 인터랙티브 프로그래밍 학습 플랫폼**

---

## 🌟 주요 특징 (Key Features)

- **🧩 스크래치 스타일 블록 코딩 시스템**:
  - 퍼즐 요철(Tab/Notch) 기반의 직관적인 상하 결합
  - C-자형 루프(`for`, `while`) 및 다단 조건문(`if`-`elif`-`else`) 블록
  - 실시간 자석 스냅(Magnetic Snap) 및 드래그 앤 드롭 결합
- **⚡ 타이핑 코드 학습**:
  - 블록과 1:1로 대응되는 실제 소스코드 타이핑 및 실시간 검증
- **🎨 모던 UI / 인터랙티브 시각화**:
  - 블록 실행 흐름 시각화 및 직관적인 캔버스 환경
  - 언어별(Python 등) 커스텀 테마 및 반응형 레이아웃

---

## 🛠️ 기술 스택 (Tech Stack)

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: Vanilla CSS (CSS Modules & Inline Tokens)
- **Runtime**: Node.js

---

## 🚀 시작하기 (Getting Started)

### 설치 (Installation)

```bash
npm install
```

### 개발 서버 실행 (Development Server)

```bash
npm run dev
```

브라우저에서 `http://localhost:3000`으로 접속하여 학습 환경을 확인할 수 있습니다.
