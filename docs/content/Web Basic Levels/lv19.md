Lv19.
Title_EN: Advanced Box Styling
Title_KO: 박스 배경색과 그림자 효과
Description_EN: Learn background-color, border-radius, and box-shadow.
Description_KO: 배경색(background-color)과 모서리 둥글기(border-radius), 그리고 그림자(box-shadow) 입체를 배웁니다.

1.
Guide_EN: Assign red background color styling rule.
Guide_KO: 상자 구역의 내부 배경색을 빨간색 스타일 규칙으로 적용합니다.
Template_HTML:
<div class="box">Red Box</div>
Template_CSS:
.box {
  background-color: red;
}

2.
Guide_EN: Assign blue background color rule.
Guide_KO: 상자 영역 배경색을 파란색 속성으로 적용해 봅니다.
Template_HTML:
<div class="box">Blue Box</div>
Template_CSS:
.box {
  background-color: blue;
}

3.
Guide_EN: Set border radius for rounding corners.
Guide_KO: 가장자리 모서리 직각부를 부드럽게 둥글리는 반경을 넣습니다.
Template_HTML:
<div class="box">Round</div>
Template_CSS:
.box {
  border-radius: 8px;
}

4.
Guide_EN: Set full circle border radius styling.
Guide_KO: 둥글기 값을 절반 비율로 주어 타원이나 정원 형태를 만듭니다.
Template_HTML:
<div class="badge">Circle</div>
Template_CSS:
.badge {
  border-radius: 50%;
}

5.
Guide_EN: Apply soft box shadow overlay designs.
Guide_KO: 상자 하단에 부드럽게 흩뿌려지는 그림자(box-shadow)를 넣습니다.
Template_HTML:
<div class="card">Shadow</div>
Template_CSS:
.card {
  box-shadow: 2px 2px 5px gray;
}

6.
Guide_EN: Combine background color and rounded corners.
Guide_KO: 밝은 파란색 배경 지정과 모서리 둥글기 6픽셀을 병합합니다.
Template_HTML:
<div class="card">Card</div>
Template_CSS:
.card {
  background-color: lightblue;
  border-radius: 6px;
}

7.
Guide_EN: Combine backgrounds, borders, and radius resets.
Guide_KO: 회색 배경에 모서리를 둥글리고 1픽셀 실선을 긋습니다.
Template_HTML:
<div class="badge">Tag</div>
Template_CSS:
.badge {
  background: #eee;
  border: 1px solid gray;
  border-radius: 4px;
}

8.
Guide_EN: Set box styles for custom actions buttons.
Guide_KO: 단추 단락의 배경을 검정으로 바꾸고 글자를 하얗게 땁니다.
Template_HTML:
<button class="btn">Click</button>
Template_CSS:
.btn {
  background-color: black;
  color: white;
}

9.
Guide_EN: Combine background and rounded buttons formatting.
Guide_KO: 녹색 배경을 가진 모서리가 둥근 입력 단추를 디자인합니다.
Template_HTML:
<button class="btn">Submit</button>
Template_CSS:
.btn {
  background: green;
  border-radius: 12px;
}

10.
Guide_EN: Include box shadow on action buttons.
Guide_KO: 동작 단추 밑에 작게 퍼지는 입체감 그림자를 덧붙여 봅니다.
Template_HTML:
<button class="btn">Push</button>
Template_CSS:
.btn {
  box-shadow: 1px 1px 3px black;
}

11.
Guide_EN: Add custom theme header styling configurations (cumulative review).
Guide_KO: 상단 헤더 영역 배경을 깔끔한 어두운 회색으로 칠해 줍니다.
Template_HTML:
<header id="nav-head">Header</header>
Template_CSS:

  background-color: #333;
  color: white;
}

12.
Guide_EN: Apply card layouts incorporating shadows and borders.
Guide_KO: 카드에 그림자를 주고 가로폭 200픽셀 수치를 적용합니다.
Template_HTML:
<div class="card">Card info</div>
Template_CSS:

  width: 200px;
  box-shadow: 0 4px 8px gray;
}

13.
Guide_EN: Combine card padding and advanced backgrounds.
Guide_KO: 카드 내부 패딩을 15픽셀 넣고 둥글기 반경을 8픽셀 줍니다.

14.

15.

Guide_KO: 단추 위에 마우스를 올렸을 때 손가락 포인터로 변환합니다.
