Lv22.
Title_EN: Flexbox Basics
Title_KO: 플렉스 레이아웃 기초
Description_EN: Learn display flex, direction, and gap.
Description_KO: 1차원 정렬 상자 flex를 만들어 가로/세로 방향을 정하고 요소 간 간격(gap)을 벌리는 법을 배웁니다.

1.
Guide_EN: Assign display flex container rule.
Guide_KO: 부모 상자에 display: flex 속성을 주어 자식들을 1차원 자동 배치합니다.
Template_HTML:
<div class="container">
  <div>A</div>
</div>
Template_CSS:
.container {
  display: flex;
}

2.
Guide_EN: Set spacing gap between flex items.
Guide_KO: 배치된 자식 상자 요인들의 사잇대 간격 10픽셀을 일괄 설정합니다.
Template_HTML:
<div class="container">
  <div>A</div>
  <div>B</div>
</div>
Template_CSS:
.container {
  display: flex;
  gap: 10px;
}

3.
Guide_EN: Apply wide gap styling to flex container.
Guide_KO: 부모 플렉스 정렬 상자의 사잇대 간격 규격을 20픽셀로 널찍이 줍니다.
Template_HTML:
<div class="container"><div>A</div><div>B</div></div>
Template_CSS:
.container {
  display: flex;
  gap: 20px;
}

4.
Guide_EN: Define flex direction vertical column axis.
Guide_KO: 가로 나열이 기본인 방향을 세로 열(column) 정렬 방향으로 전환시킵니다.
Template_HTML:
<div class="container"><div>A</div><div>B</div></div>
Template_CSS:
.container {
  display: flex;
  flex-direction: column;
}

5.
Guide_EN: Combine column axis direction and custom gaps.
Guide_KO: 세로 나열 방향 하에 15픽셀 수치의 상하 간격들을 벌려 배치합니다.
Template_HTML:
<div class="container"><div>A</div><div>B</div></div>
Template_CSS:
.container {
  display: flex;
  flex-direction: column;
  gap: 15px;
}

6.
Guide_EN: Set flex wrap parameter to wrap lines.
Guide_KO: 자식들이 부모 가로폭 한계를 초과하면 아래 줄로 자동 개행(wrap)시킵니다.
Template_HTML:
<div class="container"><div>A</div></div>
Template_CSS:
.container {
  display: flex;
  flex-wrap: wrap;
}

7.
Guide_EN: Combine flex wrap and gap rules.
Guide_KO: 아래 줄 자동 개행 기능에 사잇대 간격 12픽셀을 균등 설정합니다.
Template_HTML:
<div class="container"><div>A</div></div>
Template_CSS:
.container {
  display: flex;
  flex-wrap: wrap;
  gap: 12px;
}

8.
Guide_EN: Apply column row layouts inside page headers (cumulative review).
Guide_KO: 헤더 내부 메뉴와 제목을 가로 정렬하고 20픽셀 간격을 줍니다.
Template_HTML:
<header><h1>Site</h1><nav>Menu</nav></header>
Template_CSS:
header {
  display: flex;
  gap: 20px;
}

9.
Guide_EN: Set flex wrap properties inside card listings.
Guide_KO: 목록 카드 전체를 부모 상자 아래 자동 줄개행 배치로 엮어 봅니다.
Template_HTML:
<div class="list"><div>Card</div></div>
Template_CSS:
.list {
  display: flex;
  flex-wrap: wrap;
}

10.
Guide_EN: Combine card lists and custom layout gaps.
Guide_KO: 개행 카드 목록들 사이 공간을 사방 16픽셀 사잇값으로 벌려 줍니다.
Template_HTML:
<div class="list"><div>Card</div></div>
Template_CSS:
.list {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}

11.
Guide_EN: Set flex directions inside article layouts.
Guide_KO: 기사 상자 안의 제목과 글내용이 항상 세로로 정렬되게 묶어 줍니다.
Template_HTML:
<article><h2>Title</h2><p>Text</p></article>
Template_CSS:
article {
  display: flex;
  flex-direction: column;
}

12.
Guide_EN: Set flex items spacing inside aside columns.
Guide_KO: 사이드바 세로 상자 안 요소들 간격(gap)을 8픽셀 벌려 줍니다.
Template_HTML:
<aside><h3>Menu</h3><p>Item</p></aside>
Template_CSS:
aside {
  display: flex;
  flex-direction: column;
  gap: 8px;
}

13.
Guide_EN: Apply flex styling on navigation bars.
Guide_KO: 상단 내비게이션 바 링크들이 가로로 정렬되게 플렉스화합니다.
Template_HTML:
<nav><a href="#">Home</a><a href="#">Blog</a></nav>
Template_CSS:
nav {
  display: flex;
  gap: 15px;
}

14.
Guide_EN: Set row flex properties on lists.
Guide_KO: 세로 목록 리스트의 불릿을 없애고 자식들을 가로로 연동 배열합니다.
Template_HTML:
<ul><li>Menu 1</li><li>Menu 2</li></ul>
Template_CSS:
ul {
  display: flex;
  gap: 10px;
  list-style: none;
}

15.
Guide_EN: Combine list style resets and column configurations.
Guide_KO: 불릿 제거 목록을 세로로 누적 쌓으며 5픽셀 정렬 간격을 줍니다.
Template_HTML:
<ul><li>Menu 1</li></ul>
Template_CSS:
ul {
  display: flex;
  flex-direction: column;
  gap: 5px;
  list-style: none;
}

16.
Guide_EN: Control layout buttons group displaying flex.
Guide_KO: 행동 단추들을 묶은 상자를 플렉스화하여 나란히 정렬 엮어 봅니다.
Template_HTML:
<div class="btns"><button>A</button><button>B</button></div>
Template_CSS:
.btns {
  display: flex;
  gap: 10px;
}

17.
Guide_EN: Combine direction row reverse layouts.
Guide_KO: 가로 순서를 완전히 정반대 거꾸로(row-reverse) 뒤바꿔 정렬합니다.
Template_HTML:
<div class="btns"><span>A</span><span>B</span></div>
Template_CSS:
.btns {
  display: flex;
  flex-direction: row-reverse;
}

18.
Guide_EN: Combine direction column reverse layouts.
Guide_KO: 세로 정렬 순서를 맨 밑바닥부터 위로 거꾸로 쌓아 올립니다.
Template_HTML:
<div class="btns"><span>A</span><span>B</span></div>
Template_CSS:
.btns {
  display: flex;
  flex-direction: column-reverse;
}

19.
Guide_EN: Set display flex on form panels.
Guide_KO: 사용자 정보 전송용 폼 구역을 세로 줄맞춤 정렬로 엮어 설계합니다.
Template_HTML:
<form><input><button>Send</button></form>
Template_CSS:
form {
  display: flex;
  flex-direction: column;
  gap: 12px;
}

20.
Guide_EN: Assemble complete flex direction structures.
Guide_KO: 바디 하위에 헤더와 세로 본문들을 플렉스로 정렬 조립 완성합니다.
Template_HTML:
<body>
  <header><h1>App</h1></header>
  <main>
    <div class="box">Content</div>
  </main>
</body>
Template_CSS:
body {
  display: flex;
  flex-direction: column;
  gap: 20px;
}
main {
  display: flex;
  gap: 10px;
}
