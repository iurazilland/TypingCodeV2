Lv43.
Title_EN: DOM Style & classList
Title_KO: 인라인 스타일과 스타일 클래스
Description_EN: Learn style and classList add/remove/toggle.
Description_KO: 요소의 인라인 CSS 속성 제어(style)와 스타일 클래스를 동적 토글(classList)하는 법을 배웁니다.

1.
Guide_EN: Change inline background styling rule.
Guide_KO: 자바스크립트로 대상 요인의 인라인 배경색을 노란색으로 바꿉니다.
Template_HTML:
<div class="box">Color</div>
Template_JS:
const div = document.querySelector(".box");
div.style.backgroundColor = "yellow";

2.
Guide_EN: Change inline text color styling rule.
Guide_KO: 단락 글꼴의 인라인 글자 색상을 빨간색으로 변경시킵니다.
Template_HTML:
<p>Text</p>
Template_JS:
const p = document.querySelector("p");
p.style.color = "red";

3.
Guide_EN: Add design class utilizing classList add.
Guide_KO: 클래스 목록 제어기(classList)를 이용해 'active' 클래스를 붙입니다.
Template_HTML:
<div class="box">Box</div>
Template_JS:
const div = document.querySelector(".box");
div.classList.add("active");

4.
Guide_EN: Remove design class utilizing classList remove.
Guide_KO: 클래스 제어기로 기존에 붙어있던 'hidden' 클래스를 떼 봅니다.
Template_HTML:
<div class="box hidden">Box</div>
Template_JS:
const div = document.querySelector(".box");
div.classList.remove("hidden");

5.
Guide_EN: Toggle design class utilizing classList toggle.
Guide_KO: 클래스가 없으면 붙이고, 있으면 떼 내는 토글 동작을 지시합니다.
Template_HTML:
<div class="box">Box</div>
Template_JS:
const div = document.querySelector(".box");
div.classList.toggle("active");

6.
Guide_EN: Check class presence utilizing classList contains.
Guide_KO: 해당 클래스가 노드에 소속되어 있는지 참/거짓 판단해 봅니다.
Template_HTML:
<div class="box active">Box</div>
Template_JS:
const div = document.querySelector(".box");
console.log(div.classList.contains("active"));

7.
Guide_EN: Change multiple inline CSS styles.
Guide_KO: 요소 가로 너비 200픽셀과 세로 높이 100픽셀을 동시에 코드로 줍니다.
Template_HTML:
<div>Size</div>
Template_JS:
const div = document.querySelector("div");
div.style.width = "200px";
div.style.height = "100px";

8.
Guide_EN: Change border styling parameters inline.
Guide_KO: 인라인 테두리를 2픽셀 두께의 빨간 점선 스타일로 도포 변경합니다.
Template_HTML:
<div>Border</div>
Template_JS:
const div = document.querySelector("div");
div.style.border = "2px dashed red";

9.
Guide_EN: Change inline display property values.
Guide_KO: 숨어있던 요소를 블록화하여 화면 상에 다시 노출(block)시킵니다.
Template_HTML:
<div class="box">Show</div>
Template_JS:
const div = document.querySelector(".box");
div.style.display = "block";

10.
Guide_EN: Change display block to none inline.
Guide_KO: 보고 있던 요소를 인라인 차단 처리를 통해 화면에서 은폐합니다.
Template_HTML:
<div>Hide</div>
Template_JS:
const div = document.querySelector("div");
div.style.display = "none";

11.
Guide_EN: Apply class updates on selected headers (cumulative review).
Guide_KO: 상단 헤더에 어두운 디자인 클래스인 'dark'를 가산합니다.
Template_HTML:
<header>Header</header>
Template_JS:
const header = document.querySelector("header");
header.classList.add("dark");

12.
Guide_EN: Check class presence in conditional branch.
Guide_KO: 클래스 소속 여부를 조건 판단하여 다르게 동작을 조율합니다.
Template_JS:
const div = document.querySelector("div");
if (div.classList.contains("active")) {
  console.log("On");
}

13.
Guide_EN: Combine text modifications and class updates.
Guide_KO: 글자를 'Error'로 고치고 테두리용 에러 클래스를 씌워 줍니다.
Template_HTML:
<div>Status</div>
Template_JS:
const div = document.querySelector("div");
div.innerText = "Error";
div.classList.add("error-box");

14.
Guide_EN: Change font weight styles inline.
Guide_KO: 제목 글자 굵기를 두껍게(bold) 인라인 상에 강제 지정합니다.
Template_HTML:
<h1>Title</h1>
Template_JS:
const h1 = document.querySelector("h1");
h1.style.fontWeight = "bold";

15.
Guide_EN: Change border radius properties inline.
Guide_KO: 모서리 둥글기 둥근 값을 인라인 style 반경 8픽셀 부여합니다.
Template_HTML:
<div>Round</div>
Template_JS:
const div = document.querySelector("div");
div.style.borderRadius = "8px";

16.
Guide_EN: Toggle active classes across lists items.
Guide_KO: 목록 노드들의 활성화 클래스를 차례로 토글 전환시킵니다.
Template_HTML:
<ul><li>A</li></ul>
Template_JS:
const items = document.querySelectorAll("li");
items.forEach(li => li.classList.toggle("active"));

17.
Guide_EN: Apply pointer hover cursor changes inline.
Guide_KO: 동작 영역 위에 손가락 포인터 마우스 커서가 뜨도록 지시합니다.
Template_HTML:
<div>Btn</div>
Template_JS:
const div = document.querySelector("div");
div.style.cursor = "pointer";

18.
Guide_EN: Combine display none and class removes.
Guide_KO: 숨김 클래스를 탈거함과 동시에 인라인 display를 none 처리합니다.
Template_HTML:
<div>Hide</div>
Template_JS:
const div = document.querySelector("div");
div.classList.remove("show");
div.style.display = "none";

19.
Guide_EN: Override background colors using inputs value.
Guide_KO: 입력 필드에 사용자가 써둔 색상명을 글씨 배경색으로 반영합니다.
Template_HTML:
<div>Box</div>
<input type="text" value="pink">
Template_JS:
const input = document.querySelector("input");
const div = document.querySelector("div");
div.style.backgroundColor = input.value;

20.
Guide_EN: Assemble inline styling and classList togglers.
Guide_KO: 스타일 복합 지정, 클래스 가산, 해제 과정을 종합 마감 완성합니다.
Template_HTML:
<div class="panel">Panel</div>
<button>Toggle</button>
Template_JS:
const panel = document.querySelector(".panel");
panel.style.color = "white";
panel.classList.toggle("open");
console.log(panel.classList.contains("open"));
