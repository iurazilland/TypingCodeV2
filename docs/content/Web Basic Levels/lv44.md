Title_EN: DOM Event Listeners
Title_KO: 이벤트 리스너와 클릭 처리
Description_EN: Learn addEventListener and mouse clicks.
Description_KO: 사용자의 마우스 클릭 등의 동작을 감지하여 실행하는 addEventListener 이벤트를 배웁니다.

1.
Guide_EN: Assign click event listener with simple callback.
Guide_KO: 버튼을 클릭했을 때 특정 함수가 작동하는 수신기를 탑재합니다.
Template_HTML:
<button>Click</button>
Template_JS:
const btn = document.querySelector("button");
btn.addEventListener("click", () => {
  console.log("Clicked");
});

2.
Guide_EN: Update paragraph text inside click event handler.
Guide_KO: 단락 클릭 시 내부의 글자가 'Updated'로 변하도록 핸들러를 짭니다.
Template_HTML:

Template_JS:

20.
Guide_EN: Assemble interactive application controllers.
Guide_KO: 입력값 검출, 태그 조립 꼽기, 입력창 비우기를 최종 조립 완성합니다.
Template_HTML:
<ul></ul>
<input type="text" value="A">
<button>Add</button>
Template_JS:
const btn = document.querySelector("button");
const input = document.querySelector("input");
const ul = document.querySelector("ul");
btn.addEventListener("click", () => {
  if (input.value) {
    ul.innerHTML += "<li>" + input.value + "</li>";
    input.value = "";
  }
});
