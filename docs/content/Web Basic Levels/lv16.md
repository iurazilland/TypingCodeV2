Lv16.
Title_EN: CSS Fonts
Title_KO: 글꼴 색상과 크기 지정
Description_EN: Learn how to use CSS color, font-size, and font-family.
Description_KO: CSS를 이용해 글자의 색상(color), 크기(font-size), 서체(font-family)를 스타일링합니다.

1.
Guide_EN: Assign orange text color styling rule.
Guide_KO: 글자의 색상을 주황색(orange)으로 변경하는 CSS 규칙을 적용합니다.
Template_HTML:
<p>Orange Text</p>
Template_CSS:
p {
  color: orange;
}

2.
Guide_EN: Assign skyblue text color to headings.
Guide_KO: 제목 글자 색상을 하늘색(skyblue)으로 바꾸는 속성을 적용합니다.
Template_HTML:
<h1>Skyblue Title</h1>
Template_CSS:
h1 {
  color: skyblue;
}

3.
Guide_EN: Assign custom font size size constraint.
Guide_KO: 단락 글자 텍스트 크기를 20픽셀로 크기 키워 설정합니다.
Template_HTML:
<p>Text size</p>
Template_CSS:
p {
  font-size: 20px;
}

4.
Guide_EN: Assign font weight to bold state.
Guide_KO: 특정 글자를 굵게 표현하도록 글꼴 두께를 지정합니다.
Template_HTML:
<span>Bold text</span>
Template_CSS:
span {
  font-weight: bold;
}

5.
Guide_EN: Set sans-serif font family type.
Guide_KO: 서체가 깔끔한 돋움 계열로 바뀌도록 폰트 종류를 선언합니다.
Template_HTML:
<p>Font Family</p>
Template_CSS:
p {
  font-family: sans-serif;
}

6.
Guide_EN: Combine text color and sizing rules.
Guide_KO: 글꼴의 크기를 16픽셀로 정하고 색상을 밝은 회색으로 바꿉니다.
Template_HTML:
<p>Combined</p>
Template_CSS:
p {
  font-size: 16px;
  color: lightgray;
}

7.
Guide_EN: Combine color and font weight changes.
Guide_KO: 주황색 색상과 동시에 글씨를 두껍게 채워 봅니다.
Template_HTML:
<span>Combined</span>
Template_CSS:
span {
  color: orange;
  font-weight: bold;
}

8.
Guide_EN: Define header custom layout fonts.
Guide_KO: 헤더 대제목 크기를 32픽셀로 대폭 키워 지정해 봅니다.
Template_HTML:
<h1>Site</h1>
Template_CSS:
h1 {
  font-size: 32px;
}

9.
Guide_EN: Combine font sizes and family styles.
Guide_KO: 돋움 폰트 지정과 동시에 텍스트 크기를 14픽셀로 씁니다.
Template_HTML:
<p>Text style</p>
Template_CSS:
p {
  font-family: sans-serif;
  font-size: 14px;
}

10.
Guide_EN: Set light font weight parameter.
Guide_KO: 일반 두께보다 훨씬 가볍고 슬림한 가중치를 부여합니다.
Template_HTML:
<h2>Light Title</h2>
Template_CSS:
h2 {
  font-weight: 300;
}

11.
Guide_EN: Add custom link colors inside layouts (cumulative review).
Guide_KO: 내비게이션 링크 글자색을 밝은 회색으로 바꿉니다.
Template_HTML:
<nav><a href="#">Home</a></nav>
Template_CSS:
a {
  color: #ccc;
}

12.
Guide_EN: Combine heading colors and center alignments.
Guide_KO: 제목 색상을 연한 녹색(lightgreen)으로 정하고 중앙 정렬(text-align)합니다.
Template_HTML:
<h1>Center</h1>
Template_CSS:
h1 {
  color: lightgreen;
  text-align: center;
}

13.
Guide_EN: Apply font overrides inside paragraph details.
Guide_KO: 단락 글자 간격이나 줄 높이(line-height)를 봅니다.
Template_HTML:
<p>Spacing</p>
Template_CSS:
p {
  line-height: 1.5;
}

14.
Guide_EN: Set line heights and text decoration removals.
Guide_KO: 링크 태그 아래에 그어지는 밑줄(text-decoration)을 뺍니다.
Template_HTML:
<a href="#">Clean Link</a>
Template_CSS:
a {
  text-decoration: none;
}

15.
Guide_EN: Combine link colors and decoration resets.
Guide_KO: 밑줄을 없앤 후 링크 글자 색상을 흰색으로 지시합니다.
Template_HTML:
<a href="#">Link</a>
Template_CSS:
a {
  text-decoration: none;
  color: white;
}

16.
Guide_EN: Add italic font styles inside headers.
Guide_KO: 글꼴 스타일을 비스듬히 눕는 이탤릭체로 구성해 봅니다.
Template_HTML:
<h2>Italic</h2>
Template_CSS:
h2 {
  font-style: italic;
}

17.
Guide_EN: Combine multiple font rules in page headers.
Guide_KO: 대제목의 색상(orchid), 굵기, 정렬을 모두 한 곳에 조립해 봅니다.
Template_HTML:
<h1>Hero Title</h1>
Template_CSS:
h1 {
  color: orchid;
  font-weight: bold;
  text-align: center;
}

18.
Guide_EN: Set text properties inside semantic sections.
Guide_KO: 메인 본문의 단락 글꼴을 지정하고 크기를 변경합니다.
Template_HTML:
<main><p>Text</p></main>
Template_CSS:
main p {
  font-family: sans-serif;
  font-size: 18px;
}

19.
Guide_EN: Set text color for footer text blocks.
Guide_KO: 푸터 안의 자잘한 안내글의 글꼴 색상을 연한 회색(#aaa)으로 합니다.
Template_HTML:
<footer><p>© 2026</p></footer>
Template_CSS:
footer p {
  color: #aaa;
}

20.
Guide_EN: Assemble combined font rules across elements.
Guide_KO: 대제목(밝은 회색), 본문 글꼴, 링크 밑줄 제거(하늘색) 규칙을 최종 완성합니다.
Template_HTML:
<h1>Site</h1>
<p>Main page text</p>
<a href="#">Link</a>
Template_CSS:
h1 {
  color: #ddd;
}
p {
  font-size: 15px;
  line-height: 1.6;
}
a {
  text-decoration: none;
  color: skyblue;
}
