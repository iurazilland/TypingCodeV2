Lv31.
Title_EN: JS Variables & Console
Title_KO: 콘솔 출력과 변수 선언
Description_EN: Learn console.log, let, and const.
Description_KO: 콘솔창 출력 명령어(console.log)와 변수 let, 재할당 불가 상수 const의 사용법을 배웁니다.

1.
Guide_EN: Print a string to the console.
Guide_KO: 콘솔창에 텍스트 문장을 출력하는 출력 명령어를 실행합니다.
Template_JS:
console.log("Hello JS");

2.
Guide_EN: Print a number value to the console.
Guide_KO: 콘솔창에 문자열이 아닌 숫자 100을 출력하도록 실행해 봅니다.
Template_JS:
console.log(100);

3.
Guide_EN: Declare a reassignable variable using let.
Guide_KO: 재할당이 가능한 변수 선언 키워드 let을 사용하여 변수를 선언합니다.
Template_JS:
let score = 90;

4.
Guide_EN: Reassign new value to let variable.
Guide_KO: 선언해 둔 let 변수에 새로운 숫자 데이터 값을 대입하여 변경합니다.
Template_JS:
let score = 90;
score = 95;

5.
Guide_EN: Declare a constant variable using const.
Guide_KO: 재할당이 불가하고 값이 유지되는 상수 선언 키워드 const를 씁니다.
Template_JS:
const max = 100;

6.
Guide_EN: Verify printing variables to the console.
Guide_KO: 변수에 보관한 정보를 가져와서 콘솔창에 찍어 확인합니다.
Template_JS:
let age = 20;
console.log(age);

7.
Guide_EN: Print variables reassignment changes.
Guide_KO: let 변수를 선언하고 값을 바꾼 직후 바뀐 상태를 출력합니다.
Template_JS:
let name = "Kim";
name = "Lee";
console.log(name);

8.
Guide_EN: Combine constant definitions and prints.
Guide_KO: 상수에 텍스트를 담아 콘솔창에 출력해 봄으로써 흐름을 다집니다.
Template_JS:
const app = "App";
console.log(app);

9.
Guide_EN: Define variables with initial math variables (cumulative review).
Guide_KO: 변수를 선언하며 다른 변수의 값에 10을 더해 초기 대입합니다.
Template_JS:
let base = 50;
let total = base + 10;
console.log(total);

10.
Guide_EN: Declare empty let variable allocation.
Guide_KO: 아무런 값도 할당하지 않고 변수 껍데기만 먼저 정의해 봅니다.
Template_JS:
let data;
console.log(data);

11.
Guide_EN: Use type check typeof operator.
Guide_KO: 데이터의 속성 형식을 검사하여 알려주는 typeof 명령을 실행합니다.
Template_JS:
let str = "Hi";
console.log(typeof str);

12.
Guide_EN: Check typeof numeric values.
Guide_KO: 숫자 데이터의 형식 코드를 typeof 연산자로 확인해 봅니다.
Template_JS:
let num = 5;
console.log(typeof num);

13.
Guide_EN: Check typeof boolean states values.
Guide_KO: 참/거짓(true/false) 데이터를 선언하고 그 데이터 형식을 확인합니다.
Template_JS:
let ok = true;
console.log(typeof ok);

14.
Guide_EN: Define variables combined with strings templates.
Guide_KO: 변수를 더해서 하나의 연결 문장 문자열을 조합합니다.
Template_JS:
let user = "User";
console.log("Hello " + user);

15.
Guide_EN: Use multiple console print commands.
Guide_KO: 콘솔 출력을 연달아 두 번 지시해 순차 처리를 체감합니다.
Template_JS:
console.log("One");
console.log("Two");

16.
Guide_EN: Add custom layout configurations (cumulative review).
Guide_KO: HTML 요소를 모사한 텍스트 변수와 클래스명을 조합해 봅니다.
Template_JS:
let element = "div";
let cName = "card";
console.log(element + "." + cName);

17.
Guide_EN: Override initial numbers inside variables.
Guide_KO: 변수 덧셈 누적의 개념을 훈련하기 위해 자기 자신에 더해 봅니다.
Template_JS:
let score = 10;
score = score + 5;
console.log(score);

18.
Guide_EN: Override initial numbers using shorthand additions.
Guide_KO: 자기 자신에 5를 더하는 복합 대입 연산자(+=)를 사용해 봅니다.
Template_JS:
let count = 10;
count += 5;
console.log(count);

19.
Guide_EN: Print compound templates literal patterns.
Guide_KO: 변수를 여러 개 덧붙여 완전한 문장 텍스트로 조립 출력합니다.
Template_JS:
let h = 80;
let w = 80;
console.log("Size: " + h + "x" + w);

20.
Guide_EN: Assemble variable declarations and print outputs.
Guide_KO: 상수 식별자, 재할당 변수, 연산, 콘솔 인쇄를 종합 조립합니다.
Template_JS:
const price = 500;
let count = 2;
let total = price * count;
console.log(total);
