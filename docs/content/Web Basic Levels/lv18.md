Title_EN: Box Model Basics
Title_KO: 박스 모델과 여백 지정
Description_EN: Learn width, height, padding, margin, and border.
Description_KO: 요소의 크기(width/height)와 안쪽 여백(padding), 바깥 여백(margin), 테두리(border)의 관계를 배웁니다.

1.
Guide_EN: Define explicit width sizing for containers.
Guide_KO: 상자 요소의 가로 크기 폭을 200픽셀 수치로 제한합니다.
Template_HTML:
<div class="box">Width</div>
Template_CSS:
.box {
  width: 200px;
}

2.
Guide_EN: Define explicit height sizing for containers.
Guide_KO: 상자 요소의 세로 높이를 100픽셀 수치로 제한합니다.
Template_HTML:
<div class="box">Height</div>
Template_CSS:
.box {
  height: 100px;
}

3.
Guide_EN: Set inner spacing padding inside box borders.
Guide_KO: 상자 테두리 안쪽 여백 공간인 padding을 사방 10픽셀 줍니다.
Template_HTML:
<div class="box">Padding</div>
Template_CSS:
.box {
  padding: 10px;
}

4.
Guide_EN: Set outer spacing margin around containers.
Guide_KO: 상자 테두리 바깥쪽 마진 공간을 15픽셀 확보하여 밀어냅니다.
Template_HTML:
<div class="box">Margin</div>
Template_CSS:
.box {
  margin: 15px;
}

5.
Guide_EN: Set solid border thickness rule.
Guide_KO: 상자의 가장자리 윤곽 테두리를 2픽셀 두께의 회색 실선으로 합니다.
Template_HTML:
<div class="box">Border</div>
Template_CSS:
.box {
  border: 2px solid gray;
}

6.
Guide_EN: Combine width and height parameters.
Guide_KO: 상자의 가로 폭을 150픽셀, 세로를 80픽셀로 함께 지정합니다.
Template_HTML:
<div class="box">Box</div>
Template_CSS:
.box {
  width: 150px;
  height: 80px;
}

7.
Guide_EN: Combine borders and padding formatting.
Guide_KO: 1픽셀 실선을 둘러주고 안쪽으로 15픽셀의 패딩을 확보합니다.
Template_HTML:
<div class="box">Card</div>
Template_CSS:
.box {
  border: 1px solid gray;
  padding: 15px;
}

8.
Guide_EN: Set padding top parameter specifically.
Guide_KO: 위쪽 안쪽 여백(padding-top)만 단독으로 20픽셀 부여합니다.
Template_HTML:
<div class="box">Top Pad</div>
Template_CSS:
.box {
  padding-top: 20px;
}

9.
Guide_EN: Set margin bottom spacing specifically.
Guide_KO: 상자들의 세로 간격 확보를 위해 아래 바깥 여백을 줍니다.
Template_HTML:
<div class="box">Bottom Mar</div>
Template_CSS:
.box {
  margin-bottom: 25px;
}

10.
Guide_EN: Set compact box sizing rules.
Guide_KO: 안쪽 여백을 5픽셀, 테두리를 1픽셀 실선으로 콤팩트하게 짭니다.
Template_HTML:
<div class="box">Mini</div>
Template_CSS:
.box {
  padding: 5px;
  border: 1px solid;
}

11.
Guide_EN: Control layout buttons sizing properties (cumulative review).
Guide_KO: 행동 단추 클래스의 좌우 패딩을 상하보다 길게 넓혀 줍니다.
Template_HTML:
<button class="btn">Ok</button>
Template_CSS:
.btn {
  padding: 8px 16px;
}

12.
Guide_EN: Add outer margin around layout sections.
Guide_KO: 전체 메인 콘텐츠 영역 바깥 사방에 20픽셀 마진을 넣습니다.
Template_HTML:
<main class="content">Main</main>
Template_CSS:
.content {
  margin: 20px;
}

13.
Guide_EN: Define thick solid outline designs.
Guide_KO: 상자의 왼쪽 테두리 선(border-left)만 굵은 하늘색으로 땁니다.
Template_HTML:
<div class="alert">Warning</div>
Template_CSS:
.alert {
  border-left: 5px solid skyblue;
}

14.
Guide_EN: Set width constraints on inline block spans.
Guide_KO: 글 상자 span을 블록화하고 가로 크기를 부여합니다.
Template_HTML:
<span class="block-span">Span</span>
Template_CSS:
.block-span {
  width: 100px;
}

15.
Guide_EN: Combine border width layouts on headings.
Guide_KO: 소제목 글자 아래에만 장식 테두리 선(border-bottom)을 긋습니다.
Template_HTML:
<h2>Subject</h2>
Template_CSS:
h2 {
  border-bottom: 2px solid gray;
}

16.
Guide_EN: Set specific spacing margins left sides.
Guide_KO: 들여쓰기 연출을 위해 왼쪽 마진(margin-left)을 줍니다.
Template_HTML:
<p class="indent">Nested</p>
Template_CSS:
.indent {
  margin-left: 30px;
}

17.
Guide_EN: Adjust card heights and border constraints.
Guide_KO: 카드 상자의 가로를 250픽셀로 하고 테두리를 둘러 줍니다.
Template_HTML:
<div class="card">Info</div>
Template_CSS:
.card {
  width: 250px;
  border: 1px solid gray;
}

18.
Guide_EN: Set text properties and padding in cards.
Guide_KO: 카드 상자 글씨를 굵게 바꾸고 10픽셀 안쪽 여백을 줍니다.
Template_HTML:
<div class="card">Text</div>
Template_CSS:

  font-weight: bold;
  padding: 10px;
}

19.
Guide_EN: Define spacing between navigation elements.
Guide_KO: 내비게이션 링크들 우측에 간격 마진(margin-right)을 배치합니다.
Template_HTML:

Template_CSS:

  margin-right: 15px;

Guide_EN: Assemble complete custom box configurations.
