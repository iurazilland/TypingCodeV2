Title_EN: CSS Media Queries
Title_KO: 미디어 쿼리와 반응형 웹
Description_EN: Learn responsive layouts using @media width filters.
Description_KO: 화면 너비 해상도에 맞춰 모바일/데스크톱 스타일을 분기하는 반응형 미디어 쿼리를 배웁니다.

1.
Guide_EN: Write media query matching max-width limits.
Guide_KO: 가로가 600픽셀보다 좁아지는 모바일 환경에서 글자를 주황색(orange)으로 변경하는 조건식을 작성합니다.
Template_HTML:
<p>Mobile text</p>
Template_CSS:
@media (max-width: 600px) {
  p {
    color: orange;
  }
}

2.
Guide_EN: Add background modifications inside media queries.
Guide_KO: 가로가 600픽셀 이하일 때 본문 배경색을 변경하게 만듭니다.
Template_HTML:
<body>Page</body>
Template_CSS:
@media (max-width: 600px) {
  body {
    background: black;
  }
}

3.
Guide_EN: Write media query for desktop minimum width.
Guide_KO: 가로가 768픽셀보다 넓은 데스크톱 환경에서 제목을 하늘색(skyblue)으로 변경하는 조건식을 작성합니다.
Template_HTML:
<h1>Desktop view</h1>
Template_CSS:

  h1 {
    color: skyblue;
  }
}

4.
Guide_EN: Add font size adjustments inside desktop query.
Guide_KO: 768픽셀 이상 넓을 때 글꼴 글자 크기를 32픽셀로 키워 줍니다.
Template_HTML:

5.
Guide_EN: Change flex direction to column on mobile.
Guide_KO: 가로 600픽셀 이하 화면에서 플렉스 정렬을 세로 열로 전환합니다.
Template_HTML:

  .row {
    flex-direction: column;
  }

Guide_EN: Combine display block and inline-blocks inside media query.

7.

8.
Guide_EN: Define media query for custom layout sidebars.

9.
Guide_EN: Change grid column templates inside media query.
Guide_KO: 모바일 너비일 때 그리드 3열 분할을 1열(1fr)로 병합 일렬화합니다.

Template_CSS:

  }
}
