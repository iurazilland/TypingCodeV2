Title_EN: JS Array Transforms
Title_KO: 고차 함수와 배열 변환
Description_EN: Learn forEach, map, and filter.
Description_KO: 배열 원소를 순회(forEach)하거나 일괄 가공(map), 조건 필터링(filter)하는 고차 함수를 배웁니다.

1.
Guide_EN: Use forEach method to print all elements in the array.
Guide_KO: 배열의 내장 순회 기법인 forEach를 써서 각 원소를 콘솔에 출력합니다.
Template_JS:
let list = [1, 2, 3];
list.forEach(val => console.log(val));

2.
Guide_EN: Use map method to transform all elements of the array.
Guide_KO: 배열 내 모든 숫자 원소 값을 2배씩 튀겨서 새 배열을 만드는 map을 씁니다.
Template_JS:
let list = [1, 2, 3];
let doubled = list.map(x => x * 2);
console.log(doubled);

3.
Guide_EN: Use filter method to select specific elements.
Guide_KO: 배열의 숫자 원소 중 10보다 큰 알짜 값들만 걸러내는 filter를 씁니다.
Template_JS:
let list = [5, 12, 8, 20];
let filtered = list.filter(x => x > 10);
console.log(filtered);

4.
Guide_EN: Calculate sum of mapped numbers.
Guide_KO: 배열 각 원소에 1을 더한 결과를 map으로 묶어 콘솔 로그로 확인합니다.
Template_JS:
let list = [1, 2];
let res = list.map(x => x + 1);
console.log(res);

5.
Guide_EN: Filter even numbers from the array list.
Guide_KO: 배열에서 짝수 원소만 깔끔하게 체로 걸러 보관하는 filter식을 씁니다.
Template_JS:
let list = [1, 2, 3, 4];
let evens = list.filter(x => x % 2 === 0);
console.log(evens);

6.
Guide_EN: Combine map and filter operations in sequence.
Guide_KO: 짝수만 먼저 거른(filter) 후, 그 값들을 10배씩 곱해(map) 완성합니다.
Template_JS:
let list = [1, 2, 3, 4];
let res = list.filter(x => x % 2 === 0).map(x => x * 10);
console.log(res);

7.
Guide_EN: Check mapped strings transformations.
Guide_KO: 문자열 배열의 모든 요소를 대문자로 변환해 주는 map 메서드를 씁니다.
Template_JS:
let list = ["a", "b"];
let upper = list.map(s => s.toUpperCase());
console.log(upper);

8.
Guide_EN: Filter specific text lengths from array strings.
Guide_KO: 글자 길이가 4글자 이상인 텍스트 단어들만 걸러 모으는 filter를 구현합니다.
Template_JS:
let words = ["apple", "cat", "blue"];
let longWords = words.filter(w => w.length >= 4);
console.log(longWords);

9.
Guide_EN: Use forEach to sum numeric elements.
Guide_KO: forEach 순회 콜백 구조를 돌려 내부 총합 변수에 값을 적립시킵니다.
Template_JS:
let list = [10, 20];
let sum = 0;
list.forEach(x => sum += x);
console.log(sum);

10.
Guide_EN: Map array elements into list string segments.
Guide_KO: 문자열 배열 원소들을 HTML <li> 목록 태그 문자열 형태로 감싸 변환합니다.
Template_JS:
let list = ["Home", "Blog"];
let tags = list.map(item => "<li>" + item + "</li>");
console.log(tags);

11.
Guide_EN: Filter user names matching specific keywords.
Guide_KO: 성씨가 "Lee"로 지정된 회원 데이터만 추출해 수집하는 필터를 씁니다.
Template_JS:
let names = ["Kim", "Lee Min", "Park"];
let lees = names.filter(n => n.includes("Lee"));
console.log(lees);

12.
Guide_EN: Verify first element of mapped array results.
Guide_KO: 배열 요소들에 연산을 가한 후 새로 얻은 배열의 첫 방을 확인합니다.
Template_JS:
let list = [10, 20];
let next = list.map(x => x / 10);
console.log(next[0]);

13.
Guide_EN: Combine filter operations with length verification.
Guide_KO: 특정 조건을 만족하는 요소의 개수가 몇 개 모였는지 조회해 봅니다.
Template_JS:
let list = [5, 15, 25];
let cnt = list.filter(x => x > 10).length;
console.log(cnt);

14.
Guide_EN: Map numeric array states inside conditional checks.
Guide_KO: 홀수 원소들만 골라 제곱값으로 변환 적재하는 연결 식을 선언합니다.
Template_JS:
let raw = [1, 2, 3];
let oddSqs = raw.filter(x => x % 2 !== 0).map(x => x * x);
console.log(oddSqs);

15.
Guide_EN: Use forEach inside custom logic functions.
Guide_KO: 매개배열 요소를 순회하며 텍스트를 누적 병합 처리하는 함수 구조입니다.
Template_JS:
function joinAll(arr) {
  let res = "";
  arr.forEach(s => res += s);
  return res;
}
console.log(joinAll(["a", "b"]));

16.
Guide_EN: Return filtered array results inside functions.
Guide_KO: 인자로 받은 숫자 배열에서 짝수만 걸러서 그대로 반환해 주는 함수입니다.
Template_JS:
function getEvens(arr) {
  return arr.filter(x => x % 2 === 0);
}
console.log(getEvens([1, 2, 3]));

17.
Guide_EN: Map custom object formats inside functions.
Guide_KO: 숫자 배열 요소를 10배 불려서 새 배열로 전환 반환하는 함수를 정의합니다.
Template_JS:
const scale = (arr) => arr.map(x => x * 10);
console.log(scale([1, 2]));

18.
Guide_EN: Combine array mapping inside filter functions.
Guide_KO: 배열 내 양수 요소를 2배 곱한 결과물 리스트를 구하도록 조립합니다.
Template_JS:
function doublePos(arr) {
  return arr.filter(x => x > 0).map(x => x * 2);
}
console.log(doublePos([-1, 2]));

19.
Guide_EN: Verify mapping functionality with multiple arrays.
Guide_KO: 문자열 배열의 단어 길이를 숫자로 바꾸는 매핑 규칙을 함수로 땝니다.
Template_JS:
const getLens = (arr) => arr.map(s => s.length);
console.log(getLens(["cat", "apple"]));

20.
Guide_EN: Assemble complex functional array iterators.
Guide_KO: 배열 filter 호출 결과가 비어있는지를 판단해 주는 종결 함수를 씁니다.
Template_JS:
function noneActive(arr) {
  return arr.filter(x => x === "active").length === 0;
}
console.log(noneActive(["guest"]));
