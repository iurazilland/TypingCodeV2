Lv26.
Title_EN: Grid Layout
Title_KO: 그리드 바둑판 레이아웃
Description_EN: Learn display grid and template columns.
Description_KO: 2차원 격자 바둑판 그리드를 만들고 템플릿(columns)과 간격(gap)을 조율하는 법을 배웁니다.

1.
Guide_EN: Assign display grid container rule.
Guide_KO: 부모 상자에 display: grid 속성을 주어 격자형 바둑판 레이아웃을 선언합니다.
Template_HTML:
<div class="grid-container">
  <div>A</div>
</div>
Template_CSS:
.grid-container {
  display: grid;
}

2.
Guide_EN: Define grid column templates splitting into 3 equal tracks.
Guide_KO: 가로 칸을 동일 비율로 3칸 분할하는 grid-template-columns 속성을 씁니다.
Template_HTML:
<div class="grid-container"><div>A</div><div>B</div><div>C</div></div>
Template_CSS:
.grid-container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
}

3.
Guide_EN: Use repeat function to define columns easily.
Guide_KO: 동일 너비를 쉽게 3회 연속 반복하는 repeat() 정렬 함수를 씁니다.
Template_HTML:
<div class="grid-container"><div>A</div><div>B</div><div>C</div></div>
Template_CSS:
.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}

4.
Guide_EN: Set spacing gap between grid cell items.
Guide_KO: 격자 배치 상자들 간의 사잇대 가로세로 간격을 12픽셀 줍니다.
Template_HTML:
<div class="grid-container"><div>A</div><div>B</div></div>
Template_CSS:
.grid-container {
  display: grid;
  gap: 12px;
}

5.
Guide_EN: Combine grid template columns and gap values.
Guide_KO: 가로 2단 분할에 사잇대 간격 15픽셀을 한 번에 조립해 봅니다.
Template_HTML:
<div class="grid-container"><div>A</div><div>B</div></div>
Template_CSS:
.grid-container {
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  gap: 15px;
}

6.
Guide_EN: Define grid template rows height specifically.
Guide_KO: 세로 높이를 50픽셀과 80픽셀의 2단으로 높낮이를 제한 설정합니다.
Template_HTML:
<div class="grid-container"><div>A</div><div>B</div></div>
Template_CSS:
.grid-container {
  display: grid;
  grid-template-rows: 50px 80px;
}

7.
Guide_EN: Combine rows, columns, and gap rules in grid container.
Guide_KO: 가로 2단, 세로 2단, 간격 10픽셀 격자를 입체적 조립합니다.
Template_HTML:
<div class="grid-container"><div>A</div><div>B</div></div>
Template_CSS:
.grid-container {
  display: grid;
  grid-template-columns: 1fr 1fr;
  grid-template-rows: repeat(2, 50px);
  gap: 10px;
}

8.
Guide_EN: Define responsive cards grid lists (cumulative review).
Guide_KO: 카드가 3개 배치되도록 3열 그리드 레이아웃을 다듬어 봅니다.
Template_HTML:
<div class="grid"><div>A</div><div>B</div><div>C</div></div>
Template_CSS:
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}

9.
Guide_EN: Target child items to span multiple grid columns.
Guide_KO: 특정 자식 셀이 가로로 2칸 공간을 차지하게(grid-column) 확장합니다.
Template_HTML:
<div class="grid"><div class="wide">Wide</div><div>A</div></div>
Template_CSS:
.wide {
  grid-column: span 2;
}

10.
Guide_EN: Target child items to span multiple grid rows.
Guide_KO: 특정 자식 셀이 세로로 2칸 공간을 차지하게(grid-row) 확장합니다.
Template_HTML:
<div class="grid"><div class="tall">Tall</div><div>A</div></div>
Template_CSS:
.tall {
  grid-row: span 2;
}

11.
Guide_EN: Combine columns and row spanning rules.
Guide_KO: 가로 2칸, 세로 2칸을 한꺼번에 삼켜 독점하는 큰 격자 셀을 만듭니다.
Template_HTML:
<div class="grid"><div class="giant">Giant</div></div>
Template_CSS:
.giant {
  grid-column: span 2;
  grid-row: span 2;
}

12.
Guide_EN: Set justify-items center inside grid lines.
Guide_KO: 격자 칸 내부 자식들의 가로 정렬 위치를 가운데(center) 정렬합니다.
Template_HTML:
<div class="grid"><div>A</div></div>
Template_CSS:
.grid {
  display: grid;
  justify-items: center;
}

13.
Guide_EN: Set align-items center inside grid cells.
Guide_KO: 격자 칸 내부 자식들의 수직 정렬 높이를 정중앙에 맞춰 서게 지시합니다.
Template_HTML:
<div class="grid"><div>A</div></div>
Template_CSS:
.grid {
  display: grid;
  align-items: center;
}

14.
Guide_EN: Combine justify and align cells center properties.
Guide_KO: 격자 내부 자식들이 중앙 교차점에 완전 정중앙 안착되게 짭니다.
Template_HTML:
<div class="grid"><div>A</div></div>
Template_CSS:
.grid {
  display: grid;
  justify-items: center;
  align-items: center;
}

15.
Guide_EN: Set template columns using auto-fit sizing rule.
Guide_KO: 창 크기에 맞춰 자동 열 개수가 바뀌는 반응형 그리드를 만듭니다.
Template_HTML:
<div class="grid"><div>Card</div></div>
Template_CSS:
.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, 100px);
}

16.
Guide_EN: Use auto-fit and gap properties combined.
Guide_KO: 반응형 그리드 열 분할과 10픽셀의 사잇간격을 엮어 설계합니다.
Template_HTML:
<div class="grid"><div>Card</div></div>
Template_CSS:
.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, 80px);
  gap: 10px;
}

17.
Guide_EN: Use grid template areas names mappings.
Guide_KO: 이름을 사용해 영역을 정의하는 grid-template-areas를 씁니다.
Template_HTML:
<div class="layout"><header>H</header><main>M</main></div>
Template_CSS:
.layout {
  display: grid;
  grid-template-areas: "head head" "body body";
}

18.
Guide_EN: Assign grid areas on header layouts.
Guide_KO: 헤더 영역이 정의된 머리 구획 이름에 자식 요소를 매핑시킵니다.
Template_HTML:
<header class="hd">H</header>
Template_CSS:
.hd {
  grid-area: head;
}

19.
Guide_EN: Assign grid areas on body main content.
Guide_KO: 바디 영역이 정의된 몸통 구획 이름에 메인 요소를 매핑시킵니다.
Template_HTML:
<main class="bd">M</main>
Template_CSS:
.bd {
  grid-area: body;
}

20.
Guide_EN: Assemble complete multi-area grid layouts structure.
Guide_KO: 헤더와 바디 영역 매핑 그리드 구조를 최종 결합 마감해 봅니다.
Template_HTML:
<div class="layout">
  <header class="hd">Head</header>
  <main class="bd">Body</main>
</div>
Template_CSS:
.layout {
  display: grid;
  grid-template-areas: "head" "body";
  gap: 5px;
}
.hd { grid-area: head; }
.bd { grid-area: body; }
