Lv13.
Title_EN: Form Inputs & Attributes
Title_KO: 폼 입력창과 필수 속성
Description_EN: Learn how to use input fields, labels, placeholders, and validation.
Description_KO: 사용자 입력을 받는 다양한 input 유형과 필수 입력(required), placeholder 속성을 배웁니다.

1.
Guide_EN: Create input field with placeholder.
Guide_KO: 미리보기 안내글이 들어간 텍스트 입력창 요소를 작성합니다.
Template_HTML:
<input type="text" placeholder="Name">

2.
Guide_EN: Add input attribute setting field as required.
Guide_KO: 필수 입력 지정을 나타내는 required 속성을 추가해 봅니다.
Template_HTML:
<input type="text" required>

3.
Guide_EN: Combine placeholder and required attributes.
Guide_KO: 안내 문구와 필수 속성을 결합한 입력창을 완성합니다.
Template_HTML:
<input type="text" placeholder="ID" required>

4.
Guide_EN: Create input element for password input.
Guide_KO: 글자가 숨겨서 입력되는 패스워드 전용 창을 생성합니다.
Template_HTML:
<input type="password" placeholder="PW">

5.
Guide_EN: Create input element for email address validation.
Guide_KO: 이메일 형식의 값 유효성을 검사하는 메일 입력창을 씁니다.
Template_HTML:
<input type="email" placeholder="Email">

6.
Guide_EN: Add simple submit button.
Guide_KO: 폼 입력값들을 전송 처리하기 위한 제출 버튼을 배치합니다.
Template_HTML:
<button type="submit">Send</button>

7.
Guide_EN: Nest inputs inside form elements.
Guide_KO: 입력창들을 폼 전송을 의미하는 form 태그로 감싸 묶어줍니다.
Template_HTML:
<form>
  <input type="text" required>
</form>

8.
Guide_EN: Create labeled input tags.
Guide_KO: 입력창과 텍스트 제목 라벨 요소를 함께 배치 조립합니다.
Template_HTML:
<label>User</label>
<input type="text">

9.
Guide_EN: Combine multiple required fields in forms.
Guide_KO: 아이디와 패스워드 필수 입력창 2개를 연달아 배열합니다.
Template_HTML:
<input type="text" placeholder="ID" required>
<input type="password" placeholder="PW" required>

10.
Guide_EN: Create select options inputs.
Guide_KO: 사용자가 드롭다운으로 선택할 수 있는 폼 요소를 추가합니다.
Template_HTML:
<select>
  <option>Guest</option>
</select>

11.
Guide_EN: Create structured label association utilizing IDs.
Guide_KO: 라벨의 for 속성과 입력창의 id를 매핑하여 연동시킵니다.
Template_HTML:
<label for="uid">ID</label>
<input type="text" id="uid">

12.
Guide_EN: Add form elements inside grid containers.
Guide_KO: 상자 div 영역 내부에 라벨과 텍스트 입력창을 배치합니다.
Template_HTML:
<div class="field">
  <label>Name</label>
  <input type="text">
</div>

13.
Guide_EN: Nest email inputs inside labeled layouts.
Guide_KO: 이메일 전용 필수 입력창과 라벨 연동 구조를 만듭니다.
Template_HTML:
<label for="mail">Email</label>
<input type="email" id="mail" required>

14.
Guide_EN: Add textarea layout configurations.
Guide_KO: 여러 줄의 장문 텍스트 입력을 위한 입력 상자를 만듭니다.
Template_HTML:
<textarea placeholder="Memo"></textarea>

15.
Guide_EN: Include submit buttons inside form tags.
Guide_KO: 폼 전송 구획 내부에 최종 데이터를 보낼 제출 버튼을 넣습니다.
Template_HTML:
<form>
  <input type="text" required>
  <button type="submit">Go</button>
</form>

16.
Guide_EN: Build complete login input layouts.
Guide_KO: 라벨, 아이디 비밀번호 입력창, 제출 단추를 묶어 폼을 조립합니다.
Template_HTML:
<form>
  <label>ID</label>
  <input type="text" required>
  <label>PW</label>
  <input type="password" required>
  <button type="submit">Login</button>
</form>

17.
Guide_EN: Construct select dropdown with multiple options.
Guide_KO: 2개 이상의 다중 선택지를 갖는 드롭다운 메뉴를 만듭니다.
Template_HTML:
<select>
  <option>Admin</option>
  <option>User</option>
</select>

18.
Guide_EN: Nest form elements inside main content layout.
Guide_KO: 본문 메인 영역 내에 사용자 입력용 폼 구조를 안착시킵니다.
Template_HTML:
<main>
  <h2>Join</h2>
  <form>
    <input type="text" required>
  </form>
</main>

19.
Guide_EN: Include fieldset legends inside form groups.
Guide_KO: 입력폼들을 경계선 상자로 묶고 상단 제목을 달아 봅니다.
Template_HTML:
<!DOCTYPE html>
<html>
<head>
  <title>Form Attributes</title>
</head>
<body>
  <fieldset>
    <legend>User Info</legend>
    <input type="text">
  </fieldset>
</body>
</html>

20.
Guide_EN: Assemble complete layout sign-up input views.
Guide_KO: 메인 영역에 입력 폼, 제목, 라벨, 제출 단추를 종합 조립합니다.
Template_HTML:
<!DOCTYPE html>
<html>
<head>
  <title>Form Attributes</title>
</head>
<body>
  <main>
    <h2>Sign Up</h2>
    <form>
      <label for="n">Name</label>
      <input type="text" id="n" placeholder="Name" required>
      <button type="submit">
        Register
      </button>
    </form>
  </main>
</body>
</html>
