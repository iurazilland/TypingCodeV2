Lv23.
Title_EN: Flexbox Alignment
Title_KO: 플렉스 상자 정렬 기법
Description_EN: Learn justify-content and align-items.
Description_KO: 플렉스 상자 내부 요인들을 주축(justify-content) 및 교차축(align-items) 정렬시키는 법을 배웁니다.

1.
Guide_EN: Justify content center inside container.
Guide_KO: 자식 요소들을 주축 방향 기준 한가운데 중앙 정렬(center)시킵니다.
Template_HTML:
<div class="container">
  <div>Item</div>
</div>
Template_CSS:
.container {
  display: flex;
  justify-content: center;
}

2.
Guide_EN: Justify content space-between for maximum span.
Guide_KO: 양쪽 끝단 벽에 자식을 붙이고 남은 사잇공간을 균등 분할합니다.
Template_HTML:
<div class="container"><div>Left</div><div>Right</div></div>
Template_CSS:
.container {
  display: flex;
  justify-content: space-between;
}

3.
Guide_EN: Justify content space-around configuration.
Guide_KO: 자식 좌우에 균등한 비율의 장식 여백 여유를 두어 정렬합니다.
Template_HTML:
<div class="container"><div>A</div><div>B</div></div>
Template_CSS:
.container {
  display: flex;
  justify-content: space-around;
}

4.
Guide_EN: Align items center for vertical fit.
Guide_KO: 자식들을 수직 교차축 방향의 한가운데 수평 정렬(center)합니다.
Template_HTML:
<div class="container"><div>Center</div></div>
Template_CSS:
.container {
  display: flex;
  align-items: center;
}

5.
Guide_EN: Combine justify center and align center.
Guide_KO: 자식을 가로 세로 교차점 정중앙에 완벽히 정렬 안착시킵니다.
Template_HTML:
<div class="container"><div>Box</div></div>
Template_CSS:
.container {
  display: flex;
  justify-content: center;
  align-items: center;
}

6.
Guide_EN: Align items flex-end for bottom alignments.
Guide_KO: 수직 교차축의 맨 아래 바닥선(flex-end)에 맞춰 정렬합니다.
Template_HTML:
<div class="container"><div>Bottom</div></div>
Template_CSS:
.container {
  display: flex;
  align-items: flex-end;
}

7.
Guide_EN: Combine justify space-between and align center.
Guide_KO: 양끝 정렬 상태에서 자식들의 세로 높이 축을 중앙에 맞춥니다.
Template_HTML:
<div class="container"><div>A</div><div>B</div></div>
Template_CSS:
.container {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

8.
Guide_EN: Justify content flex-end for right alignment.
Guide_KO: 자식들을 주축 방향 오른쪽 끝선(flex-end)에 몰아 배치합니다.
Template_HTML:
<div class="container"><div>Right</div></div>
Template_CSS:
.container {
  display: flex;
  justify-content: flex-end;
}

9.
Guide_EN: Combine justify flex-end and align center.
Guide_KO: 오른쪽 끝 정렬과 수직 중앙 정렬을 조합해 상자를 엮습니다.
Template_HTML:
<div class="container"><div>Right-Center</div></div>
Template_CSS:
.container {
  display: flex;
  justify-content: flex-end;
  align-items: center;
}

10.
Guide_EN: Set flex layouts inside navigation headers (cumulative review).
Guide_KO: 내비게이션 내부 메뉴 링크들을 가로 양끝 정렬시킵니다.
Template_HTML:
<nav><h1>Logo</h1><div>Menu</div></nav>
Template_CSS:
nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

11.
Guide_EN: Combine nav heights and vertical alignments.
Guide_KO: 내비바에 세로 높이 60픽셀을 주고 자식들을 세로 정밀 조율합니다.
Template_HTML:
<nav><span>Logo</span></nav>
Template_CSS:
nav {
  display: flex;
  height: 60px;
  align-items: center;
}

12.
Guide_EN: Combine navigation gap properties and right align.
Guide_KO: 오른쪽 끝에 정렬 배치하며 각 링크 사이 간격 10픽셀을 줍니다.
Template_HTML:
<nav><a href="#">Home</a><a href="#">Blog</a></nav>
Template_CSS:
nav {
  display: flex;
  justify-content: flex-end;
  gap: 10px;
}

13.
Guide_EN: Align items baseline targeting texts sizes.
Guide_KO: 글꼴 크기가 서로 다른 문자들의 밑줄 기준선(baseline)을 맞춥니다.
Template_HTML:
<div class="row"><h1>A</h1><span>B</span></div>
Template_CSS:
.row {
  display: flex;
  align-items: baseline;
}

14.
Guide_EN: Justify space-evenly for uniform tracks.
Guide_KO: 모든 공백과 자식 사잇값을 오차 없이 완전 균등분할 정렬합니다.
Template_HTML:
<div class="container"><div>A</div><div>B</div></div>
Template_CSS:
.container {
  display: flex;
  justify-content: space-evenly;
}

15.
Guide_EN: Combine space-evenly and height limits.
Guide_KO: 공간 균등 정렬 하에 세로 높이 80픽셀을 부여해 조율합니다.
Template_HTML:
<div class="container"><div>A</div></div>
Template_CSS:
.container {
  display: flex;
  justify-content: space-evenly;
  height: 80px;
}

16.
Guide_EN: Control button contents align center.
Guide_KO: 클래스 btn 상자 내에 로고 아이콘과 글을 플렉스 정렬합니다.
Template_HTML:
<button class="btn"><img src="logo.svg" width="20"><span>Login</span></button>
Template_CSS:
.btn {
  display: flex;
  align-items: center;
  gap: 6px;
}

17.
Guide_EN: Combine card footers items align right.
Guide_KO: 카드 하단의 버튼 2개를 우측 하단 구석에 정밀 배치시킵니다.
Template_HTML:
<div class="footer"><button>Cancel</button><button>Ok</button></div>
Template_CSS:
.footer {
  display: flex;
  justify-content: flex-end;
  gap: 8px;
}

18.
Guide_EN: Apply vertical stretch flex alignments.
Guide_KO: 기본 정렬(stretch)에 맞춰 부모 세로 높이대로 세로를 늘립니다.
Template_HTML:
<div class="box">Stretch</div>
Template_CSS:
div {
  display: flex;
  align-items: stretch;
}

19.
Guide_EN: Apply stretch values and custom layouts heights.
Guide_KO: 교차 정렬을 강제 설정해 자식 상자가 세로를 채우게 만듭니다.
Template_HTML:
<div class="parent"><div>Child</div></div>
Template_CSS:
.parent {
  display: flex;
  height: 100px;
  align-items: stretch;
}

20.
Guide_EN: Assemble alignment properties across layout modules.
Guide_KO: 본문 구획을 양끝 정렬하고 수직 높이 중앙선을 최종 완성합니다.
Template_HTML:
<main class="main-zone">
  <h2>Section</h2>
  <button class="btn">More</button>
</main>
Template_CSS:
.main-zone {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 10px;
}
