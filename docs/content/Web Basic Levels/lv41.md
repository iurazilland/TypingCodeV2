Lv41.
Title_EN: DOM Selectors
Title_KO: 문서 객체 선택자
Description_EN: Learn document.querySelector and querySelectorAll.
Description_KO: 자바스크립트에서 HTML 요소를 찾아 가리키는 querySelector와 querySelectorAll 선택 기법을 배웁니다.

1.
Guide_EN: Select element by tag name.
Guide_KO: 태그명을 사용해 페이지 내 첫 번째 제목 요소를 선택해 봅니다.
Template_HTML:
<h1>Title</h1>
Template_JS:
const h1 = document.querySelector("h1");
console.log(h1);

2.
Guide_EN: Select element by class name.
Guide_KO: 클래스 선택자 기호(.)를 써서 해당 클래스의 요소를 지정합니다.
Template_HTML:
<p class="desc">Desc</p>
Template_JS:
const p = document.querySelector(".desc");
console.log(p);

3.
Guide_EN: Select element by ID selector.
Guide_KO: 고유한 대상을 가리키는 ID 선택자 기호(#)로 요소를 선택합니다.
Template_HTML:
<div id="card">Card</div>
Template_JS:
const div = document.querySelector("#card");
console.log(div);

4.
Guide_EN: Select button elements specifically.
Guide_KO: 동작 단추를 제어하기 위해 버튼 요소를 선택해 변수에 보관합니다.
Template_HTML:
<button>Go</button>
Template_JS:
const btn = document.querySelector("button");
console.log(btn);

5.
Guide_EN: Select input elements for reading.
Guide_KO: 입력창에 입력된 정보를 가져오기 위해 input을 가리킵니다.
Template_HTML:
<input type="text">
Template_JS:
const input = document.querySelector("input");
console.log(input);

6.
Guide_EN: Select all matching elements.
Guide_KO: 선택자에 대응하는 모든 요소 목록을 일괄 수집(querySelectorAll)합니다.
Template_HTML:
<p>A</p>
<p>B</p>
Template_JS:
const list = document.querySelectorAll("p");
console.log(list.length);

7.
Guide_EN: Verify length of selected nodes list.
Guide_KO: 선택된 요인 목록에 몇 개의 노드들이 담겨 있는지 크기를 봅니다.
Template_HTML:
<ul><li>1</li><li>2</li></ul>
Template_JS:
const list = document.querySelectorAll("li");
console.log(list.length);

8.
Guide_EN: Access first item of selected list.
Guide_KO: 수집된 노드 배열 리스트 중 0번 방 첫 요소를 조회합니다.
Template_HTML:
<ul><li>A</li><li>B</li></ul>
Template_JS:
const items = document.querySelectorAll("li");
console.log(items[0]);

9.
Guide_EN: Access second item of selected list.
Guide_KO: 수집된 목록 노드 배열의 두 번째(1번 방) 원소를 조회해 봅니다.
Template_HTML:
<ul><li>A</li><li>B</li></ul>
Template_JS:
const items = document.querySelectorAll("li");
console.log(items[1]);

10.
Guide_EN: Select element nested inside containers.
Guide_KO: 상자 div 영역의 자식 단락 p 요소를 경로를 주어 선택합니다.
Template_HTML:
<div class="box"><p>Inner</p></div>
Template_JS:
const p = document.querySelector(".box p");
console.log(p);

11.
Guide_EN: Select active navigation menus (cumulative review).
Guide_KO: 내비바 안에 포함된 활성화 상태인 ID current 링크를 잡습니다.
Template_HTML:
<nav><a id="current" href="#">Home</a></nav>
Template_JS:
const link = document.querySelector("nav #current");
console.log(link);

12.
Guide_EN: Select form submit buttons specifically.
Guide_KO: 전송을 처리하는 폼 영역 안의 제출용 단추 요소를 지정합니다.
Template_HTML:
<form><button type="submit">Go</button></form>
Template_JS:
const btn = document.querySelector("form button");
console.log(btn);

13.
Guide_EN: Select details inside card collections.
Guide_KO: 카드 컨테이너 내부의 세부 설명 desc 클래스를 골라냅니다.
Template_HTML:
<div class="card"><span class="desc">Hi</span></div>
Template_JS:
const span = document.querySelector(".card .desc");
console.log(span);

14.
Guide_EN: Select video elements for media controls.
Guide_KO: 동영상 플레이어 요소를 찾아내어 자바스크립트 변수로 묶습니다.
Template_HTML:
<video src="clip.mp4"></video>
Template_JS:
const vid = document.querySelector("video");
console.log(vid);

15.
Guide_EN: Check querySelector returns null if not found.
Guide_KO: 존재하지 않는 이상한 이름을 검색했을 때 돌아오는 결과를 봅니다.
Template_HTML:
<div>Empty</div>
Template_JS:
const missing = document.querySelector(".none");
console.log(missing);

16.
Guide_EN: Select class inside layouts sidebar panels.
Guide_KO: 사이드바 영역 안의 제목을 가리키는 클래스를 선택 조립합니다.
Template_HTML:
<aside><h3 class="title">Sub</h3></aside>
Template_JS:
const h3 = document.querySelector("aside .title");
console.log(h3);

17.
Guide_EN: Select element by compound class names.
Guide_KO: 클래스명이 'btn'이면서 'primary'인 버튼 요소를 지정합니다.
Template_HTML:
<button class="btn primary">Go</button>
Template_JS:
const btn = document.querySelector(".btn.primary");
console.log(btn);

18.
Guide_EN: Select input by attribute selector patterns.
Guide_KO: 타입 속성이 패스워드인 입력창을 정밀하게 타겟 지정합니다.
Template_HTML:
<input type="password">
Template_JS:
const pw = document.querySelector("input[type='password']");
console.log(pw);

19.
Guide_EN: Check querySelectorAll length on empty results.
Guide_KO: 존재하지 않는 대상을 수집했을 때 잡히는 목록 크기를 조회합니다.
Template_HTML:
<div>Box</div>
Template_JS:
const list = document.querySelectorAll("button");
console.log(list.length);

20.
Guide_EN: Assemble selectors mapping multiple nodes on pages.
Guide_KO: 제목, 입력창, 버튼 요소를 각각 변수로 매핑 확보해 완성합니다.
Template_HTML:
<h1>App</h1>
<input type="text">
<button>OK</button>
Template_JS:
const h1 = document.querySelector("h1");
const input = document.querySelector("input");
const btn = document.querySelector("button");
console.log(h1, input, btn);
