Title_EN: JS Basic Loops
Title_KO: 반복 루프와 순회
Description_EN: Learn for, while, and index increments.
Description_KO: 지정된 횟수나 조건 동안 코드를 반복 순회하는 for와 while 루프 제어를 배웁니다.

1.
Guide_EN: Write a basic for loop printing index values from 1 to 3.
Guide_KO: 1부터 3까지 숫자를 1씩 증가시키며 루프를 도는 기본 for 문을 씁니다.
Template_JS:
for (let i = 1; i <= 3; i++) {
  console.log(i);
}

2.
Guide_EN: Use for loop to iterate through all elements of the array.
Guide_KO: for 루프와 인덱스 변수를 활용해 배열의 모든 방을 순차 인쇄합니다.
Template_JS:
let list = [10, 20, 30];
for (let i = 0; i < list.length; i++) {
  console.log(list[i]);
}

3.
Guide_EN: Write a basic while loop structure that prints step counter.
Guide_KO: 조건식이 참인 동안 반복해서 도는 기본 while 반복문을 작성해 봅니다.
Template_JS:
let i = 1;
while (i <= 3) {
  console.log(i);
  i++;
}

4.
Guide_EN: Sum numeric elements of the array using for loop.
Guide_KO: for 반복문을 돌며 배열 내부 숫자 누적 합산값(sum)을 계산합니다.
Template_JS:
let list = [1, 2, 3];
let sum = 0;
for (let i = 0; i < list.length; i++) {
  sum += list[i];
}
console.log(sum);

5.
Guide_EN: Count specific matching elements in array inside loop.
Guide_KO: 배열 내에 합격 기준인 80점 이상의 점수가 몇 개인지 개수를 셉니다.
Template_JS:
let scores = [70, 90, 85];
let count = 0;
for (let i = 0; i < scores.length; i++) {
  if (scores[i] >= 80) count++;
}
console.log(count);

6.
Guide_EN: Write loop structures using backstep decrement operations.
Guide_KO: 인덱스 수치를 1씩 감소시키며 반대 방향으로 순회하는 루프를 돕니다.
Template_JS:
for (let i = 3; i > 0; i--) {
  console.log(i);
}

7.
Guide_EN: Find matching search value inside list using for loop.
Guide_KO: 목록을 순회하다 원하는 목표 값을 만나면 루프를 즉시 중단(break)합니다.
Template_JS:
let list = ["a", "target", "c"];
for (let i = 0; i < list.length; i++) {
  if (list[i] === "target") break;
}

8.
Guide_EN: Calculate values using nested for loop calculations.
Guide_KO: 이중 for 루프 구조를 사용하여 격자 모양 인덱스 순환을 처리합니다.
Template_JS:
for (let i = 0; i < 2; i++) {
  for (let j = 0; j < 2; j++) {
    console.log(i, j);
  }
}

9.
Guide_EN: Apply compound conditions inside for loops (cumulative review).
Guide_KO: 배열 원소를 돌며 짝수 숫자들만 필터링해 출력하는 루프를 구성합니다.
Template_JS:
let nums = [1, 2, 3, 4];
for (let i = 0; i < nums.length; i++) {
  if (nums[i] % 2 === 0) console.log(nums[i]);
}

10.
Guide_EN: Populate array elements dynamically using for loop.
Guide_KO: 빈 배열에 루프 인덱스 숫자를 차례대로 밀어 넣어 데이터를 채웁니다.
Template_JS:
let arr = [];
for (let i = 1; i <= 3; i++) {
  arr.push(i);
}
console.log(arr);

11.
Guide_EN: Iterate while array length is not empty.
Guide_KO: 배열에 남은 요소를 하나씩 꺼내고 비워질 때까지 while 루프를 돕니다.
Template_JS:
let list = [1, 2, 3];
while (list.length > 0) {
  console.log(list.pop());
}

12.
Guide_EN: Update string content concatenation inside loop elements.
Guide_KO: 글자 목록을 한 줄 문장 텍스트로 합쳐 누적 연결하는 루프를 돕니다.
Template_JS:
let words = ["A", "B"];
let res = "";
for (let i = 0; i < words.length; i++) {
  res += words[i];
}
console.log(res);

13.
Guide_EN: Multiply all numbers in a numeric list array.
Guide_KO: 배열 내 모든 수치의 일괄 곱셈 값을 누적 변수에 저장해 나갑니다.
Template_JS:
let nums = [2, 3, 4];
let res = 1;
for (let i = 0; i < nums.length; i++) {
  res *= nums[i];
}
console.log(res);

14.
Guide_EN: Define lists matching specific condition inside loop.
Guide_KO: 10보다 큰 수만 모아서 새로운 임시 배열 방에 적재하는 루프입니다.
Template_JS:
let raw = [5, 12, 8, 20];
let res = [];
for (let i = 0; i < raw.length; i++) {
  if (raw[i] > 10) res.push(raw[i]);
}
console.log(res);

15.
Guide_EN: Check maximum value in list using comparison loop.
Guide_KO: 배열을 한 바퀴 순회하며 가장 큰 숫자(Max)의 행방을 파악해 봅니다.
Template_JS:
let nums = [3, 9, 2];
let max = nums[0];
for (let i = 1; i < nums.length; i++) {
  if (nums[i] > max) max = nums[i];
}
console.log(max);

16.
Guide_EN: Iterate list components checking indices.
Guide_KO: 각 기사글 목록 <li> 태그 문자열에 인덱스를 붙여 출력 조립합니다.
Template_JS:
let list = ["A", "B"];
for (let i = 0; i < list.length; i++) {
  console.log(i + ":" + list[i]);
}

17.
Guide_EN: Apply loop structures inside functional calculations.
Guide_KO: 전달받은 숫자 배열의 모든 누적 합계를 리턴해 주는 함수를 만듭니다.
Template_JS:
function getSum(arr) {
  let s = 0;
  for (let i = 0; i < arr.length; i++) s += arr[i];
  return s;
}
console.log(getSum([1, 2]));

18.
Guide_EN: Verify loop boundaries returning array configurations.
Guide_KO: 1부터 n까지의 숫자가 채워진 배열을 생성해 반환해 주는 함수입니다.
Template_JS:
function makeArr(n) {
  let a = [];
  for (let i = 1; i <= n; i++) a.push(i);
  return a;
}
console.log(makeArr(3));

19.
Guide_EN: Call same functions inside looping structures.
Guide_KO: 1부터 3까지 증가하는 루프를 돌며 외부 함수 호출을 반복 수행합니다.
Template_JS:
const double = x => x * 2;
for (let i = 1; i <= 3; i++) {
  console.log(double(i));
}

20.
Guide_EN: Assemble complex loop logic checking array boundaries and updates.
Guide_KO: 이중 for 루프와 짝수 조건, 누적 연산 결과를 최종 출력해 완료합니다.
Template_JS:
let grid = [[1, 2], [3, 4]];
for (let i = 0; i < grid.length; i++) {
  for (let j = 0; j < grid[i].length; j++) {
    if (grid[i][j] % 2 === 0) console.log(grid[i][j]);
  }
}
