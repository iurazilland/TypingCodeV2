Lv48.
Title_EN: LocalStorage Persistence
Title_KO: 웹 브라우저 로컬 저장소
Description_EN: Learn localStorage setItem, getItem, and JSON parse.
Description_KO: 브라우저를 새로고침하거나 꺼도 데이터가 계속 유지되는 로컬 저장소 활용법을 배웁니다.

1.
Guide_EN: Save a string to localStorage.
Guide_KO: 브라우저 기억 저장소에 키 'name'으로 'Kim' 데이터를 저장(setItem)합니다.
Template_JS:
localStorage.setItem("name", "Kim");

2.
Guide_EN: Retrieve saved string from localStorage.
Guide_KO: 기억 저장소에서 해당 키를 명시해 저장된 값을 호출(getItem)해 읽어옵니다.
Template_JS:
const val = localStorage.getItem("name");
console.log(val);

3.
Guide_EN: Remove specific item key from storage.
Guide_KO: 기억 저장소에서 해당 키를 특정해 정보만 삭제(removeItem)합니다.
Template_JS:
localStorage.removeItem("name");

4.
Guide_EN: Clear all data saved inside storage.
Guide_KO: 기억 저장소에 저장되어 있는 모든 데이터를 일괄 삭제(clear) 청소합니다.
Template_JS:
localStorage.clear();

5.
Guide_EN: Save numeric configurations inside storage.
Guide_KO: 숫자 데이터를 글자로 자동 직렬화하여 저장소에 기록해 봅니다.
Template_JS:
localStorage.setItem("score", "95");

6.
Guide_EN: Save boolean states values inside storage.
Guide_KO: 로그인 완료 여부 참/거짓 플래그 문자열을 저장소에 꼽아 둡니다.
Template_JS:
localStorage.setItem("logged", "true");

7.
Guide_EN: Verify default fallbacks on missing keys.
Guide_KO: 기억 저장소에 없는 키를 호출했을 때 리턴되는 결과를 확인해 봅니다.
Template_JS:
const missing = localStorage.getItem("none");
console.log(missing);

8.
Guide_EN: Save objects serialized utilizing JSON stringify.
Guide_KO: 배열이나 객체를 저장 가능하게 텍스트(JSON.stringify)로 변환해 봅니다.
Template_JS:
let arr = [1, 2];
localStorage.setItem("list", JSON.stringify(arr));

9.
Guide_EN: Retrieve objects parsing utilizing JSON parse.
Guide_KO: 텍스트로 복원해온 저장값을 원래의 배열 형태(JSON.parse)로 해석합니다.
Template_JS:
const raw = localStorage.getItem("list");
const list = JSON.parse(raw);
console.log(list[0]);

10.
Guide_EN: Initialize variables checking storage presence (cumulative review).
Guide_KO: 저장된 기록이 있으면 가져오고, 없으면 기본 글자 'Guest'를 잡습니다.
Template_JS:
let user = localStorage.getItem("user") || "Guest";
console.log(user);

11.
Guide_EN: Update paragraph text using storage records.
Guide_KO: 저장소에 보관되어 있던 정보 문구를 꺼내 단락 글귀에 반영합니다.
Template_HTML:
<p>Loading</p>
Template_JS:
const p = document.querySelector("p");
const val = localStorage.getItem("name") || "Guest";
p.innerText = val;

12.
Guide_EN: Save input values to storage on changes.
Guide_KO: 입력창 데이터 값을 변경할 때마다 로컬 저장소에 주기적 갱신 저장합니다.
Template_HTML:
<input type="text" value="Lee">
Template_JS:
const input = document.querySelector("input");
localStorage.setItem("memo", input.value);

13.
Guide_EN: Load and restore input values from storage.
Guide_KO: 새로고침 복원을 모사해 로컬 저장된 값을 읽어 입력창에 채워 놓습니다.
Template_HTML:
<input type="text">
Template_JS:
const input = document.querySelector("input");
input.value = localStorage.getItem("memo") || "";

14.
Guide_EN: Save state configurations on button click event.
Guide_KO: 저장 버튼을 클릭했을 때 입력창 값을 로컬 저장소에 기록합니다.
Template_HTML:
<input type="text" value="A">
<button>Save</button>
Template_JS:
const btn = document.querySelector("button");
const input = document.querySelector("input");
btn.addEventListener("click", () => {
  localStorage.setItem("data", input.value);
});

15.
Guide_EN: Delete specific keys on click triggers.
Guide_KO: 삭제 버튼 클릭 시 저장소 내 키 'data' 레코드를 제거 처리합니다.
Template_HTML:
<button>Delete</button>
Template_JS:
const btn = document.querySelector("button");
btn.addEventListener("click", () => {
  localStorage.removeItem("data");
});

16.
Guide_EN: Combine storage loads and text updates on load.
Guide_KO: 이전 보관된 기록을 꺼내 대제목 글에 뿌려주도록 조립합니다.
Template_HTML:
<h1>Name</h1>
Template_JS:
const h1 = document.querySelector("h1");
const user = localStorage.getItem("username") || "Guest";
h1.innerText = user;

17.
Guide_EN: Toggle active designs classes using storage states.
Guide_KO: 다크 테마 설정 문자 정보 값 유무에 따라 스타일 클래스를 제어합니다.
Template_HTML:
<body></body>
Template_JS:
const active = localStorage.getItem("dark") === "true";
if (active) {
  document.body.classList.add("dark-theme");
}

18.
Guide_EN: Save theme states to storage on toggle.
Guide_KO: 테마 설정 클릭 시 참/거짓 정보를 로컬 저장소에 실시간 기재합니다.
Template_HTML:
<button>Toggle</button>
Template_JS:
const btn = document.querySelector("button");
btn.addEventListener("click", () => {
  let active = document.body.classList.toggle("dark");
  localStorage.setItem("dark", active);
});

19.
Guide_EN: Check remainder loops on JSON parsing structures.
Guide_KO: 배열 JSON을 복원한 목록 크기를 조회하는 절차를 작성해 봅니다.
Template_HTML:
<div></div>
Template_JS:
const raw = localStorage.getItem("list") || "[]";
const arr = JSON.parse(raw);
console.log(arr.length);

20.
Guide_EN: Assemble interactive storage text editors.
Guide_KO: 입력값 로컬 저장소 저장, 로드 복원, 초기화 단추 동작을 완성합니다.
Template_HTML:
<input type="text">
<button class="sv">Save</button>
<button class="cl">Clear</button>
Template_JS:
const input = document.querySelector("input");
const save = document.querySelector(".sv");
const clear = document.querySelector(".cl");
input.value = localStorage.getItem("txt") || "";
save.addEventListener("click", () => {
  localStorage.setItem("txt", input.value);
});
clear.addEventListener("click", () => {
  localStorage.removeItem("txt");
  input.value = "";
});
