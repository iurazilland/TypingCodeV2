Title_EN: JS Arrays
Title_KO: 배열 선언과 인덱스 접근
Description_EN: Learn array structures and index elements.
Description_KO: 여러 데이터를 순서대로 담아 보관하는 대괄호 배열과 방 번호(index) 접근법을 배웁니다.

1.
Guide_EN: Create an array containing three number values.
Guide_KO: 대괄호([]) 기호를 사용해 숫자 세 개를 담은 배열을 생성합니다.
Template_JS:
let nums = [10, 20, 30];

2.
Guide_EN: Access the first element of the array using index 0.
Guide_KO: 배열의 첫 번째 인덱스(0번) 원소에 접근하여 출력합니다.
Template_JS:
let nums = [10, 20, 30];
console.log(nums[0]);

3.
Guide_EN: Access the second element of the array using index 1.
Guide_KO: 배열의 두 번째 인덱스(1번) 원소 값을 읽어와 출력합니다.
Template_JS:
let nums = [10, 20, 30];
console.log(nums[1]);

4.
Guide_EN: Access the third element of the array using index 2.
Guide_KO: 배열의 세 번째 인덱스(2번) 원소 값을 콘솔에 출력합니다.
Template_JS:
let nums = [10, 20, 30];
console.log(nums[2]);

5.
Guide_EN: Update the first element of the array to a new value.
Guide_KO: 배열의 첫 인덱스(0번) 방의 값을 다른 숫자로 변경 대입합니다.
Template_JS:
let nums = [10, 20, 30];
nums[0] = 99;
console.log(nums[0]);

6.
Guide_EN: Create an array containing three string names.
Guide_KO: 세 명의 텍스트 이름 문자열을 쉼표로 나열한 배열을 만듭니다.
Template_JS:
let users = ["Kim", "Lee", "Park"];

7.
Guide_EN: Print the first name from the user array.
Guide_KO: 이름 문자열 배열의 첫 번째 이름(0번 방)을 콘솔창에 인쇄합니다.
Template_JS:
let users = ["Kim", "Lee"];
console.log(users[0]);

8.
Guide_EN: Declare an empty array variables.
Guide_KO: 내용물이 아무것도 들어있지 않은 빈 대괄호 배열을 선언합니다.
Template_JS:
let list = [];

9.
Guide_EN: Access undefined index element returns undefined.
Guide_KO: 배열 범위를 벗어난 빈 공간 인덱스 접근 시의 결과를 봅니다.
Template_JS:
let list = [];
console.log(list[0]);

10.
Guide_EN: Create multi-dimensional nesting arrays.
Guide_KO: 배열 내부의 원소로 또 다른 배열 요소를 포함하는 이중 배열을 씁니다.
Template_JS:
let grid = [[1, 2], [3, 4]];

11.
Guide_EN: Access nested element inside multi-dimensional array.
Guide_KO: 이중 배열의 행과 열 인덱스를 각각 연속 지정해 원소를 출력합니다.
Template_JS:
let grid = [[1, 2], [3, 4]];
console.log(grid[0][1]);

12.
Guide_EN: Combine variables and array allocations (cumulative review).
Guide_KO: 변수에 저장된 값을 배열의 초기 원소로 활용해 선언합니다.
Template_JS:
let age = 20;
let list = [age, 25];
console.log(list[0]);

13.
Guide_EN: Store and retrieve calculation results in array indices.
Guide_KO: 배열의 첫 두 원소 덧셈값을 구하여 변수에 보관 출력합니다.
Template_JS:
let prices = [100, 200];
let total = prices[0] + prices[1];
console.log(total);

14.
Guide_EN: Update multi-dimensional array elements dynamically.
Guide_KO: 이중 배열 내의 특정 열 값을 다른 숫자로 지정 교체해 봅니다.
Template_JS:
let matrix = [[0, 0], [0, 0]];
matrix[1][0] = 5;
console.log(matrix[1][0]);

15.
Guide_EN: Create string arrays and update second value.
Guide_KO: 텍스트 배열을 만들고, 두 번째 단어를 변경해 콘솔창에 찍어봅니다.
Template_JS:
let tags = ["html", "css"];
tags[1] = "js";
console.log(tags[1]);

16.
Guide_EN: Define list elements inside array elements.
Guide_KO: HTML 문자열 태그 원소들을 나열한 텍스트 목록 배열을 선언합니다.
Template_JS:
let htmlTags = ["<li>A</li>", "<li>B</li>"];

17.
Guide_EN: Combine array variables inside conditional branches.
Guide_KO: 배열 첫 칸의 수치가 적정 합격선을 만족하는지 조건 판별합니다.
Template_JS:
let scores = [85, 90];
if (scores[0] >= 80) {
  console.log("Pass");
}

18.
Guide_EN: Verify functional returns containing array configurations.
Guide_KO: 호출 시 숫자 배열을 결과로 리턴해 주는 단순 함수를 만듭니다.
Template_JS:
function getArr() {
  return [1, 2];
}
console.log(getArr()[0]);

19.
Guide_EN: Pass array parameter to functional calculators.
Guide_KO: 배열을 인자로 전송받아 첫 원소에 10을 더해 주는 함수를 만듭니다.
Template_JS:
function addFirst(arr) {
  return arr[0] + 10;
}
console.log(addFirst([5, 8]));

20.
Guide_EN: Assemble multiple index retrieval operations for list arrays.
Guide_KO: 배열의 0번 방과 1번 방의 글자를 연결하여 하나의 문장으로 엮어 봅니다.
Template_JS:
let words = ["Web ", "Basic"];
let msg = words[0] + words[1];
console.log(msg);
