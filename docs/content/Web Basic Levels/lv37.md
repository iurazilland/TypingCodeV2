Title_EN: JS Array Methods
Title_KO: 배열 조작 메서드
Description_EN: Learn push, pop, shift, and length.
Description_KO: 배열 끝에 추가(push)/제거(pop), 맨앞 제거(shift), 총 크기(length) 속성을 배웁니다.

1.
Guide_EN: Check array length using the length property.
Guide_KO: 배열의 전체 칸 개수를 알려주는 length 속성을 호출해 봅니다.
Template_JS:
let list = [10, 20];
console.log(list.length);

2.
Guide_EN: Add element to the end of the array using push method.
Guide_KO: 배열의 맨 마지막 방 뒤에 새로운 원소를 덧붙이는 push를 실행합니다.
Template_JS:
let list = [1, 2];
list.push(3);
console.log(list);

3.
Guide_EN: Remove element from the end of the array using pop method.
Guide_KO: 배열의 맨 마지막 원소를 제거하고 그 값을 리턴받는 pop을 씁니다.
Template_JS:
let list = [1, 2, 3];
let item = list.pop();
console.log(list, item);

4.
Guide_EN: Add element to the beginning of the array using unshift method.
Guide_KO: 배열의 맨 첫 칸(0번 방) 앞에 요소를 밀어 넣는 unshift를 씁니다.
Template_JS:
let list = [2, 3];
list.unshift(1);
console.log(list);

5.
Guide_EN: Remove element from the beginning of the array using shift method.
Guide_KO: 배열의 맨 첫 칸 요소를 빼내어 제거하는 shift 메서드를 씁니다.
Template_JS:
let list = [1, 2];
list.shift();
console.log(list);

6.
Guide_EN: Find index location of an element using indexOf method.
Guide_KO: 배열 내에 특정 값이 들어있는 방의 번호를 검색하는 indexOf를 씁니다.
Template_JS:
let list = ["a", "b"];
console.log(list.indexOf("b"));

7.
Guide_EN: Check if value exists using includes method.
Guide_KO: 배열 안에 타겟 정보가 소속되어 있는지 참/거짓 판단하는 속성을 씁니다.
Template_JS:
let list = ["a", "b"];
console.log(list.includes("c"));

8.
Guide_EN: Combine push and length checks in array operations.
Guide_KO: 요소를 하나 추가한 직후 변경된 배열의 총 길이를 확인해 봅니다.
Template_JS:
let list = [5];
list.push(10);
console.log(list.length);

9.
Guide_EN: Use pop on empty arrays returns undefined.
Guide_KO: 빈 배열에 제거 명령을 지시했을 때 리턴되는 값을 확인해 봅니다.
Template_JS:
let list = [];
console.log(list.pop());

10.
Guide_EN: Combine array methods in sequential operations.
Guide_KO: 요소 추가(push)와 첫 칸 제거(shift)를 연달아 행해 큐를 만듭니다.
Template_JS:
let queue = [1];
queue.push(2);
queue.shift();
console.log(queue);

11.
Guide_EN: Check includes logic in conditional branch.
Guide_KO: 배열 안에 찾는 단어가 들어있는지 확인해 분기 처리를 실행합니다.
Template_JS:
let tags = ["html", "css"];
if (tags.includes("html")) {
  console.log("Web");
}

12.
Guide_EN: Join array elements into a single string using join method.
Guide_KO: 배열 내 문자열 원소들을 슬래시(/) 기호로 이어 붙여 출력합니다.
Template_JS:
let date = [2026, 6, 12];
console.log(date.join("/"));

13.
Guide_EN: Reverse array elements ordering using reverse method.
Guide_KO: 배열 내부 원소들의 나열 순서를 앞뒤 정반대로 뒤집어 배치합니다.
Template_JS:
let list = [1, 2, 3];
list.reverse();
console.log(list);

14.
Guide_EN: Slice part of the array using slice method.
Guide_KO: 배열의 특정 범위 방 번호 구간을 잘라내어 새 배열 복사본을 땝니다.
Template_JS:
let list = ["a", "b", "c"];
console.log(list.slice(0, 2));

15.
Guide_EN: Update array size dynamically and verify limits.
Guide_KO: 배열에 다수의 데이터 push를 가한 후 최종 인덱스 한계를 검사합니다.
Template_JS:
let items = [];
items.push("A");
items.push("B");
console.log(items[1]);

16.
Guide_EN: Check indexOf returns minus one if not found.
Guide_KO: 배열 내에 존재하지 않는 텍스트를 검색했을 때 나오는 결과 번호를 봅니다.
Template_JS:
let list = ["html"];
console.log(list.indexOf("css"));

17.
Guide_EN: Manage state changes utilizing push methods inside loops.
Guide_KO: 조건 만족 판별 후 결과 임시 적재용 배열에 값을 밀어 넣어 채웁니다.
Template_JS:
let res = [];
let num = 10;
if (num > 5) {
  res.push(num);
}

18.
Guide_EN: Manage array states inside structured custom functions.
Guide_KO: 인자로 넘겨받은 배열에 새로운 데이터를 밀어 넣어 리턴하는 함수입니다.
Template_JS:
function addVal(arr) {
  arr.push(100);
  return arr;
}
console.log(addVal([1]));

19.
Guide_EN: Check array length constraints inside function returns.
Guide_KO: 배열의 크기가 비어있지 않고 차 있는지 판단해 주는 함수를 만듭니다.
Template_JS:
function hasItems(arr) {
  return arr.length > 0;
}
console.log(hasItems([]));

20.
Guide_EN: Assemble complex array modifications verifying length changes.
Guide_KO: 배열 생성, 맨 앞 요소 제거, 총 길이 세부 값 판독을 총괄 검토합니다.
Template_JS:
let list = [9, 8, 7];
list.shift();
list.push(6);
console.log(list.length, list[0]);
