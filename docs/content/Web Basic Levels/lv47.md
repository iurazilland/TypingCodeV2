Title_EN: JS Timers
Title_KO: 일정 시간 반복 타이머
Description_EN: Learn setInterval, clearInterval, and setTimeout.
Description_KO: 일정 시간 초마다 동작을 반복(setInterval)하거나 멈추는(clearInterval) 시간 제어를 배웁니다.

1.
Guide_EN: Start recurring interval timer.
Guide_KO: 일정 시간(1초 = 1000ms)마다 주기적으로 도는 반복 타이머를 켭니다.
Template_HTML:
<div></div>
Template_JS:
const id = setInterval(() => {
  console.log("Tick");
}, 1000);

2.
Guide_EN: Stop running interval timer.
Guide_KO: 동작 중인 반복 타이머의 키값 ID를 회수해 강제 정지(clearInterval)합니다.
Template_HTML:
<div></div>
Template_JS:
const id = setInterval(() => {}, 1000);
clearInterval(id);

3.
Guide_EN: Start one-shot delay timer.
Guide_KO: 지정된 시간(1.5초 = 1500ms) 후에 단 한 번만 실행되는 타이머를 켭니다.
Template_HTML:
<div></div>
Template_JS:
setTimeout(() => {
  console.log("Delay Done");
}, 1500);

4.
Guide_EN: Update paragraph text using interval timer.
Guide_KO: 1초 주기 타이머 작동 시마다 단락 글자가 주기적으로 갱신되게 짭니다.

<p>Ready</p>

7.
Guide_EN: Stop counter timer on click events (cumulative review).
Guide_KO: 중단 버튼을 누르면 구동 중이던 타이머가 멈추게(clear) 만듭니다.

17.

20.
Guide_EN: Assemble interactive timers stopwatch logic.
Guide_KO: 시작 단추, 중단 단추, 초 누계 디스플레이 기능을 종합 조립 완성합니다.
Template_HTML:
<h1>0</h1>
<button class="start">Start</button>
<button class="stop">Stop</button>
Template_JS:
let cnt = 0;
let id = null;
const h1 = document.querySelector("h1");
const run = document.querySelector(".start");
const pause = document.querySelector(".stop");
run.addEventListener("click", () => {
  if (id) clearInterval(id);
  id = setInterval(() => {
    cnt++;
    h1.innerText = cnt;
  }, 1000);
});
pause.addEventListener("click", () => {
  if (id) clearInterval(id);
});
