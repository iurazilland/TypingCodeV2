Lv11.
Title_EN: Semantic Layout Elements
Title_KO: 시맨틱 레이아웃 태그
Description_EN: Learn how to use header, main, and footer elements.
Description_KO: 웹페이지의 영역을 의미론적으로 분할하는 header, main, footer 태그를 배웁니다.

1.
Guide_EN: Create a page header element.
Guide_KO: 페이지 상단 영역을 정의하는 헤더 태그를 생성합니다.
Template_HTML:
<header>
  <h1>Header</h1>
</header>

2.
Guide_EN: Create a page main content element.
Guide_KO: 페이지 핵심 내용을 담을 메인 영역 태그를 생성합니다.
Template_HTML:
<main>
  <p>Main content</p>
</main>

3.
Guide_EN: Create a page footer element.
Guide_KO: 페이지 하단 저작권 정보를 표시하는 푸터 태그를 생성합니다.
Template_HTML:
<footer>
  <p>© 2026</p>
</footer>

4.
Guide_EN: Group header and main elements.
Guide_KO: 헤더와 메인 요소를 나란히 배치해 레이아웃을 형성합니다.
Template_HTML:
<header>
  <h1>App</h1>
</header>
<main>
  <p>Info</p>
</main>

5.
Guide_EN: Group main and footer elements.
Guide_KO: 메인 영역과 푸터 영역을 연이어 작성해 구조화합니다.
Template_HTML:
<main>
  <p>Main info</p>
</main>
<footer>
  <p>Footer</p>
</footer>

6.
Guide_EN: Add layout structure using all three tags.
Guide_KO: 헤더, 메인, 푸터를 종합하여 단일 페이지 구조를 만듭니다.
Template_HTML:
<header>
  <h1>Title</h1>
</header>
<main>
  <p>Content</p>
</main>
<footer>
  <p>End</p>
</footer>

7.
Guide_EN: Use sub-headings inside main layout.
Guide_KO: 메인 영역 내에 부제목 요소를 배치하여 정보를 계층화합니다.
Template_HTML:
<main>
  <h2>Section Title</h2>
  <p>Details here.</p>
</main>

8.
Guide_EN: Embed links inside the footer container.
Guide_KO: 푸터 영역 내부에 이동 링크 요소를 결합해 봅니다.
Template_HTML:
<footer>
  <p>Contact: <a href="#">Mail</a></p>
</footer>

9.
Guide_EN: Add images inside the page header.
Guide_KO: 헤더 구획 내부에 브랜드 로고 이미지를 삽입해 봅니다.
Template_HTML:
<header>
  <img src="logo.svg" width="50">
</header>

10.
Guide_EN: Nest containers inside the main tag.
Guide_KO: 메인 영역 내부에 그룹 상자 div를 중첩하여 설계합니다.
Template_HTML:
<main>
  <div class="box">
    <p>Inner Content</p>
  </div>
</main>

11.
Guide_EN: Combine logo and titles inside header.
Guide_KO: 헤더 안에 로고 이미지와 대제목을 한 번에 정렬합니다.
Template_HTML:
<header>
  <img src="logo.svg" width="40">
  <h1>Header Title</h1>
</header>

12.
Guide_EN: Add multiple blocks inside main content.
Guide_KO: 메인 영역 내에 분할된 여러 박스 상자를 작성합니다.
Template_HTML:
<main>
  <div class="box">Card A</div>
  <div class="box">Card B</div>
</main>

13.
Guide_EN: Add emphasize strings inside footer layout.
Guide_KO: 푸터 안의 저작권 설명에 강조 strong 태그를 씁니다.
Template_HTML:
<footer>
  <p>© <strong>Company</strong> 2026</p>
</footer>

14.
Guide_EN: Use nested lists inside the main block.
Guide_KO: 메인 영역에 항목들을 나열하는 순서 없는 목록을 씁니다.
Template_HTML:
<main>
  <ul>
    <li>Item 1</li>
    <li>Item 2</li>
  </ul>
</main>

15.
Guide_EN: Structure header navigation sections.
Guide_KO: 헤더 하위에 바로가기 영역인 div 요소를 엮어 줍니다.
Template_HTML:
<header>
  <h1>Site</h1>
  <div class="nav">Menu</div>
</header>

16.
Guide_EN: Insert action button inside main element.
Guide_KO: 메인 영역에 학습 동작을 수행할 버튼 요소를 올립니다.
Template_HTML:
<main>
  <h2>Start Now</h2>
  <button>Go</button>
</main>

17.
Guide_EN: Use nested structure inside body layouts.
Guide_KO: 전체 바디 태그 아래에 헤더와 메인을 온전히 중첩합니다.
Template_HTML:
<body>
  <header><h1>Header</h1></header>
  <main><p>Body</p></main>
</body>

18.
Guide_EN: Create multi-level headings inside main.
Guide_KO: 메인 안에 여러 등급의 헤더 제목들을 연속 배치합니다.
Template_HTML:
<main>
  <h2>Main Subject</h2>
  <h3>Sub Topic</h3>
</main>

19.
Guide_EN: Embed link buttons inside semantic main.
Guide_KO: 메인 본문 내에 링크가 걸린 동작 버튼을 구현합니다.
Template_HTML:
<!DOCTYPE html>
<html>
<head>
  <title>Semantic Layout</title>
</head>
<body>
  <main>
    <p>Welcome</p>
    <a href="#">
      <button>View</button>
    </a>
  </main>
</body>
</html>

20.
Guide_EN: Assemble complete semantic page layout.
Guide_KO: 헤더, 메인, 푸터를 body 내에 최종 종합 조립 완성합니다.
Template_HTML:
<!DOCTYPE html>
<html>
<head>
  <title>Semantic Layout</title>
</head>
<body>
  <header>
    <h1>Semantic App</h1>
  </header>
  <main>
    <div class="card">
      <h2>Hello</h2>
      <button>OK</button>
    </div>
  </main>
  <footer>
    <p>Done</p>
  </footer>
</body>
</html>
