Lv27.
Title_EN: Position Properties
Title_KO: 상대 위치와 절대 위치 지정
Description_EN: Learn position relative, absolute, fixed, and sticky.
Description_KO: 자신 기준(relative), 부모 기준(absolute), 브라우저 화면 기준(fixed/sticky) 좌표 배치를 배웁니다.

1.
Guide_EN: Assign position relative styling rule.
Guide_KO: 자식의 기준점이 되도록 자기 원래 위치 기준 정렬인 relative를 선언합니다.
Template_HTML:
<div class="rel">Relative</div>
Template_CSS:
.rel {
  position: relative;
}

2.
Guide_EN: Set positional coordinates using top offset.
Guide_KO: 상대 좌표 기준 위에서 아래 방향으로 10픽셀 이격 이동시킵니다.
Template_HTML:
<div class="rel">Offset</div>
Template_CSS:
.rel {
  position: relative;
  top: 10px;
}

3.
Guide_EN: Set positional coordinate offset left side.
Guide_KO: 상대 좌표 기준 왼쪽 벽에서 오른쪽으로 15픽셀 이동시킵니다.
Template_HTML:
<div class="rel">Offset</div>
Template_CSS:
.rel {
  position: relative;
  left: 15px;
}

4.
Guide_EN: Assign position absolute styling rule.
Guide_KO: 부모 기준 절대적 둥둥 떠서 배치되는 absolute 정렬을 부여합니다.
Template_HTML:
<div class="parent">
  <div class="abs">Absolute</div>
</div>
Template_CSS:
.abs {
  position: absolute;
}

5.
Guide_EN: Set coordinates for absolute positions.
Guide_KO: 절대 배치 상자를 부모 기준 탑 10픽셀, 레프트 20픽셀에 고정합니다.
Template_HTML:
<div class="parent"><div class="abs">Abs</div></div>
Template_CSS:
.abs {
  position: absolute;
  top: 10px;
  left: 20px;
}

6.
Guide_EN: Place absolute elements at top right corner.
Guide_KO: 절대 배치 요소를 부모의 오른쪽 상단 꼭짓점에 딱 맞춰 부착시킵니다.
Template_HTML:
<div class="parent"><div class="abs">Abs</div></div>
Template_CSS:
.abs {
  position: absolute;
  top: 0;
  right: 0;
}

7.
Guide_EN: Place absolute elements at bottom right corner.
Guide_KO: 절대 배치 요소를 부모의 오른쪽 하단 꼭짓점 위치에 부착시킵니다.
Template_HTML:
<div class="parent"><div class="abs">Abs</div></div>
Template_CSS:
.abs {
  position: absolute;
  bottom: 0;
  right: 0;
}

8.
Guide_EN: Set parent relative child absolute bindings (cumulative review).
Guide_KO: 부모를 relative로 묶어 자식 absolute의 좌표 한계를 가둡니다.
Template_HTML:
<div class="box"><span class="badge">Tag</span></div>
Template_CSS:
.box {
  position: relative;
}
.badge {
  position: absolute;
  top: 5px;
}

9.
Guide_EN: Assign position fixed styling rule.
Guide_KO: 스크롤을 굴려도 브라우저 뷰포트 화면 특정 곳에 붙박는 fixed를 씁니다.
Template_HTML:
<div class="bar">Fixed</div>
Template_CSS:
.bar {
  position: fixed;
}

10.
Guide_EN: Place fixed bar elements at top edge.
Guide_KO: 스크롤해도 화면 최상단 가장자리에 항상 붙박아 고정되는 바를 설계합니다.
Template_HTML:
<div class="top-bar">Top</div>
Template_CSS:
.top-bar {
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
}

11.
Guide_EN: Place fixed elements at bottom edge.
Guide_KO: 화면 최하단 가장자리에 고정 밀착되어 따라다니는 단추를 고정합니다.
Template_HTML:
<button class="bottom-btn">Top</button>
Template_CSS:
button {
  position: fixed;
  bottom: 10px;
  right: 10px;
}

12.
Guide_EN: Assign position sticky rule.
Guide_KO: 임계점을 지나 스크롤되면 고정 붙박이 상태로 전이되는 sticky를 씁니다.
Template_HTML:
<div class="header">Sticky</div>
Template_CSS:
.header {
  position: sticky;
  top: 0;
}

13.
Guide_EN: Combine top stick coordinate alignments.
Guide_KO: 화면 제일 상단 0에 도달했을 때 끈적하게 붙게 정렬 조율합니다.
Template_HTML:
<nav>Sticky Menu</nav>
Template_CSS:
nav {
  position: sticky;
  top: 0;
  background: white;
}

14.
Guide_EN: Define custom width on absolute elements.
Guide_KO: 둥둥 뜨는 절대 요인에 가로 100% 수치를 줘서 부모폭 전체를 채웁니다.
Template_HTML:
<div class="parent"><div class="abs">A</div></div>
Template_CSS:
.abs {
  position: absolute;
  left: 0;
  width: 100%;
}

15.
Guide_EN: Center absolute element horizontally inside container.
Guide_KO: 둥둥 뜨는 요소를 가로 50% 지점 위치로 옮겨 봅니다.
Template_HTML:
<div class="parent"><div class="abs">C</div></div>
Template_CSS:
.abs {
  position: absolute;
  left: 50%;
}

16.
Guide_EN: Center absolute elements using translate parameters.
Guide_KO: 절반 위치 하에 크기 절반만큼 소급 환원하여 정중앙 수평 정렬합니다.
Template_HTML:
<div class="parent"><div class="abs">Center</div></div>
Template_CSS:
.abs {
  position: absolute;
  left: 50%;
  transform: translateX(-50%);
}

17.
Guide_EN: Control layout navigation menus fixed states.
Guide_KO: 상단 내비게이션 바 전체를 화면 맨 위에 밀착 고정되게 결합합니다.
Template_HTML:
<nav>Nav Header</nav>
Template_CSS:
nav {
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
}

18.
Guide_EN: Add close button absolute inside relative card wrapper.
Guide_KO: 카드 구석 우측 상단 10픽셀에 절대 위치 닫기 단추를 조립합니다.
Template_HTML:
<div class="card"><button class="close">X</button></div>
Template_CSS:
.card {
  position: relative;
}
.close {
  position: absolute;
  top: 10px;
  right: 10px;
}

19.
Guide_EN: Set custom height constraints on relative parent items.
Guide_KO: relative 부모 카드 크기를 세로 200픽셀 수치로 지정해 둡니다.
Template_HTML:
<div class="card">Relative</div>
Template_CSS:
.card {
  position: relative;
  height: 200px;
}

20.
Guide_EN: Assemble absolute badges inside rounded visual cards layout.
Guide_KO: 배경 둥근 카드 모서리 구석에 알림 배지를 절대 위치 조립 완성합니다.
Template_HTML:
<div class="card">
  <span class="badge">New</span>
  <p>Main info text.</p>
</div>
Template_CSS:
.card {
  position: relative;
  border-radius: 8px;
  padding: 10px;
}
.badge {
  position: absolute;
  top: -5px;
  right: -5px;
  background: red;
}
