Title_EN: DOM Text & HTML
Title_KO: 글자 변경과 태그 삽입
Description_EN: Learn innerText, innerHTML, and inputs read.
Description_KO: 가리킨 요소의 일반 텍스트 글자(innerText)와 HTML 동적 태그(innerHTML)를 변경해 봅니다.

1.
Guide_EN: Read inner text content from heading.
Guide_KO: 제목 요소를 선택하여 그 안에 쓰여진 텍스트 내용을 읽어옵니다.
Template_HTML:
<h1>Hello</h1>
Template_JS:
const h1 = document.querySelector("h1");
console.log(h1.innerText);

2.
Guide_EN: Update text content of paragraph dynamically.
Guide_KO: 단락 요소를 선택한 뒤 내부 글자를 다른 문장으로 변경 대입합니다.
Template_HTML:

Template_JS:
const p = document.querySelector("p");
p.innerText = "New text";

3.
Guide_EN: Read input value from text field.
