Lv49.
Title_EN: Theme Switcher App
Title_KO: 다크 모드 테마 스위처
Description_EN: Learn how to toggle dark theme class on body.
Description_KO: HTML/CSS/JS를 결합하여 사용자 동작에 반응하는 테마(다크 모드) 전환 컴포넌트를 조립해 봅니다.

1.
Guide_EN: Select the body element.
Guide_KO: 테마 클래스 제어 대상인 전체 body 요소를 가리켜 확보합니다.
Template_HTML:
<body></body>
Template_JS:
const body = document.body;
console.log(body);

2.
Guide_EN: Add dark class name to body.
Guide_KO: body 클래스 목록에 다크 테마 식별자인 'dark'를 가산 적용합니다.
Template_HTML:
<body></body>
Template_JS:
document.body.classList.add("dark");

3.
Guide_EN: Remove dark class name from body.
Guide_KO: body 클래스 목록에서 'dark' 테마 식별자를 탈거 해제합니다.
Template_HTML:
<body class="dark"></body>
Template_JS:
document.body.classList.remove("dark");

4.
Guide_EN: Toggle theme classes on body element.
Guide_KO: body의 테마 클래스 'dark' 소속 상태를 토글 전환 가동시킵니다.
Template_HTML:
<body></body>
Template_JS:
document.body.classList.toggle("dark");

5.
Guide_EN: Check body active theme state contains.
Guide_KO: 현재 바디가 다크 모드(dark) 상태인지 참/거짓 판단을 조회합니다.
Template_HTML:
<body class="dark"></body>
Template_JS:
const isDark = document.body.classList.contains("dark");
console.log(isDark);

6.
Guide_EN: Create dark mode style structures overrides.
Guide_KO: 바디에 dark 클래스가 붙었을 때의 배경/글씨색 CSS 규칙을 짭니다.
Template_HTML:
<body>Text</body>
Template_CSS:
body.dark {
  background-color: black;
  color: white;
}

7.
Guide_EN: Toggle body dark class inside click listener (cumulative review).
Guide_KO: 테마 단추 클릭 시 body의 'dark' 클래스를 토글 제어해 봅니다.
Template_HTML:
<body><button>Mode</button></body>
Template_JS:
const btn = document.querySelector("button");
btn.addEventListener("click", () => {
  document.body.classList.toggle("dark");
});

8.
Guide_EN: Read default theme state from storage.
Guide_KO: 로컬 저장소에서 사용자가 직전에 썼던 테마 설정 기록을 가져옵니다.
Template_HTML:
<body></body>
Template_JS:
const mode = localStorage.getItem("theme");
console.log(mode);

9.
Guide_EN: Apply storage theme states to body element.
Guide_KO: 읽어온 테마 정보가 'dark'이면 바디에 실제로 다크 클래스를 붙입니다.
Template_HTML:
<body></body>
Template_JS:
const mode = localStorage.getItem("theme");
if (mode === "dark") {
  document.body.classList.add("dark");
}

10.
Guide_EN: Save switched theme state to storage.
Guide_KO: 테마 단추 클릭으로 활성화된 정보를 로컬 저장소에 'dark'로 기재합니다.
Template_HTML:
<body><button>Mode</button></body>
Template_JS:
const btn = document.querySelector("button");
btn.addEventListener("click", () => {
  document.body.classList.toggle("dark");
  localStorage.setItem("theme", "dark");
});

11.
Guide_EN: Toggle and save theme states conditionally.
Guide_KO: 바디 클래스 활성 판단 값에 따라 저장소에 'dark' 혹은 'light'를 기재합니다.
Template_HTML:
<body><button>Mode</button></body>
Template_JS:
const btn = document.querySelector("button");
btn.addEventListener("click", () => {
  document.body.classList.toggle("dark");
  const isDark = document.body.classList.contains("dark");
  localStorage.setItem("theme", isDark ? "dark" : "light");
});

12.
Guide_EN: Restore and sync theme modes on load.
Guide_KO: 저장소 값을 불러와 바디에 클래스명을 동기화하는 절차를 작성합니다.
Template_HTML:
<body></body>
Template_JS:
const mode = localStorage.getItem("theme");
if (mode === "dark") {
  document.body.classList.add("dark");
} else {
  document.body.classList.remove("dark");
}

13.
Guide_EN: Update button text matching current theme state.
Guide_KO: 현재 테마가 다크면 단추 글귀를 'Light Mode'로 가공 변경합니다.
Template_HTML:
<body><button>Mode</button></body>
Template_JS:
const btn = document.querySelector("button");
const isDark = document.body.classList.contains("dark");
btn.innerText = isDark ? "Light" : "Dark";

14.
Guide_EN: Update button text dynamically on click.
Guide_KO: 테마 단추를 누를 때마다 단추 내부 문구가 알맞게 뒤바뀌도록 처리합니다.
Template_HTML:
<body><button>Dark</button></body>
Template_JS:
const btn = document.querySelector("button");
btn.addEventListener("click", () => {
  document.body.classList.toggle("dark");
  const isDark = document.body.classList.contains("dark");
  btn.innerText = isDark ? "Light" : "Dark";
});

15.
Guide_EN: Apply transition animations inside theme CSS styling rules.
Guide_KO: 테마 전환 시 0.3초간 부드럽게 배경이 전이되게 전환 속성을 줍니다.
Template_HTML:
<body></body>
Template_CSS:
body {
  transition: background 0.3s;
}
body.dark {
  background: black;
}

16.
Guide_EN: Add light theme CSS styling rules.
Guide_KO: 일반 라이트 모드일 때의 기본 body 배경색을 하양(#fff)으로 명시합니다.
Template_HTML:
<body></body>
Template_CSS:
body {
  background-color: white;
  color: black;
}

17.
Guide_EN: Combine active class and inputs checkbox status.
Guide_KO: 체크박스 폼 선택 창 선택 여부에 따라 다크 테마 클래스를 제어합니다.
Template_HTML:
<body><input type="checkbox"></body>
Template_JS:
const chk = document.querySelector("input");
chk.addEventListener("change", () => {
  document.body.classList.toggle("dark", chk.checked);
});

18.
Guide_EN: Restore checkbox status from storage states.
Guide_KO: 로컬 저장소 다크 플래그에 맞춰 체크박스 활성화 체크를 동기화합니다.
Template_HTML:
<body><input type="checkbox"></body>
Template_JS:
const chk = document.querySelector("input");
const isDark = localStorage.getItem("theme") === "dark";
chk.checked = isDark;
document.body.classList.toggle("dark", isDark);

19.
Guide_EN: Save checkbox status changes to storage.
Guide_KO: 체크박스 클릭으로 변경된 참/거짓 값을 저장소 테마 키에 반영합니다.
Template_HTML:
<body><input type="checkbox"></body>
Template_JS:
const chk = document.querySelector("input");
chk.addEventListener("change", () => {
  document.body.classList.toggle("dark", chk.checked);
  localStorage.setItem("theme", chk.checked ? "dark" : "light");
});

20.
Guide_EN: Assemble complete interactive theme switcher app components.
Guide_KO: 기존 테마 로드 복원, 변경 클릭 토글, 저장소 저장 절차를 총괄 조립합니다.
Template_HTML:
<body>
  <button class="btn">Dark</button>
</body>
Template_CSS:
body {
  transition: background 0.3s, color 0.3s;
}
body.dark {
  background: #222;
  color: #fff;
}
Template_JS:
const btn = document.querySelector(".btn");
const active = localStorage.getItem("theme") === "dark";
if (active) {
  document.body.classList.add("dark");
  btn.innerText = "Light";
}
btn.addEventListener("click", () => {
  const isDark = document.body.classList.toggle("dark");
  btn.innerText = isDark ? "Light" : "Dark";
  localStorage.setItem("theme", isDark ? "dark" : "light");
});
