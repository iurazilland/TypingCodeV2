Lv28.
Title_EN: z-index Control
Title_KO: 겹침 순서와 입체 레이어
Description_EN: Learn position overlapping and z-index priority.
Description_KO: 요소들이 화면 상에서 앞뒤로 겹칠 때 층층 겹침 순위(z-index)를 조율해 입체를 연출하는 법을 배웁니다.

1.
Guide_EN: Assign z-index priority value rule.
Guide_KO: 화면 앞뒤 입체적 배치 겹침 선순위 z-index 수치 1을 줍니다.
Template_HTML:
<div class="box">Front</div>
Template_CSS:
.box {
  position: relative;
  z-index: 1;
}

2.
Guide_EN: Set high z-index priority formatting.
Guide_KO: 상대적으로 가장 앞쪽에 배치되어 겹쳐지도록 z-index 10을 부여합니다.
Template_HTML:
<div class="pop">Popup</div>
Template_CSS:
.pop {
  position: absolute;
  z-index: 10;
}

3.
Guide_EN: Set negative z-index priority layouts.
Guide_KO: 배경처럼 가장 후순위 밑바닥으로 뒤까져 깔리게 음수 -1을 줍니다.
Template_HTML:
<div class="bg">Background</div>
Template_CSS:
.bg {
  position: absolute;
  z-index: -1;
}

4.
Guide_EN: Combine position relative and z-index overrides.
Guide_KO: 상대 배치 속성 가동 하에 겹침 우선순위 z-index 2를 결합합니다.
Template_HTML:
<div class="item">Item</div>
Template_CSS:
.item {
  position: relative;
  z-index: 2;
}

5.
Guide_EN: Combine position absolute and z-index parameters.
Guide_KO: 절대 배치 설정 하에 z-index 5 순위를 조합해 앞장세웁니다.
Template_HTML:
<div class="alert">Alert</div>
Template_CSS:
.alert {
  position: absolute;
  z-index: 5;
}

6.
Guide_EN: Place z-indexed dialog elements center.
Guide_KO: 모달 대화창을 화면 중앙에 띄우고 z-index 100을 배정합니다.
Template_HTML:
<div class="modal">Dialog</div>
Template_CSS:
.modal {
  position: fixed;
  z-index: 100;
}

7.
Guide_EN: Place z-indexed dropdown overlays.
Guide_KO: 하위 요소에 가려지지 않게 드롭다운 메뉴 z-index 50을 줍니다.
Template_HTML:
<nav><div class="drop">Dropdown</div></nav>
Template_CSS:
.drop {
  position: absolute;
  z-index: 50;
}

8.
Guide_EN: Set parent relative child absolute z-index layers (cumulative review).
Guide_KO: 부모 밑에 겹치는 자식의 앞면 배치를 z-index 2로 안착시킵니다.
Template_HTML:
<div class="card"><div class="badge">New</div></div>
Template_CSS:
.card {
  position: relative;
}
.badge {
  position: absolute;
  z-index: 2;
}

9.
Guide_EN: Create dark dim overlays background structures.
Guide_KO: 화면 전체를 검게 가리는 딤드 배경 z-index 90을 구성합니다.
Template_HTML:
<div class="dim">Dim background</div>
Template_CSS:
.dim {
  position: fixed;
  z-index: 90;
  background: rgba(0,0,0,0.5);
}

10.
Guide_EN: Place highest modal dialogs above background dims.
Guide_KO: 대화창을 딤드 배경보다 앞인 z-index 100으로 올려 정렬합니다.
Template_HTML:
<div class="modal">Popup</div>
Template_CSS:
.modal {
  position: fixed;
  z-index: 100;
}

11.
Guide_EN: Control layout navigation fixed z-index overrides.
Guide_KO: 고정 상단 메뉴가 본문 스크롤에 묻히지 않게 z-index 10을 부여합니다.
Template_HTML:
<nav>Fixed Header</nav>
Template_CSS:
nav {
  position: fixed;
  z-index: 10;
}

12.
Guide_EN: Target overlapping sibling absolute blocks.
Guide_KO: 자식 A와 B의 z-index를 각각 1과 2로 차등 두어 앞뒤 정렬합니다.
Template_HTML:
<div class="box-a">A</div>
<div class="box-b">B</div>
Template_CSS:
.box-a { position: absolute; z-index: 1; }
.box-b { position: absolute; z-index: 2; }

13.
Guide_EN: Target details overlapping structures.
Guide_KO: 상세 보기 카드 상자의 z-index 우선도를 3으로 상향 조정합니다.
Template_HTML:
<div class="detail-card">Detail</div>
Template_CSS:
.detail-card {
  position: absolute;
  z-index: 3;
}

14.
Guide_EN: Combine z-index and opacity styles.
Guide_KO: 반투명하게 비치는 플로팅 메뉴 창의 z-index를 99로 높여 둡니다.
Template_HTML:
<div class="float">Float</div>
Template_CSS:
.float {
  position: fixed;
  z-index: 99;
  opacity: 0.9;
}

15.
Guide_EN: Combine z-index and rounded card styling elements.
Guide_KO: 둥글고 입체적인 모달 카드 상자를 z-index 20으로 조립합니다.
Template_HTML:
<div class="modal-card">Card</div>
Template_CSS:
.modal-card {
  position: fixed;
  z-index: 20;
  border-radius: 6px;
}

16.
Guide_EN: Set relative positioning z-index on hover lists.
Guide_KO: 리스트 특정 항목에 마우스를 올릴 것에 대비해 z-index를 높입니다.
Template_HTML:
<ul><li class="hover">Item</li></ul>
Template_CSS:
li.hover {
  position: relative;
  z-index: 5;
}

17.
Guide_EN: Add close button absolute inside z-indexed modals.
Guide_KO: z-index 100 대화창 내에 절대 좌표 닫기 단추를 조립합니다.
Template_HTML:
<div class="modal"><button class="close">X</button></div>
Template_CSS:
.modal {
  position: fixed;
  z-index: 100;
}
.close {
  position: absolute;
}

18.
Guide_EN: Combine parent flex and children z-indexes alignments.
Guide_KO: 플렉스 부모 아래 자식 중 일부만 절대 겹침 z-index를 부여합니다.
Template_HTML:
<div class="flex"><div class="tip">Tip</div></div>
Template_CSS:
.tip {
  position: absolute;
  z-index: 15;
}

19.
Guide_EN: Set spacing values on absolute z-indexed badges.
Guide_KO: 알림 배지 위치 좌표와 z-index 2 순위를 조합 배정합니다.
Template_HTML:
<span class="badge">1</span>
Template_CSS:
.badge {
  position: absolute;
  right: 5px;
  z-index: 2;
}

20.
Guide_EN: Assemble z-indexed layout modal popup containers.
Guide_KO: 화면 딤 배경과 실제 모달 메시지 윈도우 조립을 최종 완성합니다.
Template_HTML:
<div class="dim"></div>
<div class="modal">
  <h2>Saved</h2>
  <button>Ok</button>
</div>
Template_CSS:
.dim {
  position: fixed;
  z-index: 90;
  background: black;
}
.modal {
  position: fixed;
  z-index: 100;
  background: white;
}
