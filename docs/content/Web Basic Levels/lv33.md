Lv33.
Title_EN: JS Conditional Branches
Title_KO: 조건 분기와 논리 연산
Description_EN: Learn if, else if, else, AND, OR, and NOT.
Description_KO: 비교 연산자와 if/else 문, 그리고 다중 조건을 판단하는 논리 연산자(&&, ||, !)의 활용을 배웁니다.

1.
Guide_EN: Write a simple if condition checking true values.
Guide_KO: 조건 괄호가 참(true)일 때 실행되는 기본 if 문을 선언합니다.
Template_JS:
if (true) {
  console.log("True");
}

2.
Guide_EN: Compare two numbers using greater than operator.
Guide_KO: 비교 연산자(>)를 이용하여 수치 대소 관계 참 판별을 지시합니다.
Template_JS:
let score = 90;
if (score > 80) {
  console.log("Pass");
}

3.
Guide_EN: Add else block to handle alternative outcomes.
Guide_KO: 조건 만족 실패 시의 예외 처리를 담당하는 else 문을 덧붙입니다.
Template_JS:
let age = 15;
if (age >= 20) {
  console.log("Adult");
} else {
  console.log("Kid");
}

4.
Guide_EN: Check equality using triple equals operator.
Guide_KO: 값과 데이터 형식이 완전 일치하는지 판별하는 삼중 등호(===)를 씁니다.
Template_JS:
let state = "ok";
if (state === "ok") {
  console.log("Run");
}

5.
Guide_EN: Check inequality using not equal operator.
Guide_KO: 서로 다른 값인지(같지 않은지) 판별하는 부정 비교(!==)를 씁니다.
Template_JS:
let status = "error";
if (status !== "success") {
  console.log("Fail");
}

6.
Guide_EN: Compare numbers using less than or equal operator.
Guide_KO: 수치가 특정 값보다 작거나 같은 이하(<=) 관계를 판단합니다.
Template_JS:
let temp = 25;
if (temp <= 30) {
  console.log("Good");
}

7.
Guide_EN: Add else if statement checking multiple states.
Guide_KO: 여러 개별 조건을 연달아 확인하는 else if 구문을 작성합니다.
Template_JS:
let score = 75;
if (score >= 90) {
  console.log("A");
} else if (score >= 70) {
  console.log("B");
}

8.
Guide_EN: Combine if, else if, and else blocks sequentially.
Guide_KO: if, else if, else의 3단계 완전한 다중 분기를 구성합니다.
Template_JS:
let num = 0;
if (num > 0) {
  console.log("+");
} else if (num < 0) {
  console.log("-");
} else {
  console.log("0");
}

9.
Guide_EN: Use logical AND operator to combine rules (cumulative review).
Guide_KO: 두 조건이 모두 만족해야 참이 되는 엠퍼샌드(&&) 연산을 씁니다.
Template_JS:
let age = 25;
if (age >= 20 && age < 30) {
  console.log("20s");
}

10.
Guide_EN: Use logical OR operator for alternative rules.
Guide_KO: 둘 중 하나라도 충족하면 참이 되는 버티컬 바(||) 연산을 씁니다.
Template_JS:
let code = 404;
if (code === 404 || code === 500) {
  console.log("Error");
}

11.
Guide_EN: Use logical NOT operator to negate boolean values.
Guide_KO: 조건 판단 참을 거짓으로 역전시키는 느낌표(!) 연산자를 씁니다.
Template_JS:
let active = false;
if (!active) {
  console.log("Offline");
}

12.
Guide_EN: Combine variable updates inside conditional blocks.
Guide_KO: 조건 만족 시 누적 변수에 가산 처리를 더하는 블록을 만듭니다.
Template_JS:
let bonus = 0;
let score = 95;
if (score >= 90) {
  bonus += 10;
}
console.log(bonus);

13.
Guide_EN: Compare variables string properties inside conditions.
Guide_KO: 문자열 텍스트 변수 내용에 특정 글자가 포함되었는지 분기합니다.
Template_JS:
let url = "/about";
if (url === "/about") {
  console.log("About Page");
}

14.
Guide_EN: Nest if statements inside other if blocks.
Guide_KO: if 조건이 참인 영역 내부 공간에서 다시 2차 if 판별을 겹칩니다.
Template_JS:
let logged = true;
let admin = true;
if (logged) {
  if (admin) {
    console.log("Admin ok");
  }
}

15.
Guide_EN: Combine nested checks and variables evaluations.
Guide_KO: 중첩된 조건 분기 속에서 일반 변수 값을 연산해 대입 출력합니다.
Template_JS:
let login = true;
let val = 0;
if (login) {
  val = 100;
}
console.log(val);

16.
Guide_EN: Compare floating calculations inside conditions.
Guide_KO: 소수점 계산 결과를 바탕으로 조건의 참/거짓 판단을 유도합니다.
Template_JS:
let ratio = 0.55;
if (ratio > 0.5) {
  console.log("High");
}

17.
Guide_EN: Target string structures variables checking details.
Guide_KO: HTML 클래스명 텍스트가 active 상태인지 조건 비교해 봅니다.
Template_JS:
let activeClass = "active";
if (activeClass === "active") {
  console.log("Show");
}

18.
Guide_EN: Evaluate active states utilizing boolean flags.
Guide_KO: 참/거짓 플래그 변수 참값 여부를 괄호 안에 바로 대입해 분기합니다.
Template_JS:
let hasError = true;
if (hasError) {
  console.log("Alert");
}

19.
Guide_EN: Check numeric remainder outputs in branches.
Guide_KO: 수치를 나눈 나머지가 0인지 체크해 짝수 여부를 판단해 봅니다.
Template_JS:
let num = 8;
if (num % 2 === 0) {
  console.log("Even");
}

20.
Guide_EN: Assemble complex logic combining AND, OR, and negation rules.
Guide_KO: 여러 논리 연산자와 복합 분기 출력 단계를 종합 구성 완성합니다.
Template_JS:
let level = 10;
let points = 50;
if (level >= 10 && (points > 40 || points === 0)) {
  console.log("Qualified");
} else {
  console.log("Disqualified");
}
