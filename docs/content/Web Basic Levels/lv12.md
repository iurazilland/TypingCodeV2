Lv12.
Title_EN: Sidebar & Article Navigation
Title_KO: 사이드바와 본문 구조
Description_EN: Learn how to use nav, aside, and article elements.
Description_KO: 메뉴 링크를 담는 nav, 보조 정보 aside, 독립된 글 article 태그를 배웁니다.

1.
Guide_EN: Create a page navigation container.
Guide_KO: 메뉴 링크들을 묶어줄 내비게이션 영역 태그를 생성합니다.
Template_HTML:
<nav>
  <a href="#">Link</a>
</nav>

2.
Guide_EN: Add multiple links inside navigation.
Guide_KO: 내비게이션 안에 여러 개 이동 링크를 가로로 배치합니다.
Template_HTML:
<nav>
  <a href="#">Home</a>
  <a href="#">About</a>
</nav>

3.
Guide_EN: Nest link list inside navigation elements.
Guide_KO: 내비게이션 안에 목록 태그를 사용해 깔끔하게 정렬합니다.
Template_HTML:
<nav>
  <ul>
    <li><a href="#">Menu</a></li>
  </ul>
</nav>

4.
Guide_EN: Create an aside sidebar block container.
Guide_KO: 페이지 주변부 부가 정보용 사이드바 영역 태그를 생성합니다.
Template_HTML:
<aside>
  <h3>Sidebar</h3>
</aside>

5.
Guide_EN: Add descriptive paragraph inside sidebar aside.
Guide_KO: 사이드바 영역 내부에 부가 설명 문장을 배치합니다.
Template_HTML:
<aside>
  <h3>Sidebar</h3>
  <p>Info text.</p>
</aside>

6.
Guide_EN: Create an article post element.
Guide_KO: 페이지의 독립적 정보 기사글 본문을 담는 영역 태그를 생성합니다.
Template_HTML:
<article>
  <h2>Post Title</h2>
</article>

7.
Guide_EN: Add text paragraph inside article tags.
Guide_KO: 기사글 본문 내부에 실제 포스트 문장 단락을 구성합니다.
Template_HTML:
<article>
  <h2>Post Title</h2>
  <p>Story details.</p>
</article>

8.
Guide_EN: Combine nav layout and aside elements.
Guide_KO: 내비게이션 메뉴와 사이드바 영역을 함께 정렬 조립합니다.
Template_HTML:
<nav><a href="#">Link</a></nav>
<aside><p>Sidebar</p></aside>

9.
Guide_EN: Combine article content and aside panels.
Guide_KO: 기사글 영역과 정보 패널 사이드바를 연달아 배치합니다.
Template_HTML:
<article><h2>News</h2></article>
<aside><p>Ad link</p></aside>

10.
Guide_EN: Use subheadings inside articles.
Guide_KO: 기사글 영역 내부에 소주제 제목 요소를 조립합니다.
Template_HTML:
<article>
  <h2>Main News</h2>
  <h3>Detail Header</h3>
</article>

11.
Guide_EN: Add links inside article descriptions.
Guide_KO: 기사글 본문 안에 자세히 보기 외부 이동 링크를 붙입니다.
Template_HTML:
<article>
  <h2>Post</h2>
  <p>Read more: <a href="#">Link</a></p>
</article>

12.
Guide_EN: Embed images inside article contents.
Guide_KO: 기사글 본문 영역 내부에 관련 일러스트 이미지를 올립니다.
Template_HTML:
<article>
  <h2>Post</h2>
  <img src="photo.svg" width="60">
</article>

13.
Guide_EN: Use navigation layouts inside page headers.
Guide_KO: 헤더 영역 내부에 상단 내비게이션 바를 안착시킵니다.
Template_HTML:
<header>
  <nav>
    <a href="#">Home</a>
  </nav>
</header>

14.
Guide_EN: Place article elements inside main page contents.
Guide_KO: 메인 영역 내에 독립 기사글 본문을 품어 정렬 설계합니다.
Template_HTML:
<main>
  <article>
    <h2>Main Article</h2>
  </article>
</main>

15.
Guide_EN: Add multiple article lists inside main structure.
Guide_KO: 메인 본문 내에 여러 개의 기사글 상자를 연속 배열합니다.
Template_HTML:
<main>
  <article>Post 1</article>
  <article>Post 2</article>
</main>

16.
Guide_EN: Place list items inside navigation blocks.
Guide_KO: 내비게이션 내부에 2개의 목록 메뉴 링크를 정렬 배치합니다.
Template_HTML:
<nav>
  <ul>
    <li><a href="#">A</a></li>
    <li><a href="#">B</a></li>
  </ul>
</nav>

17.
Guide_EN: Add close action button inside sidebar asides.
Guide_KO: 사이드바 영역 안에 닫기 동작을 지원할 버튼을 올립니다.
Template_HTML:
<aside>
  <h3>Sidebar</h3>
  <button>Close</button>
</aside>

18.
Guide_EN: Nest nav items inside layout sections.
Guide_KO: 본문 구획을 가르는 섹션 내부에 정보 내비게이션을 배치합니다.
Template_HTML:
<section>
  <nav><a href="#">Sub Menu</a></nav>
</section>

19.
Guide_EN: Wrap article lists inside semantic body elements.
Guide_KO: 바디 영역 아래에 내비게이션 바와 기사글을 조립합니다.
Template_HTML:
<!DOCTYPE html>
<html>
<head>
  <title>Sidebar & Navigation</title>
</head>
<body>
  <nav><a href="#">Home</a></nav>
  <article><h2>Post</h2></article>
</body>
</html>

20.
Guide_EN: Assemble complete layout navigation architecture.
Guide_KO: 내비바, 포스트 영역, 사이드바를 하나의 레이아웃으로 조립합니다.
Template_HTML:
<!DOCTYPE html>
<html>
<head>
  <title>Sidebar & Navigation</title>
</head>
<body>
  <header>
    <nav><a href="#">News</a></nav>
  </header>
  <main>
    <article>
      <h2>Post</h2>
      <p>Body info.</p>
    </article>
    <aside>
      <p>Sidebar info.</p>
    </aside>
  </main>
</body>
</html>
