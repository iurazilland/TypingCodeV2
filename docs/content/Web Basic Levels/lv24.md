Lv24.
Title_EN: Flexbox Children
Title_KO: 플렉스 자식 크기 조율
Description_EN: Learn flex-grow, flex-shrink, and flex-basis.
Description_KO: 플렉스 자식들의 여백 확장(flex-grow), 수축 방지(flex-shrink), 초기 크기(flex-basis)를 배웁니다.

1.
Guide_EN: Assign flex-grow parameter to fill space.
Guide_KO: 지정된 자식이 남은 공간을 독점하여 넓어지도록 grow 수치를 줍니다.
Template_HTML:
<div class="container">
  <div class="grow-item">Grow</div>
</div>
Template_CSS:
.grow-item {
  flex-grow: 1;
}

2.
Guide_EN: Set flex-grow on multiple siblings elements.
Guide_KO: 동일 클래스를 지닌 형제 모두 넓어져 공간을 균등 분할합니다.
Template_HTML:
<div class="container"><div class="item">A</div><div class="item">B</div></div>
Template_CSS:
.item {
  flex-grow: 1;
}

3.
Guide_EN: Set custom flex-grow proportions.
Guide_KO: 자식 A가 자식 B보다 2배 비율로 여유 공간을 더 가져가게 짭니다.
Template_HTML:
<div class="container"><div class="grow-two">A</div><div>B</div></div>
Template_CSS:
.grow-two {
  flex-grow: 2;
}

4.
Guide_EN: Assign flex-shrink to prevent narrow squeeze.
Guide_KO: 공간이 비좁아져도 자식이 작아지지 않게 수축 방지 0을 줍니다.
Template_HTML:
<div class="container"><div class="no-shrink">A</div></div>
Template_CSS:
.no-shrink {
  flex-shrink: 0;
}

5.
Guide_EN: Assign flex-basis initial sizes width.
Guide_KO: 아이템의 배치 시작 기본 초기 규격 크기를 150픽셀로 잡습니다.
Template_HTML:
<div class="container"><div class="base-item">Base</div></div>
Template_CSS:
.base-item {
  flex-basis: 150px;
}

6.
Guide_EN: Combine grow and basis properties.
Guide_KO: 초기 크기 100픽셀 수립 하에 빈 공간 grow 확장도 같이 켭니다.
Template_HTML:
<div class="container"><div class="flex-item">Item</div></div>
Template_CSS:
.flex-item {
  flex-grow: 1;
  flex-basis: 100px;
}

7.
Guide_EN: Combine shrink and basis formatting.
Guide_KO: 초기 크기 200픽셀 수립 하에 수축만 불가로 고정 보호합니다.
Template_HTML:
<div class="container"><div class="fix-item">Fix</div></div>
Template_CSS:
.fix-item {
  flex-shrink: 0;
  flex-basis: 200px;
}

8.
Guide_EN: Set flex shorthand parameters in layouts.
Guide_KO: 속성들을 한 단어로 단축(flex: grow shrink basis) 표현해 봅니다.
Template_HTML:
<div class="container"><div class="flex-short">Short</div></div>
Template_CSS:
.flex-short {
  flex: 1 0 120px;
}

9.
Guide_EN: Set auto grow flex values on item details.
Guide_KO: 기본값 유지 상태에서 자유 확장이 되도록 단축 단어를 씁니다.
Template_HTML:
<div class="container"><div class="flex-auto">Auto</div></div>
Template_CSS:
.flex-auto {
  flex: auto;
}

10.
Guide_EN: Set none shrink flex values.
Guide_KO: 줄어들지도 늘어나지도 않는 고유 깡통 속성단어를 선언합니다.
Template_HTML:
<div class="container"><div class="flex-none">None</div></div>
Template_CSS:
.flex-none {
  flex: none;
}

11.
Guide_EN: Apply children flex-grow in layouts navigation (cumulative review).
Guide_KO: 내비바 한가운데 검색 입력 상자만 넓게 확장시켜 봅니다.
Template_HTML:
<nav><span>Logo</span><input class="search"><span>Btn</span></nav>
Template_CSS:
.search {
  flex-grow: 1;
}

12.
Guide_EN: Combine navigation items base width limits.
Guide_KO: 메뉴 링크들이 최소 80픽셀 초기 너비를 확보하게 만듭니다.
Template_HTML:
<nav><a href="#">Home</a></nav>
Template_CSS:
nav a {
  flex-basis: 80px;
  text-align: center;
}

13.
Guide_EN: Add shrink zero constraint on logo images.
Guide_KO: 화면이 좁혀져도 헤더의 로고 아이콘 크기가 훼손되지 않게 막습니다.
Template_HTML:
<header><img class="logo" src="logo.svg"></header>
Template_CSS:
.logo {
  flex-shrink: 0;
}

14.
Guide_EN: Set flex-grow inside article components.
Guide_KO: 게시글 본문 목록 중 텍스트 본문 영역만 넓어지도록 지정합니다.
Template_HTML:
<article><div class="img"></div><div class="txt">Text</div></article>
Template_CSS:
.txt {
  flex-grow: 1;
}

15.
Guide_EN: Combine base width layouts inside sidebar columns.
Guide_KO: 사이드바 컬럼의 가로폭 초기 값을 200픽셀로 제한합니다.
Template_HTML:
<aside class="sidebar">Aside</aside>
Template_CSS:
.sidebar {
  flex-basis: 200px;
  flex-shrink: 0;
}

16.
Guide_EN: Set align-self properties on custom items.
Guide_KO: 나머지 형제들과 달리 혼자만 수직 끝선(align-self)에 맞춥니다.
Template_HTML:
<div class="parent"><div>A</div><div class="self-item">B</div></div>
Template_CSS:
.self-item {
  align-self: flex-end;
}

17.
Guide_EN: Combine self-align center rules.
Guide_KO: 플렉스 부모 안에서 혼자만 수직 중앙에 맞춰 서게 지시합니다.
Template_HTML:
<div class="parent"><div>A</div><div class="self-mid">B</div></div>
Template_CSS:
.self-mid {
  align-self: center;
}

18.
Guide_EN: Control layout buttons flex growths.
Guide_KO: 버튼 그룹 내 첫 버튼만 남은 가로폭을 채우도록 연출합니다.
Template_HTML:
<div class="group"><button class="main-btn">Ok</button></div>
Template_CSS:
.main-btn {
  flex-grow: 1;
}

19.
Guide_EN: Target flex children order priority adjustments.
Guide_KO: 시각적 배치 나열 순서 번호(order)를 강제로 맨 앞으로 당깁니다.
Template_HTML:
<div class="parent"><div>A</div><div class="first-item">B</div></div>
Template_CSS:
.first-item {
  order: -1;
}

20.
Guide_EN: Assemble flex child properties inside pages layout.
Guide_KO: 로고 고정 수축 방지와 본문 확장을 조합한 상단을 최종 완성합니다.
Template_HTML:
<nav>
  <img class="logo" src="logo.svg">
  <input class="search" placeholder="Search">
</nav>
Template_CSS:
nav {
  display: flex;
  align-items: center;
}
.logo {
  flex-shrink: 0;
}
.search {
  flex-grow: 1;
  margin-left: 10px;
}
