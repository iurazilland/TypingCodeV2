Lv17.
Title_EN: Class & ID Selectors
Title_KO: 클래스와 ID 선택자
Description_EN: Learn how to style elements using .class and #id.
Description_KO: 특정 그룹을 나타내는 클래스(.)와 고유한 대상을 나타내는 ID(#) 선택자 규칙을 배웁니다.

1.
Guide_EN: Target class name with color rule.
Guide_KO: 클래스명이 'accent'인 단락 요소를 주황색 스타일 지정합니다.
Template_HTML:
<p class="accent">Accent text</p>
Template_CSS:
.accent {
  color: orange;
}

2.
Guide_EN: Target unique ID element styling rules.
Guide_KO: 아이디명이 'main-title'인 단독 요소만 골라 하늘색으로 물들입니다.
Template_HTML:
<h1 id="main-title">Title</h1>
Template_CSS:
#main-title {
  color: skyblue;
}

3.
Guide_EN: Set size on target container class.
Guide_KO: 클래스명이 'content'인 박스의 글꼴 크기를 크게 조절합니다.
Template_HTML:
<div class="content">Info</div>
Template_CSS:
.content {
  font-size: 20px;
}

4.
Guide_EN: Combine class selectors and weight configs.
Guide_KO: 특정 경고 클래스 텍스트를 두껍고 노란색으로 처리합니다.
Template_HTML:
<span class="warn">Warning</span>
Template_CSS:
.warn {
  color: gold;
  font-weight: bold;
}

5.
Guide_EN: Define custom styles for action buttons.
Guide_KO: 클래스가 'btn'인 단추의 글씨 크기와 색상을 지정해 봅니다.
Template_HTML:
<button class="btn">Action</button>
Template_CSS:
.btn {
  color: white;
  font-size: 14px;
}

6.
Guide_EN: Override background colors using ID properties.
Guide_KO: 페이지 고유 상단인 ID 'header' 영역 배경색을 지정해 봅니다.
Template_HTML:
<header id="main-header">Header</header>
Template_CSS:

  background: black;
}

7.
Guide_EN: Combine element selector and class rules.

8.
Guide_EN: Target nested link class elements.

9.
Guide_EN: Override classes using ID specificity.
