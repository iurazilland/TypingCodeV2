Lv14.
Title_EN: HTML5 Multimedia
Title_KO: 멀티미디어 오디오와 비디오
Description_EN: Learn how to embed audio and video players.
Description_KO: 웹페이지에 음악과 영상을 삽입하고 제어하는 audio와 video 태그를 배웁니다.

1.
Guide_EN: Create audio tag element.
Guide_KO: 배경 음악 등을 재생할 오디오 요소를 선언해 봅니다.
Template_HTML:
<audio src="music.mp3"></audio>

2.
Guide_EN: Add controls UI to audio tags.
Guide_KO: 사용자가 재생/조절할 수 있는 컨트롤 버튼 패널을 띄웁니다.
Template_HTML:
<audio src="music.mp3" controls></audio>

3.
Guide_EN: Create video tag element.
Guide_KO: 영상을 상영할 수 있는 비디오 영역 요소를 선언해 봅니다.
Template_HTML:
<video src="clip.mp4"></video>

4.
Guide_EN: Add controls UI to video tags.
Guide_KO: 비디오 영역 하단에 컨트롤 바 인터페이스를 노출시킵니다.
Template_HTML:
<video src="clip.mp4" controls></video>

5.
Guide_EN: Set dimensions width for video layout.
Guide_KO: 비디오의 가로 크기(폭) 수치를 명시적으로 제한 설정합니다.
Template_HTML:
<video src="clip.mp4"  controls width="200">
</video>

6.
Guide_EN: Add alternative texts inside audio tags.
Guide_KO: 지원 불가 브라우저를 위해 대체 문구를 오디오 태그 안에 씁니다.
Template_HTML:
<audio src="music.mp3" controls>
  Audio unavailable.
</audio>

7.
Guide_EN: Add alternative texts inside video tags.
Guide_KO: 미지원 브라우저용 안내 글귀를 비디오 태그 내부에 배치합니다.
Template_HTML:
<video src="clip.mp4"  controls width="180">
  Video unavailable.
</video>

8.
Guide_EN: Place audio layout inside box container.
Guide_KO: 디자인 영역을 나누는 div 상자 안에 오디오 플레이어를 둡니다.
Template_HTML:
<div class="player">
  <audio src="audio.mp3" controls></audio>
</div>

9.
Guide_EN: Place video layout inside box container.
Guide_KO: 레이아웃 카드 div 안에 비디오 플레이어 공간을 병합합니다.
Template_HTML:
<div class="card">
  <video src="video.mp4" controls width="200"></video>
</div>

10.
Guide_EN: Nest audio tag inside page footer.
Guide_KO: 페이지 하단 저작권 표시 옆에 사운드 오디오를 배치해 봅니다.
Template_HTML:
<footer>
  <audio src="sound.mp3" controls></audio>
</footer>

11.
Guide_EN: Place video tags inside article bodies.
Guide_KO: 게시글 본문 기사 블록 영역 내부에 동영상 요소를 중첩합니다.
Template_HTML:
<article>
  <h2>Live Video</h2>
  <video src="live.mp4"  controls width="220">
  </video>
</article>

12.
Guide_EN: Insert descriptive titles above audio.
Guide_KO: 오디오 플레이어 상단에 트랙 이름을 알려주는 제목을 넣습니다.
Template_HTML:
<div class="track">
  <h3>Track 01</h3>
  <audio src="song.mp3" controls></audio>
</div>

13.
Guide_EN: Insert descriptions paragraph below video.
Guide_KO: 비디오 화면 아래에 영상에 관한 간략한 소개 문장을 배치합니다.
Template_HTML:
<div class="movie">
  <video src="film.mp4" controls width="200"></video>
  <p>Promo Video</p>
</div>

14.
Guide_EN: Add source tag alternative fallbacks.
Guide_KO: 오디오 파일의 다중 확장자 지원을 위해 source 태그를 씁니다.
Template_HTML:
<audio controls>
  <source src="track.mp3"  type="audio/mpeg">
</audio>

15.
Guide_EN: Add video source tag alternative elements.
Guide_KO: 비디오 파일 호환성 향상을 위해 내부 source 경로를 씁니다.
Template_HTML:
<video controls width="180">
  <source src="movie.mp4"  type="video/mp4">
</video>

16.
Guide_EN: Use multiple sources inside video player.
Guide_KO: 동영상 플레이어 안에 mp4와 webm 두 가지 파일을 선언합니다.
Template_HTML:
<video controls width="200">
  <source src="vid.mp4"  type="video/mp4">
  <source src="vid.webm"  type="video/webm">
</video>

17.
Guide_EN: Combine required forms and audio player layouts.
Guide_KO: 폼 입력창 아래에 배경 가이드 소리를 들려줄 오디오를 배치합니다.
Template_HTML:
<form>
  <input type="text" placeholder="Listen">
  <audio src="guide.mp3" controls></audio>
</form>

18.
Guide_EN: Nest media components inside main structural sections.
Guide_KO: 메인 본문 영역의 섹션 안에 홍보 영상을 안착시켜 정렬합니다.
Template_HTML:
<main>
  <section>
    <h2>Intro Movie</h2>
    <video src="intro.mp4" controls width="200"></video>
  </section>
</main>

19.
Guide_EN: Combine navigation and audio controls.
Guide_KO: 상단 내비게이션 바 하단에 재생용 오디오 바를 부착해 봅니다.
Template_HTML:
<!DOCTYPE html>
<html>
<head>
  <title>Multimedia</title>
</head>
<body>
  <nav>
    <a href="#">Home</a>
    <audio src="bgm.mp3" controls></audio>
  </nav>
</body>
</html>

20.
Guide_EN: Assemble complete layout containing header, nav, video, footer.
Guide_KO: 내비바, 비디오 카드, 소개글, 푸터를 최종 조립 배치합니다.
Template_HTML:
<!DOCTYPE html>
<html>
<head>
  <title>Multimedia</title>
</head>
<body>
  <header>
    <nav><a href="#">Home</a></nav>
  </header>
  <main>
    <div class="video-card">
      <h2>Tutorial</h2>
      <video src="tut.mp4" controls width="200"></video>
      <p>Start learning.</p>
    </div>
  </main>
  <footer>
    <p>© 2026</p>
  </footer>
</body>
</html>
