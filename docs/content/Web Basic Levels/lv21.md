Lv21.
Title_EN: Display Properties
Title_KO: 블록과 인라인 상자 배치
Description_EN: Learn display block, inline, and inline-block.
Description_KO: 요소의 한 줄 독점(block), 필요한 크기만큼만 가로 나열(inline/inline-block) 성질을 배웁니다.

1.
Guide_EN: Assign display block rule to force block-level behavior.
Guide_KO: 요소가 한 줄 영역을 독점하여 줄바꿈되게 만드는 block 속성을 가해 봅니다.
Template_HTML:
<span>Block</span>
Template_CSS:
span {
  display: block;
}

2.
Guide_EN: Assign display inline rule to let elements flow horizontally.
Guide_KO: 요소가 필요 최소한의 크기만 갖고 가로로 나열되게 inline 속성을 줍니다.
Template_HTML:
<div>Inline</div>
Template_CSS:
div {
  display: inline;
}

3.
Guide_EN: Assign display inline-block rule to support width settings.
Guide_KO: 가로 배치를 유지하면서 가로세로 픽셀 크기 설정이 되도록 속성을 지정합니다.
Template_HTML:
<span>Item</span>
Template_CSS:
span {
  display: inline-block;
  width: 60px;
}

4.
Guide_EN: Combine display inline-block and backgrounds.
Guide_KO: 가로 배열 상자 크기에 배경색을 칠해서 렌더링 영역을 명확히 확인합니다.
Template_HTML:
<span>Box</span>
Template_CSS:
span {
  display: inline-block;
  background: gray;
}

5.
Guide_EN: Set padding inside horizontal inline-block spans.
Guide_KO: 가로 배열 상자 안쪽 사방에 패딩 여백 8픽셀을 부여하여 여유를 둡니다.
Template_HTML:
<span>Span</span>
Template_CSS:
span {
  display: inline-block;
  padding: 8px;
}

6.
Guide_EN: Add borders around inline-block box containers.
Guide_KO: 가로 배열 상자 바깥에 얇은 외곽 테두리 실선 1픽셀을 둘러 장식합니다.
Template_HTML:
<span>A</span>
<span>B</span>
Template_CSS:
span {
  display: inline-block;
  border: 1px solid;
}

7.
Guide_EN: Define display block properties inside layout containers (cumulative review).
Guide_KO: 목록 안의 링크 글자 상자를 블록화하여 전체 영역을 클릭 가능하게 하며 글자색을 하늘색으로 바꿉니다.
Template_HTML:
<nav><a href="#">Home</a></nav>
Template_CSS:
nav a {
  display: block;
  color: skyblue;
}

8.
Guide_EN: Combine block displaying rules and background fills.
Guide_KO: 대제목 제목 요소를 한 줄 독점 블록화하고 노란색 배경을 채워 봅니다.
Template_HTML:
<h1>Heading</h1>
Template_CSS:
h1 {
  display: block;
  background: yellow;
}

9.
Guide_EN: Set height constraints inside inline-block items.
Guide_KO: 가로 배열 상자 세로 높이 크기를 50픽셀 수치로 지정해 봅니다.
Template_HTML:
<span>Box</span>
Template_CSS:
span {
  display: inline-block;
  height: 50px;
}

10.
Guide_EN: Apply height and width combinations on inline blocks.
Guide_KO: 가로 배열 상자 가로와 세로 높이 규격을 80픽셀 동일 크기로 맞춥니다.
Template_HTML:
<span>Square</span>
Template_CSS:
span {
  display: inline-block;
  width: 80px;
  height: 80px;
}

11.
Guide_EN: Add margin separating inline-block elements.
Guide_KO: 가로 배열 상자들 사이에 마진 간격 10픽셀을 배치해 나란히 밀어냅니다.
Template_HTML:
<span>A</span>
<span>B</span>
Template_CSS:
span {
  display: inline-block;
  margin-right: 10px;
}

12.
Guide_EN: Set line heights inside block displaying nodes.
Guide_KO: 줄바꿈 블록 요소의 위아래 높이를 1.5 비율로 유연하게 다듬어 봅니다.
Template_HTML:
<div>Content</div>
Template_CSS:
div {
  display: block;
  line-height: 1.5;
}

13.
Guide_EN: Set display none property hiding content.
Guide_KO: 화면 상에서 보이지 않고 공간도 차지하지 않게 차단 숨김 처리합니다.
Template_HTML:

Template_CSS:

  display: none;
}

14.
Guide_EN: Apply hidden state class designs.
Guide_KO: 알림 에러 경고 상자를 일시 차단 숨김 클래스로 다듬습니다.

15.
Guide_EN: Control layout navigation menus displaying blocks.
Guide_KO: 헤더 내비바의 링크 항목 전체를 블록화해 세로로 층층 쌓아 배열합니다.

16.
Guide_EN: Apply inline displaying rules on lists.
Guide_KO: 세로로 쌓이던 리스트 항목 li 요소를 한 줄 가로 배치가 되게 변경합니다.
Template_HTML:

17.
Guide_EN: Combine inline listing rules and side margins.
Guide_KO: 리스트 항목들을 가로로 나열하며 우측마다 15픽셀 씩 벌려 놓습니다.
