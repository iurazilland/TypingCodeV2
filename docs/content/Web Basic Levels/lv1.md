Lv1.
Title_EN: HTML Basics & Paragraphs
Title_KO: HTML 기초와 문단 태그
Description_EN: Learn HTML headers, paragraph tags, and line breaks.
Description_KO: 웹페이지를 구성하는 제목 태그(h1~h6), 본문 단락 태그(p), 줄바꿈 태그(br)를 배웁니다.

1.
Guide_EN: Write the largest heading h1 and sub-heading h2 tags sequentially.
Guide_KO: 가장 큰 제목 h1 태그와 그 아래 단계인 h2 제목 태그를 나란히 배치해 봅니다.
Visual: L1S1_HtmlStructureVisualizer
Template_HTML:
<h1>First Page</h1>
<h2>About Me</h2>

2.
Guide_EN: Create headings using h3 and h4 tags for mid-level subheadings.
Guide_KO: 중간 크기 제목 태그인 h3와 h4를 함께 적어 제목 단계 차이를 비교합니다.
Template_HTML:
<h3>Contact Info</h3>
<h4>Notice Panel</h4>

3.
Guide_EN: Use h5 and h6 tags for detailed tiny heading titles.
Guide_KO: 하위 단계 제목 태그인 h5와 가장 작은 크기의 h6 제목을 선언합니다.
Template_HTML:
<h5>Sub Topic</h5>
<h6>Tiny Title</h6>

4.
Guide_EN: Practice writing h1, h3, and h6 tags sequentially to compare heading sizes.
Guide_KO: 대표적인 1, 3, 6단계 제목을 나열하여 크기 차이를 한 화면에 관찰합니다.
Template_HTML:
<h1>Title 1</h1>
<h3>Title 3</h3>
<h6>Title 6</h6>

5.
Guide_EN: Stack two paragraph p tags sequentially to write basic body text lines.
Guide_KO: 두 개의 p 태그를 사용하여 본문이 단락별로 구분되어 출력되는지 확인합니다.
Template_HTML:
<p>Hello HTML world.</p>
<p>Welcome to my site.</p>

6.
Guide_EN: Use three p tags to confirm they display vertically with built-in spacing.
Guide_KO: 세 개의 p 태그를 세로로 정렬해 상하 간격이 자동으로 확보되는지 확인합니다.
Template_HTML:
<p>Welcome to my site.</p>
<p>Learn coding today.</p>
<p>It is very fun.</p>

7.
Guide_EN: Insert the br tag within paragraphs to create actual line breaks.
Guide_KO: 줄바꿈을 유발하는 <br> 태그를 본문 p 태그 중간중간에 삽입해 봅니다.
Template_HTML:
<p>Seoul, Korea<br>Open: 9 AM</p>
<p>Date: June 17<br>Time: 9 AM</p>

8.
Guide_EN: Combine multiple paragraph segments with nested br line breaks.
Guide_KO: 단락별로 분리하고 각 단락 내에 줄바꿈 br 태그를 넣어 상세 정보를 정돈합니다.
Template_HTML:
<p>Developer<br>HTML & CSS</p>
<p>Soccer<br>Basketball</p>

9.
Guide_EN: Combine a heading h1 tag and a paragraph p tag to create a basic text hierarchy.
Guide_KO: 대제목 h1 태그와 단락 p 태그를 조합하여 본문 계층 구조를 생성합니다.
Template_HTML:
<h1>First Page</h1>
<p>Hello HTML world.</p>

10.
Guide_EN: Combine an h2 heading with paragraphs containing a br line break.
Guide_KO: 중제목 h2 아래에 일반 단락 및 줄바꿈 단락을 조립해 소개 섹션을 설계합니다.
Template_HTML:
<h2>About Me</h2>
<p>I love web coding.</p>
<p>Seoul, Korea<br>Open: 9 AM</p>

11.
Guide_EN: Place a heading h3 tag above structured paragraph descriptions.
Guide_KO: h3 소제목 아래에 취미 생활을 나열한 단락과 줄바꿈 단락을 매칭시킵니다.
Template_HTML:
<h3>My Hobbies</h3>
<p>Playing games.</p>
<p>Soccer<br>Basketball</p>

12.
Guide_EN: Group an h4 heading with multiple paragraph text descriptions.
Guide_KO: h4 공지용 소제목 아래에 본문 문단을 나열하여 일련의 글 상자를 연출합니다.
Template_HTML:
<h4>Notice Panel</h4>
<p>Welcome to my site.</p>
<p>Learn coding today.</p>

13.
Guide_EN: Place structured paragraphs and br line breaks under an h5 heading.
Guide_KO: h5 하위 소주제에 상세 정보 단락과 수정 항목을 줄바꿈으로 채워봅니다.
Template_HTML:
<h5>Sub Topic</h5>
<p>Detailed notes here.</p>
<p>Check code<br>Fix layout</p>

14.
Guide_EN: Combine a tiny h6 heading with paragraph comments and br line breaks.
Guide_KO: h6 팁 제목 아래에 설명 단락과 시맨틱 태그 줄바꿈 코드를 결합합니다.
Template_HTML:
<h6>Tiny Title</h6>
<p>This is a small header.</p>
<p>Use tags<br>Keep semantic</p>

15.
Guide_EN: Compare sizes of h1, h3 headings and paragraph elements inside one page.
Guide_KO: 대제목과 소제목, 그리고 내용 단락을 혼합 배치하여 구조적 대비를 봅니다.
Template_HTML:
<h1>Title 1</h1>
<h3>Title 3</h3>
<p>Compare heading sizes.</p>
<p>Learn coding today.</p>

16.
Guide_EN: Structure a document heading hierarchy from h1 down to h3 and paragraph text.
Guide_KO: 대, 중, 소제목의 단계를 순차적으로 중첩해 계층형 레이아웃 문서 구조를 만듭니다.
Template_HTML:
<h1>Main Title</h1>
<h2>Sub Section</h2>
<h3>Detail Section</h3>
<p>Perfect hierarchy.</p>

17.
Guide_EN: Wrap paragraphs and line breaks together for mixed practice.
Guide_KO: 문단 나누기 p 태그와 단락 내 줄바꿈 br 태그를 함께 타이핑하여 최종 복습합니다.
Template_HTML:
<p>First paragraph.</p>
<p>Second paragraph.</p>
<p>Line one<br>Line two</p>

18.
Guide_EN: Wrap the headings and paragraphs inside a body container tag block.
Guide_KO: <body> 본문 영역 태그 내부에 제목과 여러 단락들을 담아 기본 블록을 형성합니다.
Template_HTML:
<body>
  <h2>My Site</h2>
  <p>Welcome here.</p>
  <p>Learn coding today.</p>
</body>

19.
Guide_EN: Wrap the body container with head, title, and html skeleton tags.
Guide_KO: 메타정보 헤더 <head>와 본문 <body>를 감싼 <html> 문서 구조를 만듭니다.
Template_HTML:
<!DOCTYPE html>
<html>
<head>
  <title>My App</title>
</head>
<body>
  <h2>Summary</h2>
  <p>Header and paragraphs.</p>
</body>
</html>

20.
Guide_EN: Add a doctype declaration at the top to complete the page document structure.
Guide_KO: 최상단 HTML5 표준 규격 선언문인 doctype과 함께 레벨 1 완성 구조를 마크업합니다.
Template_HTML:
<!DOCTYPE html>
<html>
<head>
  <title>My App</title>
</head>
<body>
  <h1>Level 1 Complete</h1>
  <p>HTML basics<br>are completed.</p>
</body>
</html>
