Title_EN: JS Basic Functions
Title_KO: 함수 정의와 값 반환
Description_EN: Learn function declaration, arguments, return, and arrows.
Description_KO: 독립된 동작 단위를 정의하는 function 선언과 인자 전송, return 반환, arrow 함수를 배웁니다.

1.
Guide_EN: Define a basic function that prints greeting.
Guide_KO: 호출하면 환영 메시지를 인쇄하는 함수를 function 키워드로 짭니다.
Template_JS:
function greet() {
  console.log("Hello");
}

2.
Guide_EN: Call defined function multiple times.
Guide_KO: 선언한 함수 이름에 소괄호를 붙여 실제로 가동 호출해 봅니다.
Template_JS:
function greet() {
  console.log("Hello");
}
greet();

3.
Guide_EN: Define function taking single parameter arguments.
Guide_KO: 전달 인자를 괄호 변수로 넘겨받아 활용하는 매개함수를 정의합니다.
Template_JS:
function welcome(name) {
  console.log("Welcome " + name);
}

4.
Guide_EN: Call function passing argument value.
Guide_KO: 함수를 호출할 때 괄호 안에 전달하고자 하는 텍스트 값을 실어 보냅니다.
Template_JS:
function welcome(name) {
  console.log("Welcome " + name);
}
welcome("Kim");

5.
Guide_EN: Return value from custom function.
Guide_KO: 동작 완료 후 연산 결과 데이터를 반환하는 return 명령을 씁니다.
Template_JS:
function addOne(x) {
  return x + 1;
}

6.
Guide_EN: Print function return value to the console.
Guide_KO: 함수 리턴 결과값을 변수에 보관하고 콘솔창에 인쇄해 봅니다.
Template_JS:
function addOne(x) {
  return x + 1;
}
let res = addOne(5);
console.log(res);

7.
Guide_EN: Define function taking multiple parameter arguments.
Guide_KO: 두 개의 매개변수 인자를 한 번에 전송받는 입력 함수를 만듭니다.
Template_JS:
function add(a, b) {
  return a + b;
}

8.
Guide_EN: Call function passing multiple parameters.
Guide_KO: 두 수치를 인자로 넘겨 호출한 덧셈값을 얻어 출력 확인합니다.
Template_JS:
function add(a, b) {
  return a + b;
}
console.log(add(10, 20));

9.
Guide_EN: Define function calculating custom math formula.
Guide_KO: 단가를 넘겨받아 부가세가 붙은 총합 금액을 구하는 함수를 땁니다.
Template_JS:
function getPrice(base) {
  return base * 1.1;
}

10.
Guide_EN: Return string results inside custom function.
Guide_KO: 입력값과 문자열을 더해 조립한 결과 텍스트를 리턴하는 함수입니다.
Template_JS:
function tag(name) {
  return "<" + name + ">";
}

11.
Guide_EN: Call string formatting functions passing tags (cumulative review).
Guide_KO: 태그 이름 문자열을 전송해 연산된 결과 괄호를 받아 출력합니다.
Template_JS:
function tag(name) {
  return "<" + name + ">";
}
console.log(tag("div"));

12.
Guide_EN: Combine logic variables inside custom functions.
Guide_KO: 함수 내부 코드에서 조건 판별 if 문을 사용하여 판단 조율합니다.
Template_JS:
function check(n) {
  if (n > 0) return "+";
  return "-";
}

13.
Guide_EN: Evaluate check functions passing numeric values.
Guide_KO: 수치 판단 함수에 양수를 인자로 주어 리턴값을 콘솔창에 찍어봅니다.
Template_JS:
function check(n) {
  if (n > 0) return "+";
  return "-";
}
console.log(check(5));

14.
Guide_EN: Define arrow function shorthand formatting rules.
Guide_KO: 함수 정의를 한 줄 화살표 기호(=>)로 표현하는 약식 함수를 씁니다.
Template_JS:
const double = x => x * 2;

15.
Guide_EN: Call arrow function printing results.
Guide_KO: 선언한 화살표 함수를 가동해 얻은 결과 수치를 콘솔창에 인쇄합니다.
Template_JS:
const double = x => x * 2;
console.log(double(10));

16.
Guide_EN: Write multi-line arrow functions body blocks.
Guide_KO: 중괄호와 return 명령을 포함하는 온전한 화살표 함수 블록을 씁니다.
Template_JS:
const add = (a, b) => {
  return a + b;
};

17.
Guide_EN: Combine multiple logic variables inside arrow functions.
Guide_KO: 인자 2개 중 큰 쪽 수치 데이터를 선별해 리턴하는 화살표 함수입니다.
Template_JS:
const max = (a, b) => {
  if (a > b) return a;
  return b;
};

18.
Guide_EN: Call logic comparison functions printing outputs.
Guide_KO: 대소 비교 화살표 함수를 호출하여 더 큰 수치를 받아 콘솔에 쏩니다.
Template_JS:
const max = (a, b) => {
  if (a > b) return a;
  return b;
};
console.log(max(12, 15));

19.
Guide_EN: Check string matching logic returns.
Guide_KO: 아이디 형식이 맞는지 참/거짓 판단 결과를 리턴해 주는 함수입니다.
Template_JS:
const isValid = id => id === "admin";
console.log(isValid("guest"));

20.
Guide_EN: Assemble custom functions calling sibling methods.
Guide_KO: 두 수치를 더하고 그 결과를 2배 곱해 주는 두 함수 조합을 조립 완성합니다.
Template_JS:
const add = (a, b) => a + b;
const double = x => x * 2;
let total = double(add(3, 4));
console.log(total);
