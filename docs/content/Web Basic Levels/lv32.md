Lv32.
Title_EN: JS Arithmetic & Operators
Title_KO: 산술 연산과 대입 연산자
Description_EN: Learn +, -, *, /, %, and compound assignments.
Description_KO: 사칙연산(+-*/), 나머지(%), 그리고 값을 덮어쓰는 복합 대입 연산자(+=, -=)를 배웁니다.

1.
Guide_EN: Add two variables using arithmetic operators.
Guide_KO: 두 개의 변수 수치를 덧셈(+) 기호로 연산해 결과를 확인합니다.
Template_JS:
let a = 10;
let b = 20;
console.log(a + b);

2.
Guide_EN: Subtract variables using arithmetic subtraction.
Guide_KO: 두 변수의 수치를 뺄셈(-) 연산자로 연산하여 결과를 봅니다.
Template_JS:
let a = 30;
let b = 10;
console.log(a - b);

3.
Guide_EN: Multiply variables using arithmetic multiplication.
Guide_KO: 두 값을 곱셈(*) 기호로 곱해 곱의 결과를 콘솔에 출력합니다.
Template_JS:
let a = 5;
let b = 6;
console.log(a * b);

4.
Guide_EN: Divide variables using arithmetic division.
Guide_KO: 두 수치를 나눗셈(/) 기호로 나눠 몫을 계산해 출력합니다.
Template_JS:
let a = 20;
let b = 4;
console.log(a / b);

5.
Guide_EN: Find remainder of division using modulo operator.
Guide_KO: 나머지를 구해 주는 나머지(%) 기호를 써서 잔여 수치를 확인합니다.
Template_JS:
let a = 10;
let b = 3;
console.log(a % b);

6.
Guide_EN: Apply exponentiation operator on values.
Guide_KO: 제곱승 값을 연산해 주는 거듭제곱(**) 기호 연산을 행해 봅니다.
Template_JS:
let a = 2;
console.log(a ** 3);

7.
Guide_EN: Use parentheses to alter calculation orders.
Guide_KO: 덧셈을 먼저 가동시키기 위해 괄호(()) 기호로 구역을 감쌉니다.
Template_JS:
let res = (5 + 3) * 2;
console.log(res);

8.
Guide_EN: Use prefix increment operations on variables.
Guide_KO: 수치를 1 증가시키는 증가(++) 연산자를 선행 실행해 봅니다.
Template_JS:
let n = 5;
n++;
console.log(n);

9.
Guide_EN: Use prefix decrement operations on variables.
Guide_KO: 수치를 1 감소시키는 감소(--) 연산자를 실행해 봅니다.
Template_JS:
let n = 5;
n--;
console.log(n);

10.
Guide_EN: Combine multiplication and modulo calculations (cumulative review).
Guide_KO: 변수를 곱하고 바로 다른 숫자로 나눈 몫의 나머지를 구합니다.
Template_JS:
let res = (10 * 3) % 7;
console.log(res);

11.
Guide_EN: Combine additions and strings parameters.
Guide_KO: 텍스트에 수치를 더해 글자로 합쳐지는 자동 형변환을 봅니다.
Template_JS:
let items = 3;
console.log("Count: " + (items + 1));

12.
Guide_EN: Add decimal numbers using floating operations.
Guide_KO: 소수점이 있는 실수들의 덧셈 결과를 계산해 출력합니다.
Template_JS:
let x = 0.5;
let y = 1.2;
console.log(x + y);

13.
Guide_EN: Divide floating point operations values.
Guide_KO: 실수를 정수로 나누는 수치 처리를 실행해 확인합니다.
Template_JS:
let total = 2.5;
console.log(total / 2);

14.
Guide_EN: Add values to variables using shorthand additions.
Guide_KO: 기존 보관량에 10을 더해 덧씌우는 단축 연산(+=)을 씁니다.
Template_JS:
let price = 100;
price += 10;
console.log(price);

15.
Guide_EN: Subtract values using shorthand subtractions.
Guide_KO: 기존 보관량에서 5를 빼서 덧씌우는 단축 연산(-=)을 씁니다.
Template_JS:
let stock = 10;
stock -= 5;
console.log(stock);

16.
Guide_EN: Multiply values using shorthand multiplications.
Guide_KO: 기존 수치에 2배를 곱해 덧씌우는 단축 연산(*=)을 실행합니다.
Template_JS:
let speed = 50;
speed *= 2;
console.log(speed);

17.
Guide_EN: Divide values using shorthand divisions.
Guide_KO: 기존 수치를 2로 나누어 덮어씌우는 단축 연산(/=)을 행합니다.
Template_JS:
let width = 80;
width /= 2;
console.log(width);

18.
Guide_EN: Verify shorthand modulo allocations inside logic variables.
Guide_KO: 나머지를 구해서 그 값을 즉시 변수에 재대입(%=)합니다.
Template_JS:
let val = 10;
val %= 3;
console.log(val);

19.
Guide_EN: Combine multiple variables and operations calculations.
Guide_KO: 두 개의 변수를 곱한 가격을 다른 변수와 합산 처리합니다.
Template_JS:
let p = 200;
let qty = 3;
let ship = 50;
console.log(p * qty + ship);

20.
Guide_EN: Assemble complex mathematical formula calculations.
Guide_KO: 수치 괄호 연산, 누적 연산, 출력 단계를 종합 구성 완성합니다.
Template_JS:
let base = 100;
let tax = (base * 10) / 100;
let total = base + tax;
console.log(total);
