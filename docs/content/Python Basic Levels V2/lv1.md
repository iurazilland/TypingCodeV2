Lv1.
Title_EN: Outputting Numbers
Title_KO: 숫자 출력과 연산
Description_EN: Learn to print numbers, perform basic arithmetic, and output multiple values.
Description_KO: 화면에 숫자를 출력하고, 간단한 사칙연산을 수행하며, 여러 개의 값을 함께 출력하는 방법을 배웁니다.

1. 
Guide_EN: Use print() to output a number.
Guide_KO: print()를 사용하여 하나의 숫자를 화면에 출력합니다.
Template_EN:
print(5)
print(10)
print(100)
Template_KO:
print(5)
print(10)
print(100)

2. 
Guide_EN: You can print any number, including 0.
Guide_KO: 0을 포함하여 어떤 숫자든 출력할 수 있습니다.
Template_EN:
print(7)
print(0)
print(999)
Template_KO:
print(7)
print(0)
print(999)

3. 
Guide_EN: print() can calculate additions (+).
Guide_KO: print() 안에서 더하기(+) 기호를 사용하면 계산된 결과가 출력됩니다.
Template_EN:
print(1 + 1)
print(10 + 5)
print(100 + 200)
Template_KO:
print(1 + 1)
print(10 + 5)
print(100 + 200)

4. 
Guide_EN: print() can also perform subtractions (-).
Guide_KO: 빼기(-) 기호를 사용하여 뺄셈을 수행할 수 있습니다.
Template_EN:
print(10 - 5)
print(50 - 20)
print(100 - 1)
Template_KO:
print(10 - 5)
print(50 - 20)
print(100 - 1)

5. 
Guide_EN: Use the asterisk (*) for multiplication.
Guide_KO: 별표(*) 기호를 사용하여 곱셈을 계산할 수 있습니다.
Template_EN:
print(2 * 3)
print(5 * 5)
print(10 * 10)
Template_KO:
print(2 * 3)
print(5 * 5)
print(10 * 10)

6. 
Guide_EN: Use the slash (/) for division.
Guide_KO: 슬래시(/) 기호를 사용하여 나눗셈을 계산합니다. 결과는 소수점으로 나옵니다.
Template_EN:
print(10 / 2)
print(20 / 4)
print(100 / 10)
Template_KO:
print(10 / 2)
print(20 / 4)
print(100 / 10)

7. 
Guide_EN: Use commas (,) to print multiple numbers on one line.
Guide_KO: 쉼표(,)를 사용하면 여러 숫자를 한 줄에 띄어쓰기로 구분하여 출력할 수 있습니다.
Template_EN:
print(1, 2)
print(10, 20)
print(100, 200)
Template_KO:
print(1, 2)
print(10, 20)
print(100, 200)

8. 
Guide_EN: You can output more than two numbers using commas.
Guide_KO: 쉼표를 계속 연결하여 세 개 이상의 숫자도 출력할 수 있습니다.
Template_EN:
print(1, 2, 3)
print(7, 8, 9)
print(10, 20, 30)
Template_KO:
print(1, 2, 3)
print(7, 8, 9)
print(10, 20, 30)

9. 
Guide_EN: Combine calculations and commas to show both.
Guide_KO: 수식 계산과 쉼표를 결합하여 여러 결과를 한 번에 확인할 수 있습니다.
Template_EN:
print(10 + 5, 20)
print(100, 50 + 50)
print(10 * 2, 30)
Template_KO:
print(10 + 5, 20)
print(100, 50 + 50)
print(10 * 2, 30)

10. 
Guide_EN: Print multiple calculation results at once.
Guide_KO: 여러 개의 계산 결과를 한 줄에 나란히 출력해 봅니다.
Template_EN:
print(1, 1 + 1, 3)
print(10, 10 * 2, 30)
print(100 - 50, 50, 100)
Template_KO:
print(1, 1 + 1, 3)
print(10, 10 * 2, 30)
print(100 - 50, 50, 100)

Guide_KO: 빈칸을 채워 숫자 5를 출력하는 명령어를 완성하세요.

^^^^^(5)
Template_KO:
^^^^^(5)

Guide_EN: Fill in the blank to add 10 and 5.
Guide_KO: 빈칸을 채워 10과 5를 더하는 수식을 완성하세요.
Template_EN:
print(10 ^ 5)
Template_KO:
print(10 ^ 5)

13. [Blank]
Guide_EN: Fill in the blanks to print 1, 2, and 3 separated by spaces.
Guide_KO: 빈칸을 채워 1, 2, 3을 한 줄에 띄어쓰기로 구분하여 출력하세요.
Template_EN:
print(1^ 2^ 3)
Template_KO:
print(1^ 2^ 3)
