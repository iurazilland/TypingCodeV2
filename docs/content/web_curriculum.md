# 웹 프로그래밍 타자 연습 커리큘럼 — Web Basic (50단계 완결)

이 커리큘럼은 **4단계의 연습(Practice)**과 **1단계의 챌린지(Challenge)**가 반복되는 **4+1 패턴**으로 설계되었습니다. HTML 구조 설계부터 CSS 레이아웃, 그리고 JavaScript DOM 제어와 동적 기능 구현까지 웹 기초의 핵심을 50단계에 나누어 완벽히 마스터합니다.

---

## 💡 학습 원칙
1. **연습 레벨 20단계(Sets) 정량 구성**: 모든 연습 레벨은 학습 성취도를 높이고 충분한 반복 타자 연습량을 제공하기 위해 **반드시 20단계(Step 1 ~ 20)**로 점진적 설계합니다.
2. **가시적인 실행 결과 보장 (Visual Feedback)**: 사용자가 코드를 완성하는 즉시 라이브 프리뷰 화면이나 브라우저 콘솔창에 직접적이고 가시적인 변화(렌더링된 컴포넌트, 로그 메시지 등)가 일어나야 합니다. 화면에 아무런 시각적 변화가 발생하지 않는 빈 뼈대 태그(예: 단독 `<html><body>` 구역 설정 등)는 금지됩니다.
3. **중첩 누적 학습(Cumulative Review)**: 새로운 개념을 배울 때 이전 레벨에서 배운 문법을 예제에 섞어 자연스럽게 복습합니다.
4. **실시간 미리보기 연동(Live Preview)**: 코드를 치는 즉시 라이브 미리보기로 변화를 보며 태그와 스타일, 스크립트의 작동을 배웁니다.
5. **코드 한 줄 길이 제한 (40자 안팎)**: 가로폭이 좁은 편집 창에서도 자동 줄바꿈으로 가독성이 저하되지 않도록 짧고 간결하게 예제를 구성합니다.
6. **쉬운 복습 중심의 챌린지 (★가장 중요)**: 
   * '챌린지'는 어려운 알고리즘이나 꼬아놓은 논리 퀴즈를 푸는 것이 아닙니다. 
   * **직전 4개 레벨에서 배운 태그나 속성, 함수 구조를 다시 한 번 입력해 보며 기억을 상기시키는 친절한 '복습'용 난이도로 설계하며, 10문항으로 구성됩니다.**
   * 문항 유형(3-3-2-2 규칙):
     * **Q1 ~ Q3 [Blank]**: 핵심 속성이나 키워드의 빈칸을 채우는 가벼운 문항 (3문항)
     * **Q4 ~ Q6 [One Line]**: 배운 기능 중 가장 직관적인 한 줄을 작성하는 문항 (3문항)
     * **Q7 ~ Q8 [Fix]**: 닫는 태그 누락이나 세미콜론 오타 등 눈에 잘 띄는 에러 한 곳 수정하기 (2문항)
     * **Q9 ~ Q10 [Full Code]**: 가이드라인이 명확하게 주어지는 짧은 전체 코드 작성 (2문항)

## 🟦 Phase 1: HTML 문서 구조와 뼈대 설계 (Lv 1-15)

### Lv 1-5: HTML 기초 요소와 텍스트
* **Lv 1: HTML 구조 정의와 문단 태그**
  * **Step 1**: `<html>`, `<body>`로 웹페이지의 기본 구역 설정 (최소 구조)
  * **Step 2**: `<h1>`로 제목 작성
  * **Step 3**: `<p>`로 대제목 아래 설명 문단 추가 (Lv 1 문법 중첩)
* **Lv 2: 인라인 텍스트 스타일과 링크**
  * **Step 1**: `<span>`으로 단어 분리
  * **Step 2**: `<strong>` 및 `<em>`로 텍스트 강조 처리
  * **Step 3**: `<a>`로 연결 링크 추가 + `<strong>` 강조 복습
* **Lv 3: 버튼 및 이미지 요소 삽입**
  * **Step 1**: `<img>` 태그와 `src` 속성으로 이미지 불러오기
  * **Step 2**: `<button>`으로 클릭 영역 생성
  * **Step 3**: `<a>` 링크 버튼 배치하여 인라인 요소 조합 복습
* **Lv 4: 영역 분할 및 레이아웃 컨테이너**
  * **Step 1**: `<div>` 태그로 요소를 묶는 컨테이너 생성
  * **Step 2**: `<section>` 태그로 의미론적인 구역 나누기
  * **Step 3**: `<div>` 안에 `<h1>`, `<p>`, `<button>`을 한 번에 감싸서 카드 영역 조립
* **Lv 5: [Challenge] 프로필 정보 텍스트 카드 설계 (복습)**
  * **Q1~Q3 [Blank]**: `<h1>`, `<p>`, `<a>` 태그의 빈 구멍 속성 채우기
  * **Q4~Q6 [One Line]**: 텍스트 카드 내부에 들어갈 링크 태그 한 줄 구현 (`<a href="...">`)
  * **Q7~Q8 [Fix]**: 닫는 태그 누락 에러 및 `href` 오타 가볍게 수정
  * **Q9~Q10 [Full Code]**: 가이드를 보며 3줄 내외의 간단한 프로필 카드 마크업 구현

### Lv 6-10: 구조적 목록과 사용자 입력 폼
* **Lv 6: 순서 있는 목록과 순서 없는 목록**
  * **Step 1**: `<ul>`과 `<li>`로 번호 없는 목록 생성
  * **Step 2**: `<ol>`과 `<li>`로 순서가 있는 목록 생성
  * **Step 3**: `<div>` 영역 내부에 제목(`<h1>`)과 목록 요소 조합 복습
* **Lv 7: 테이블 표 데이터 표기**
  * **Step 1**: `<table>`과 `<tr>`로 표의 줄 영역 생성
  * **Step 2**: `<th>`를 사용해 표의 제목 헤더 열 정의
  * **Step 3**: `<td>`를 사용해 일반 셀 데이터 채우기 (목록 요소와의 개념 복습)
* **Lv 8: 사용자 입력 요소와 텍스트 에어리어**
  * **Step 1**: `<input type="text">`로 한 줄 입력 폼 생성
  * **Step 2**: `<label>`을 연결하여 입력창의 이름 표시
  * **Step 3**: `<textarea>`로 설명 칸 추가 및 전송 `<button>` 배치
* **Lv 9: 다중 선택 드롭다운과 버튼 그룹**
  * **Step 1**: `<select>`와 `<option>`으로 펼쳐지는 드롭다운 선택 폼 구현
  * **Step 2**: `<fieldset>`과 `<legend>`로 폼 내 영역 테두리 씌우기
  * **Step 3**: 인풋창(`input`)과 드롭다운(`select`)을 그룹으로 묶어 배치하는 복습
* **Lv 10: [Challenge] 회원가입 양식 입력 폼 설계 (복습)**
  * **Q1~Q3 [Blank]**: `input` 태그의 `type` 속성 및 `label`의 `for` 연결 채우기
  * **Q4~Q6 [One Line]**: 이메일 주소 입력창 및 `select`의 선택 옵션 태그 작성 (짧은 한 줄)
  * **Q7~Q8 [Fix]**: `form` 태그 닫기 누락 에러와 버튼의 `type="submit"` 속성 에러 수정
  * **Q9~Q10 [Full Code]**: 가이드를 따르는 아이디, 비밀번호 입력란 마크업 구현

### Lv 11-15: 시맨틱 레이아웃과 멀티미디어

## 🟩 Phase 2: CSS 스타일링 및 반응형 레이아웃 (Lv 16-30)

### Lv 16-20: CSS 스타일링 기초와 박스 모델
* **Lv 16: CSS 연동과 글꼴 스타일**
  * **Step 1**: 외부 CSS 연동 또는 `<style>` 구문에서 텍스트 색상(`color`) 변경
  * **Step 2**: 글자 크기(`font-size`)와 글꼴(`font-family`) 지정
  * **Step 3**: 줄 간격(`line-height`)을 조절하여 문단(`<p>`) 제어
* **Lv 17: 클래스·ID 및 전체 선택자 활용**
  * **Step 1**: 특정 요소에만 적용하는 `.class` 선택자 작성
  * **Step 2**: 고유 요소에 스타일을 적용하는 `#id` 선택자 지정
  * **Step 3**: 전체 선택자(`*`)로 모든 요소의 마진 초기화 및 클래스 결합 응용
* **Lv 18: 박스 모델 기본 속성**
  * **Step 1**: 요소의 너비(`width`)와 높이(`height`) 지정
  * **Step 2**: 테두리 안쪽 여백(`padding`) 설정으로 컴포넌트 내부 공간 확보
  * **Step 3**: 테두리 바깥쪽 여백(`margin`)과 경계선(`border`) 속성 결합 복습
* **Lv 19: 배경색, 둥근 모서리 및 그림자 효과**
  * **Step 1**: 배경색(`background-color`) 변경
  * **Step 2**: 박스의 네 모퉁이를 둥글게 깎는 `border-radius` 적용
  * **Step 3**: 입체감을 주는 `box-shadow`를 클래스(`.card`)에 적용하여 카드 UI 디자인
* **Lv 20: [Challenge] 그림자 효과를 넣은 Hover 버튼 컴포넌트 꾸미기 (복습)**
  * **Q1~Q3 [Blank]**: 기본 색상(`color`) 및 배경색(`background-color`) 스타일 구멍 채우기
  * **Q4~Q6 [One Line]**: 안쪽 여백(`padding`) 및 모퉁이 라운딩(`border-radius`) 속성 정의
  * **Q7~Q8 [Fix]**: 단위 표시(px) 누락 오류 및 속성명 오타 수정
  * **Q9~Q10 [Full Code]**: 가이드를 보며 버튼에 배경색과 테두리 스타일을 입히는 코드 구현

### Lv 21-25: Flexbox 현대식 레이아웃
* **Lv 21: 디스플레이 배치 특성**
  * **Step 1**: 줄바꿈이 일어나는 `display: block` 성질 파악
  * **Step 2**: 가로로 흐르는 `display: inline` 성질 스타일링
  * **Step 3**: 크기 지정이 가능하면서 가로로 흐르는 `display: inline-block` 응용 복습
* **Lv 22: Flexbox 컨테이너와 정렬 방향**
  * **Step 1**: 부모 요소에 `display: flex`를 주어 자식 요소들을 가로 정렬
  * **Step 2**: `flex-direction: column`으로 세로 정렬 방향 전환
  * **Step 3**: 요소들 사이의 간격을 조절하는 `gap` 속성 복습
* **Lv 23: Flexbox 축 정렬**
  * **Step 1**: 메인 축을 기준으로 요소를 정렬하는 `justify-content` (center, space-between)
  * **Step 2**: 수직 축을 기준으로 요소를 정렬하는 `align-items` (center)
  * **Step 3**: 특정 자식 요소만 따로 수직 정렬하는 `align-self` 응용 복습
* **Lv 24: Flexbox 자식 요소 신축 비율**
  * **Step 1**: 남는 공간을 채우는 비율인 `flex-grow` 적용
  * **Step 2**: 공간 부족 시 줄어드는 비율인 `flex-shrink` 설정
  * **Step 3**: 기본 크기를 정의하는 `flex-basis`와 신축 속성 통합 복습
* **Lv 25: [Challenge] Flexbox 기반 반응형 네비게이션 헤더 바 디자인 (복습)**
  * **Q1~Q3 [Blank]**: `display: flex` 선언 및 축 방향 속성 빈칸 매칭
  * **Q4~Q6 [One Line]**: 수평 정렬(`justify-content`) 및 간격(`gap`) 설정 코드 구현
  * **Q7~Q8 [Fix]**: Flex 자식 요소 배치 시 `align-self`와 `align-items` 오사용 수정
  * **Q9~Q10 [Full Code]**: Flex 속성을 사용하여 버튼 두 개를 가로로 배치하고 정렬하는 스타일 작성

### Lv 26-30: Grid 시스템과 절대적 위치 배치
* **Lv 26: Grid 레이아웃 기본 바둑판 설계**
  * **Step 1**: `display: grid` 선언과 열 비율 나누기 (`grid-template-columns: repeat(3, 1fr)`)
  * **Step 2**: 행 비율 나누기 및 간격(`gap`) 설정
  * **Step 3**: Grid를 사용해 2x2 카드 리스트 레이아웃 생성 복습
* **Lv 27: 자유로운 절대 위치 지정과 고정 배치**
  * **Step 1**: 자식 위치의 기준점이 되는 `position: relative` 설정
  * **Step 2**: 부모 기준 절대 위치로 배치하는 `position: absolute` 및 `top`, `right` 활용
  * **Step 3**: 스크롤해도 화면 한곳에 머무르는 `position: fixed` 플로팅 버튼 만들기
* **Lv 28: 레이어 겹침 제어와 우선순위**
  * **Step 1**: 겹쳐진 요소들의 순서를 바꿀 수 있는 `z-index` 속성 적용
  * **Step 2**: `position`이 있는 요소들 간의 겹침 우선순위 비교
  * **Step 3**: `absolute` 요소를 카드 텍스트 위에 겹치게 배치하고 `z-index`로 순서 조정 복습
* **Lv 29: 반응형 미디어 쿼리 기초**
  * **Step 1**: 가로 해상도가 768px 이하일 때 글자 크기 줄이기 (`@media`)
  * **Step 2**: 모바일 환경에서 flex 정렬 방향 바꾸기 (`flex-direction: column`)
  * **Step 3**: 데스크톱(Grid 3열)에서 모바일(Grid 1열)로 바뀌는 반응형 미디어 쿼리 작성 복습
* **Lv 30: [Challenge] Grid & Position을 이용한 반응형 인스타그램형 프로필 페이지 (복습)**
  * **Q1~Q3 [Blank]**: grid 분할 및 absolute 배치 위치 속성 매칭
  * **Q4~Q6 [One Line]**: absolute 요소 위치 설정 속성 작성 (`top: 10px; right: 10px;`)
  * **Q7~Q8 [Fix]**: z-index 스택 차이로 가려지는 뱃지 겹침 현상 디버깅 및 수정
  * **Q9~Q10 [Full Code]**: 모바일 해상도에서 이미지를 1열로 세로 정렬하는 간단한 미디어 쿼리 스타일 작성
