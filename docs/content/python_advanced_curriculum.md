# 파이썬 타자 연습 커리큘럼 — Advanced (심화 과정 · 임시 설계안)

> ⚠️ **이 문서는 임시 설계안입니다.** 레벨 번호 및 상세 구성은 Basic 과정 확정 후 재정리됩니다.

Basic 과정(Lv 1-50)을 졸업한 학습자를 위한 심화 과정입니다.
현재 `docs/content/Python Advanced Levels/` 폴더에 이동된 파일(lv51~lv95)의 콘텐츠를 기반으로 재구성될 예정입니다.

---

## 📌 심화 과정에서 다룰 주제 (예정)

### 자료구조 & 함수형 심화
- 딕셔너리 내포 (Dict Comprehension)
- 복합 딕셔너리 접근 및 관리
- 세트를 이용한 고급 데이터 필터링
- collections 모듈 (Counter, defaultdict 등)
- 가변 인자 (*args, **kwargs)

### 객체지향 심화
- 클래스 상속 (Inheritance)
- 메서드 오버라이딩 & super()
- 클래스 메서드와 정적 메서드 (@classmethod, @staticmethod)
- 다형성 (Polymorphism)
- @property 데코레이터
- 매직 메서드 (__str__, __len__, __repr__)
- 추상 클래스 (ABC)

### 고급 예외 처리
- 다양한 예외 타입 심화
- 사용자 정의 예외 (Custom Exception)
- 의도적 예외 발생 (raise)

### 모듈 & 패키지 심화
- 표준 라이브러리 심화 (os, sys, time)
- 외부 라이브러리 활용 (requests 등)
- 패키지 구조 이해

### 파일 처리 심화
- JSON 고급 처리
- CSV 파일 다루기
- 파일 경로 관리 (pathlib)

### 고급 파이썬 생산성
- 데코레이터 (Decorator) 구현 원리
- 제너레이터 (Generator)와 yield
- 이터레이터 (Iterator) 프로토콜
- 정규표현식 (re 모듈)
- 날짜와 시간 (datetime)
