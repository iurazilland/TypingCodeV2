Title_EN: Structure Unpacking & Variable Args
Title_KO: 자료구조 언패킹과 함수 가변 인자
Description_EN: Master unpacking lists and dictionaries, and apply it to function argument systems.
Description_KO: 자료구조(리스트, 딕셔너리)의 언패킹 동작을 완벽히 마스터하고, 이를 함수의 가변 인자 매개변수 시스템에 적용해 배웁니다.

1. 
Guide_EN: Merge two dictionaries using double star unpacking.
Guide_KO: 별표 두 개(**)를 사용하여 두 딕셔너리를 하나의 새로운 딕셔너리로 결합해 봅니다.
Template_EN:
d1 = {"a": 1}
d2 = {"b": 2}
merged = {**d1, **d2}
print(merged)
Template_KO:
d1 = {"a": 1}
d2 = {"b": 2}
merged = {**d1, **d2}
print(merged)
