Description_EN: Learn how to use powerful ready-made tools like random or time using import.
Description_KO: 파이썬이 미리 만들어둔 강력한 도구(모듈)들을 가져와서 내 프로그램에 사용하는 법을 배웁니다.

1. 
Guide_EN: Use 'import' to bring in a module and access its functions with a dot (.).
Guide_KO: import를 사용해 도구함(모듈)을 통째로 불러오고, 그 안에 든 기능을 꺼내서 써봅니다.
Visual: L47S1_ImportVisualizer
Template_EN:

print(math.sqrt(16))
Template_KO:
import math
print(math.sqrt(16))

2. 
Guide_EN: Use 'from ... import' to bring in specific functions directly.
Guide_KO: from...import를 쓰면 도구함 이름을 생략하고 필요한 기능만 바로 이름으로 부를 수 있습니다.

print(f"Pi is {pi:.2f}")
Template_KO:

20. 
Guide_EN: Final exercise: Shuffle user input numbers and calculate max square root. (ex: 16 9 25)
Guide_KO: 입력받은 숫자들을 섞고, 그중 가장 큰 수의 제곱근을 구하는 종합 문제입니다. (ex: 16 9 25)
Template_EN:
