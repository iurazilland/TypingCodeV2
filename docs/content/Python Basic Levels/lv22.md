20. 
Guide_EN: Summarize a list (Sum, Max, Min) in a single pass.
Guide_KO: 리스트를 한 번만 훑어서 합계, 최댓값, 최솟값을 동시에 계산하여 출력합니다.

for d in data:
    total += d
    if d > max_v:
        max_v = d
    if d < min_v:
        min_v = d
print("Sum:", total, "Max:", max_v, "Min:", min_v)
