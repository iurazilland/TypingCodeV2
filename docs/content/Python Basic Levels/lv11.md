Lv11.
Title_EN: List Basics & Indexing
Title_KO: 리스트 기초와 인덱싱
Description_EN: Learn to manage multiple data in a line and retrieve specific values.
Description_KO: 여러 개의 데이터를 한 줄로 세워 관리하고, 원하는 위치의 값을 꺼내는 법을 배웁니다.

1. 
Guide_EN: A list stores multiple values. Start by creating and printing a full list.
Guide_KO: 리스트는 여러 값을 하나로 묶어 저장합니다. 먼저 전체 리스트를 생성하고 출력해 봅시다.
Visual: L11S1_ListConceptVisualizer
Template_EN:
colors = ["Red", "Green", "Blue"]
total_colors = len(colors)
print("All colors:", colors)
Template_KO:
colors = ["빨강", "초록", "파랑"]
total_colors = len(colors)
print("전체 색상:", colors)

2. 
Guide_EN: Indices start from 0. Use [0] to get the first item.
Guide_KO: 인덱스는 0부터 시작합니다. [0]을 사용하여 첫 번째 항목을 가져옵니다.
Visual: L11S2_ListIndexVisualizer
Template_EN:
colors = ["Red", "Green", "Blue"]
first_color = colors[0]
print("First item:", first_color)
Template_KO:
colors = ["빨강", "초록", "파랑"]
first_color = colors[0]
print("첫 번째 항목:", first_color)

3. 
Guide_EN: You can access other items using indices 1, 2, and so on.
Guide_KO: 인덱스 1, 2번을 사용하여 두 번째와 세 번째 항목을 가져옵니다.
Template_EN:
colors = ["Red", "Green", "Blue"]
print("Index 1:", colors[1])
print("Index 2:", colors[2])
Template_KO:
colors = ["빨강", "초록", "파랑"]
print("1번 인덱스:", colors[1])
print("2번 인덱스:", colors[2])

4. 
Guide_EN: Negative indexing starts from the end. -1 is the very last item.
Guide_KO: 음수 인덱스는 끝에서부터 셉니다. -1은 가장 마지막 항목입니다.
Template_EN:
nums = [10, 20, 30, 40]
last_num = nums[-1]
print("Last item:", last_num)
Template_KO:
nums = [10, 20, 30, 40]
last_num = nums[-1]
print("마지막 항목:", last_num)

5. 
Guide_EN: Use -2 to get the second to last item.
Guide_KO: -2를 사용하여 뒤에서 두 번째 항목을 가져와 봅시다.
Template_EN:
nums = [10, 20, 30, 40]
second_last = nums[-2]
print("Second to last:", second_last)
Template_KO:
nums = [10, 20, 30, 40]
second_last = nums[-2]
print("뒤에서 두 번째:", second_last)

6. 
Guide_EN: A normal variable can be reassigned to a list at any time.
Guide_KO: 일반 변수에 담긴 값을 언제든 리스트로 변경하여 덮어쓸 수 있습니다.
Template_EN:
data = 100
print("Normal:", data)
data = [10, 20]
print("List:", data)
Template_KO:
data = 100
print("일반 변수:", data)
data = [10, 20]
print("리스트 변수:", data)

7. 
Guide_EN: You can replace an entire list with a completely different list.
Guide_KO: 리스트 변수 전체를 다른 리스트로 통째로 교체할 수도 있습니다.
Template_EN:
nums = [1, 2, 3]
nums = [10, 20, 30, 40, 50]
print("Updated list:", nums)
Template_KO:
nums = [1, 2, 3]
nums = [10, 20, 30, 40, 50]
print("수정된 리스트:", nums)

8. 
Guide_EN: Use [] to create an empty list. It's often used as a starting point.
Guide_KO: []를 사용하여 아무것도 들어있지 않은 빈 리스트를 만듭니다.
Template_EN:
empty_list = []
print("Empty:", empty_list)
print("Size:", len(empty_list))
Template_KO:
empty_list = []
print("빈 리스트:", empty_list)
print("크기:", len(empty_list))

9. 
Guide_EN: Combine two lists into a new one using the + operator.
Guide_KO: + 연산자를 사용하여 두 리스트를 하나로 합칠 수 있습니다.
Template_EN:
a = [1, 2]
b = [3, 4]
c = a + b
print("Combined:", c)
Template_KO:
a = [1, 2]
b = [3, 4]
c = a + b
print("합쳐진 리스트:", c)

10. 
Guide_EN: Repeat list elements multiple times using the * operator.
Guide_KO: * 연산자를 사용하여 리스트를 여러 번 반복하여 늘립니다.
Template_EN:
blink = ["*"]
pattern = blink * 5
print("Pattern:", pattern)
Template_KO:
blink = ["*"]
pattern = blink * 5
print("패턴:", pattern)

11. 
Guide_EN: Modify a specific item by assigning a new value to its index.
Guide_KO: 특정 인덱스에 새로운 값을 할당하여 리스트의 내용을 수정합니다.
Template_EN:
fruits = ["Apple", "Banana", "Cherry"]
fruits[1] = "Blueberry"
print("Updated fruits:", fruits)
Template_KO:
fruits = ["사과", "바나나", "체리"]
fruits[1] = "블루베리"
print("수정된 과일:", fruits)

12. 
Guide_EN: You can also use negative indices to modify items from the end.
Guide_KO: 음수 인덱스를 사용하여 끝에 있는 항목을 수정할 수도 있습니다.
Template_EN:
prices = [100, 200, 300]
prices[-1] = 999
print("Updated prices:", prices)
Template_KO:
prices = [100, 200, 300]
prices[-1] = 999
print("수정된 가격:", prices)

13. 
Guide_EN: len() returns the total count of elements in the list.
Guide_KO: len()은 리스트에 담긴 전체 요소의 개수를 반환합니다.
Template_EN:
users = ["A", "B", "C", "D", "E"]
user_count = len(users)
print("Total users:", user_count)
Template_KO:
users = ["A", "B", "C", "D", "E"]
user_count = len(users)
print("전체 유저 수:", user_count)

14. 
Guide_EN: Use a variable as an index to access elements dynamically.
Guide_KO: 변수를 인덱스 번호로 사용하여 요소에 유연하게 접근해 봅시다.
Template_EN:
i = 0
colors = ["Red", "Green", "Blue"]
print("Current color:", colors[i])
Template_KO:
i = 0
colors = ["빨강", "초록", "파랑"]
print("현재 색상:", colors[i])

15. 
Guide_EN: Lists can store different data types together.
Guide_KO: 리스트 하나에 문자열, 숫자, 불리언 등 다양한 타입을 섞어서 담을 수 있습니다.
Template_EN:
mixed = ["User1", 100, True]
mixed_type = type(mixed)
print("Mixed data:", mixed)
print("Type:", mixed_type)
Template_KO:
mixed = ["유저1", 100, True]
mixed_type = type(mixed)
print("혼합 데이터:", mixed)
print("타입:", mixed_type)

16. 
Guide_EN: Practice combined indexing. Get the first and last items at once.
Guide_KO: 첫 번째(0)와 마지막(-1) 항목을 동시에 가져오는 복습을 해봅시다.
Template_EN:
nums = [10, 20, 30, 40, 50]
first_item = nums[0]
last_item = nums[-1]
print("First:", first_item, "Last:", last_item)
Template_KO:
nums = [10, 20, 30, 40, 50]
first_item = nums[0]
last_item = nums[-1]
print("처음:", first_item, "마지막:", last_item)

17. 
Guide_EN: Practice accessing an item in the middle of a longer list.
Guide_KO: 조금 더 긴 리스트에서 중간(3번 인덱스)에 위치한 값을 가져와 봅시다.
Template_EN:
scores = [85, 92, 78, 95, 88, 100]
middle_score = scores[3]
print("Index 3 score:", middle_score)
Template_KO:
scores = [85, 92, 78, 95, 88, 100]
middle_score = scores[3]
print("3번 인덱스 점수:", middle_score)

18. 
Guide_EN: Negative indices can go further back. -3 is the third from the end.
Guide_KO: 음수 인덱스는 더 뒤로 갈 수 있습니다. -3은 뒤에서 세 번째 항목입니다.
Template_EN:
cities = ["Seoul", "Tokyo", "London", "New York", "Paris"]
third_from_end = cities[-3]
print("Third from end:", third_from_end)
Template_KO:
cities = ["서울", "도쿄", "런던", "뉴욕", "파리"]
third_from_end = cities[-3]
print("뒤에서 세 번째:", third_from_end)

19. 
Guide_EN: You can use existing list values to calculate and update them.
Guide_KO: 리스트의 기존 값을 가져와 계산한 뒤 다시 저장할 수 있습니다.
Template_EN:
inventory = [10, 20, 30]
inventory[0] = inventory[0] + 5
print("Updated inventory:", inventory)
Template_KO:
inventory = [10, 20, 30]
inventory[0] = inventory[0] + 5
print("업데이트된 재고:", inventory)

20. 
Guide_EN: Final review: Create a list, change an item, and print the first and last items.
Guide_KO: 마지막 복습입니다. 리스트를 만들고, 항목을 수정한 뒤 처음과 끝을 출력해 보세요.
Template_EN:
hero = ["Warrior", 100, "Sword"]
hero[1] = 150
print("Role:", hero[0], "| HP:", hero[1])
print("Weapon:", hero[-1])
Template_KO:
hero = ["전사", 100, "검"]
hero[1] = 150
print("직업:", hero[0], "| 체력:", hero[1])
print("무기:", hero[-1])
