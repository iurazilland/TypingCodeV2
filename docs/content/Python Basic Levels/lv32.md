Title_EN: Scope & Default Parameters
Title_KO: 변수 범위와 기본 매개변수
Description_EN: Learn about where variables can be used and how to set default values for functions.
Description_KO: 변수가 어디서 사용되는지(범위)를 알아보고, 함수에 미리 값을 채워두는 편리한 기능을 배웁니다.

1. 
Guide_EN: Local Scope: Variables defined inside a function are not accessible outside.
Guide_KO: 함수 안에서 만든 변수는 그 함수 안에서만 쓸 수 있습니다. 이를 '지역 변수'라고 합니다.
Visual: L32S1_LocalScopeVisualizer
Template_EN:
def test():
    local_val = 10
    print("Inside:", local_val)

test()
Template_KO:
def test():
    local_val = 10
    print("함수 안:", local_val)

test()

2. 
Guide_EN: Parameter Scope: Function parameters also act as local variables and cannot be accessed outside.
Guide_KO: 함수가 입력받는 매개변수(예: x) 역시 함수 안에서만 사용되는 지역 변수입니다. 함수 밖에서는 부를 수 없습니다.
Template_EN:
def show_param(x):
    print("Parameter:", x)

show_param(50)
Template_KO:
def show_param(x):
    print("매개변수:", x)

show_param(50)

3. 
Guide_EN: Global Scope: Variables defined outside can be accessed inside a function.
Guide_KO: 함수 밖에서 만든 '전역 변수'는 함수 안에서도 가져와서 읽을 수 있습니다.
Template_EN:
global_val = 100

def show():
    print("Global:", global_val)

show()
Template_KO:
global_val = 100

def show():
    print("전역 변수:", global_val)

show()

4. 
Guide_EN: Variable Shadowing: A local variable with the same name as a global variable hides the global one inside the function.
Guide_KO: 함수 안과 밖에 이름이 같은 변수가 있으면, 함수 안에서는 자신의 지역 변수를 우선으로 사용합니다.
Template_EN:
msg = "Global"

def show_local():
    msg = "Local"
    print("Inside:", msg)

show_local()
print("Outside:", msg)
Template_KO:
msg = "전역"

def show_local():
    msg = "지역"
    print("함수 안:", msg)

show_local()
print("함수 밖:", msg)

5. 
Guide_EN: Global Keyword: Use 'global' to modify a global variable inside a function.
Guide_KO: 함수 안에서 밖에 있는 전역 변수의 값을 직접 바꾸고 싶을 땐 'global'이라는 약속을 사용합니다.
Template_EN:
count = 0

def increment():
    global count
    count += 1
    return count

print("Count 1:", increment())
print("Count 2:", increment())
Template_KO:
count = 0

def increment():
    global count
    count += 1
    return count

print("1차 카운트:", increment())
print("2차 카운트:", increment())

8. 
Guide_EN: Combine condition checks with the global keyword to track level ups.
Guide_KO: 경험치(exp)가 누적되어 일정 점수를 넘으면 전역 변수 level을 올려주고, 변화된 레벨을 즉시 확인해 봅니다.
Template_EN:

    global exp, level

    return level

Guide_KO: 함수 안에서 외부에 있는 'total' 변수의 값을 직접 수정(+=)하려면 'global total' 선언이 반드시 필요합니다.

20. 
Guide_EN: Final summary of Scope & Default Parameters with dynamic balance printing.
Guide_KO: 전역 계좌 잔액(bank_balance)과 기본 수수료(500)를 활용하여 출금하고 실시간 잔액을 확인하는 최종 종합 문제입니다.
Template_EN:
bank_balance = 10000

def withdraw(amount, fee=500):
    global bank_balance
    total = amount + fee
    if bank_balance >= total:
        bank_balance -= total
    return bank_balance

print("Balance 1:", withdraw(3000))
print("Balance 2 (no fee):", withdraw(2000, 0))
Template_KO:
