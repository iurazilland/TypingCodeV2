Description_EN: Learn how to insert variables and operations into strings to format your output.
Description_KO: 문자열 사이에 변수나 연산 결과를 끼워 넣어 원하는 모양으로 출력하는 방법을 배웁니다.

1. 
Guide_EN: Use the % operator to print strings (%s) and integers (%d) in specific positions.
Guide_KO: % 연산자를 사용하여 문자열(%s)과 정수(%d) 값을 원하는 위치에 출력합니다.
Visual: L36S1_FStringVisualizer

print("Score: %d" % score)

2. 
Guide_EN: Combine loop and % formatting to print a list of item names and prices.
Guide_KO: 반복문과 % 포맷팅을 조합해 상품명과 가격 리스트를 출력합니다.

3. 
Guide_EN: Use the format() method to print dictionary values inside curly braces {}.
Guide_KO: format() 메서드를 사용하여 중괄호 {} 위치에 딕셔너리 값을 출력합니다.

4. 
Guide_EN: Use the format() method inside a function to return a formatted string.
Guide_KO: 함수 매개변수들을 format() 메서드를 사용해 하나의 문자열로 완성하여 반환합니다.

    msg = "Student: {}, Score: {}"

18. 
Guide_EN: Calculate discounted prices and return them formatted with thousands separators.
Guide_KO: 함수에서 할인가를 구한 뒤 천 단위 구분 쉼표를 적용하고 소수점 없는 정수 형식으로 반환합니다.
Template_EN:

    final = price * (1 - rate)
    return f"Price: {price:,} -> {final:,.0f}"

print(get_discount(25000, 0.15))
Template_KO:

    final = price * (1 - rate)
    return f"원가: {price:,} -> 할인가: {final:,.0f}"

20. 
Guide_EN: Print a receipt with original, discount, and final amounts formatted with thousands separators. (ex: Pen 5 1200)
Guide_KO: 입력 정보를 바탕으로 원가, 할인액(10%), 최종금액을 구분 쉼표 포맷이 적용된 f-string으로 출력합니다. (ex: 볼펜 5 1200)
Template_EN:

print(f"Original: {org:,}")
print(f"Discount: {disc:,}")
print(f"Final: {final:,}")
Template_KO:

print(f"원가: {org:,}원")
print(f"할인: {disc:,}원")
print(f"최종: {final:,}원")
