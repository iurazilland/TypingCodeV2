Lv41.
Title_EN: List Copying & Starred Unpacking
Title_KO: 리스트 복사와 별표(*) 언패킹
Description_EN: Learn standard memory reference copying rules and how to slice/merge lists using starred unpacking.
Description_KO: 리스트의 표준 메모리 주소 복사 규칙(얕은/깊은 복사)과 별표(*)를 활용한 리스트 데이터 슬라이싱 및 병합을 마스터합니다.

1. 
Guide_EN: Simple assignment sharing the same memory reference.
Guide_KO: 단순 대입(=)은 리스트의 값들을 새로 복사하지 않고 기존 주소(참조)를 그대로 공유합니다.
Visual: L41S1_ListCopyVisualizer
Template_EN:
a = [1, 2, 3]
b = a
b[0] = 99
print("a:", a)
print("b:", b)
Template_KO:
a = [1, 2, 3]
b = a
b[0] = 99
print("a:", a)
print("b:", b)

2. 
Guide_EN: Use == to compare values, and is to compare memory references.
Guide_KO: == 연산자는 리스트 안의 값들을 비교하고, is 연산자는 실제 메모리 주소가 같은지 비교합니다.
Template_EN:
a = [1, 2]
b = a
print("a == b:", a == b)
print("a is b:", a is b)
Template_KO:
a = [1, 2]
b = a
print("a == b:", a == b)
print("a is b:", a is b)

3. 
Guide_EN: Use copy() to create a shallow copy with a new reference.
Guide_KO: .copy() 메서드를 사용해 복사하면 두 변수는 값은 동일하지만 서로 다른 메모리 주소를 가리킵니다.
Template_EN:
a = [1, 2]
b = a.copy()
print("a == b:", a == b)
print("a is b:", a is b)
Template_KO:
a = [1, 2]
b = a.copy()
print("a == b:", a == b)
print("a is b:", a is b)

4. 
Guide_EN: Use list slicing [:] as an alternative way to copy.
Guide_KO: [:]와 같이 범위 전체를 슬라이싱하는 문법을 사용해도 .copy()와 동일하게 얕은 복사본을 생성합니다.
Template_EN:
a = [1, 2]
b = a[:]
print("a is b:", a is b)
Template_KO:
a = [1, 2]
b = a[:]
print("a가 b인가:", a is b)

5. 
Guide_EN: Modifying a copied list does not affect the original list.
Guide_KO: .copy()나 슬라이싱으로 복사한 사본 리스트를 수정해도 원본 리스트는 변하지 않습니다.
Template_EN:
a = [1, 2]
b = a.copy()
b[0] = 99
print("a:", a, "b:", b)
Template_KO:
a = [1, 2]
b = a.copy()
b[0] = 99
print("a:", a, "b:", b)

6. 
Guide_EN: A shallow copy shares memory references for inner lists.
Guide_KO: 2차원 리스트(중첩 리스트)를 얕게 복사하면, 내부 리스트의 주소는 여전히 공유됩니다.
Template_EN:
a = [[1, 2]]
b = a.copy()
print("a[0] is b[0]:", a[0] is b[0])
Template_KO:
a = [[1, 2]]
b = a.copy()
print("내부 주소 공유:", a[0] is b[0])

7. 
Guide_EN: Modifying an inner list in a shallow copy affects the original.
Guide_KO: 얕은 복사된 중첩 리스트의 내부 요소를 바꾸면 원본 리스트의 내용도 함께 오염됩니다.
Template_EN:
a = [[1, 2]]
b = a.copy()
b[0][0] = 99
print("a:", a, "b:", b)
Template_KO:
a = [[1, 2]]
b = a.copy()
b[0][0] = 99
print("a:", a, "b:", b)

8. 
Guide_EN: Import the external copy module to use deepcopy() for duplicating nested list references.
Guide_KO: 외부 라이브러리를 불러오는 import copy를 사용하여, 내부 리스트 주소까지 완전히 복제하는 deepcopy를 활용합니다.
Template_EN:
import copy

a = [[1, 2]]
b = copy.deepcopy(a)
print("a[0] is b[0]:", a[0] is b[0])
Template_KO:
import copy

a = [[1, 2]]
b = copy.deepcopy(a)
print("내부 주소 공유:", a[0] is b[0])

9. 
Guide_EN: Modifying a deep copy inner list does not affect the original.
Guide_KO: deepcopy로 복사한 중첩 리스트의 내부 요소를 바꾸어도 원본 리스트는 안전하게 보존됩니다.
Template_EN:
import copy

a = [[1, 2]]
b = copy.deepcopy(a)
b[0][0] = 99
print("a:", a, "b:", b)
Template_KO:
import copy

a = [[1, 2]]
b = copy.deepcopy(a)
b[0][0] = 99
print("a:", a, "b:", b)

10. 
Guide_EN: Summary: Compare simple assignment, copy, and deepcopy.
Guide_KO: 대입, 얕은 복사, 깊은 복사의 참조 분리 수준 차이를 최종적으로 확인합니다.
Template_EN:
import copy

a = [[1]]
b = a
c = a.copy()
d = copy.deepcopy(a)
r1 = b is a
r2 = c[0] is a[0]
r3 = d[0] is a[0]
print(r1, r2, r3)
Template_KO:
import copy

a = [[1]]
b = a
c = a.copy()
d = copy.deepcopy(a)
r1 = b is a
r2 = c[0] is a[0]
r3 = d[0] is a[0]
print(r1, r2, r3)

11. 
Guide_EN: Starred unpacking collects remaining elements into a list.
Guide_KO: 별표(*)를 사용하면 리스트의 특정 요소를 꺼내고 남은 요소들을 하나의 리스트로 묶어 가져올 수 있습니다.
Template_EN:
nums = [1, 2, 3, 4]
first, *rest = nums
print("first:", first)
print("rest:", rest)
Template_KO:
nums = [1, 2, 3, 4]
first, *rest = nums
print("first:", first)
print("rest:", rest)

12. 
Guide_EN: Starred unpacking collects elements at the front or middle.
Guide_KO: 별표(*)의 위치에 따라 앞부분을 묶어 꺼내거나 중간 부분만 따로 묶어 꺼낼 수도 있습니다.
Template_EN:
nums = [1, 2, 3, 4]
*front, last = nums
a, *mid, b = nums
print("front:", front)
print("mid:", mid)
Template_KO:
nums = [1, 2, 3, 4]
*front, last = nums
a, *mid, b = nums
print("front:", front)
print("mid:", mid)

13. 
Guide_EN: Starred unpacking with string elements.
Guide_KO: 문자열이 담긴 리스트에서도 동일하게 별표(*)를 활용해 일부분을 묶어서 분리할 수 있습니다.
Template_EN:
langs = ["py", "js", "go", "rb"]
head, *tail = langs
print("head:", head)
print("tail:", tail)
Template_KO:
langs = ["py", "js", "go", "rb"]

14. 
Guide_EN: Merge multiple lists using starred unpacking.
Guide_KO: 별표(*)를 사용해 여러 리스트의 요소들을 펼쳐서 하나의 새로운 리스트로 쉽게 합칠 수 있습니다.
Template_EN:
a = [1, 2]
b = [3, 4]
merged = [*a, *b]
print("merged:", merged)
print("is unique:", merged is a)
Template_KO:
a = [1, 2]
b = [3, 4]
merged = [*a, *b]
print("합병 리스트:", merged)
print("주소 다른가:", merged is a)

15. 
Guide_EN: Mix individual values and lists using starred unpacking.
Guide_KO: 별표(*) 병합을 할 때 리스트와 함께 단일 숫자나 문자열 요소를 자유롭게 섞어서 결합할 수 있습니다.
Template_EN:
nums = [1, 2]
new_list = [*nums, 99, 100]
print(new_list)
Template_KO:
nums = [1, 2]
new_list = [*nums, 99, 100]

16. 
Guide_EN: Merge lists of strings and numbers.
Guide_KO: 서로 다른 타입의 리스트 데이터(문자열과 숫자 등)를 별표(*)를 사용해 하나의 리스트로 결합합니다.

Guide_EN: Unpack list elements when passing to print().
Guide_KO: 함수를 호출할 때 리스트 앞에 *를 붙이면, 리스트의 요소들이 각각 낱개로 펼쳐져 전달됩니다.

Guide_KO: 리스트의 별표(*) 병합, 복사 및 함수 인자 언패킹을 한 번에 정리하는 종합 연습 단계입니다.
