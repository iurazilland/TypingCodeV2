1. 
Guide_EN: Convert a tuple to a list using the list() function.
Guide_KO: list() 함수를 사용하여 튜플을 리스트로 변환합니다.

Template_EN:

print(l)
Template_KO:

print(l)

2. 
Guide_EN: Convert a list back to a tuple using the tuple() function.
Guide_KO: tuple() 함수를 사용하여 리스트를 튜플로 되돌립니다.
Template_EN:
l = [10, 20, 30]
t = tuple(l)
print(t)
Template_KO:
l = [10, 20, 30]
t = tuple(l)
print(t)

3. 
Guide_EN: Modify a tuple's content by converting it to a list first.
Guide_KO: 튜플은 직접 고칠 수 없으므로, 리스트로 바꾼 뒤 값을 수정하고 다시 튜플로 만듭니다.
Template_EN:
colors = ("빨강", "초록")
temp = list(colors)
print("리스트로 변환:", temp)
temp.append("파랑")
colors = tuple(temp)
print("최종 튜플:", colors)

4. 
Guide_EN: Sort a tuple by converting it to a list temporarily.
Guide_KO: 튜플의 숫자들을 정렬하고 싶을 때, 리스트로 변환하여 sort()한 뒤 다시 튜플로 바꿉니다.
Template_EN:
nums = (40, 10, 30)
temp = list(nums)
print("정렬 전 리스트:", temp)
temp.sort()
nums = tuple(temp)
print("최종 튜플:", nums)

6. 
Guide_EN: Add user input to a tuple using the list conversion pattern. (ex: cherry)
Guide_KO: 기존 튜플에 사용자가 입력한 값을 추가하여 새로운 튜플을 완성합니다. (ex: 체리)
Template_EN:
fruits = ("사과", "바나나")
new_item = input()
temp = list(fruits)
print("추가 전 리스트:", temp)

fruits = tuple(temp)
print("최종 튜플:", fruits)

7. 
Guide_EN: Filter elements from a tuple into a new tuple.
Guide_KO: 튜플에서 짝수만 골라내어 새로운 튜플을 만듭니다. (리스트를 거쳐서 변환)
Template_EN:
nums = (1, 2, 3, 4, 5, 6)
evens = []
for n in nums:
    if n % 2 == 0:
        evens.append(n)
result = tuple(evens)
print(result)
Template_KO:

8. 
Guide_EN: Swap two elements in a tuple (requires conversion).
Guide_KO: 튜플의 첫 번째와 마지막 요소의 위치를 바꾸기 위해 리스트 변환을 활용합니다.
Template_EN:
data = (100, 2, 300)
temp = list(data)
print("교체 전 리스트:", temp)
temp[0], temp[-1] = temp[-1], temp[0]
data = tuple(temp)
print("최종 튜플:", data)

9. 
Guide_EN: Count occurrences in a tuple before converting.
Guide_KO: 튜플에서 특정 값의 개수를 세고, 리스트로 변환하여 그 값을 모두 제거해 봅니다.
Template_EN:
nums = (1, 2, 1, 3, 1)
temp = list(nums)
print("제거 전 리스트:", temp)
while 1 in temp:
    temp.remove(1)
nums = tuple(temp)
print("최종 튜플:", nums)
