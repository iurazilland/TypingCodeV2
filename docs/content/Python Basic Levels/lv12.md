Lv12.
Title_EN: Multi-dimensional Lists
Title_KO: 다차원 리스트 (2D & 3D)
Description_EN: Understand nested lists and learn how to find data within them.
Description_KO: 리스트 속에 리스트가 들어있는 중첩 구조를 이해하고 데이터를 찾아내는 법을 익힙니다.

1. 
Guide_EN: A 2D list contains lists as items (rows).
Guide_KO: 2차원 리스트는 리스트를 항목(행)으로 포함합니다.
Template_EN:
matrix = [[10, 20], [30, 40]]
print("Row 0:", matrix[0])
print("Row 1:", matrix[1])
Visualizer: L12S1_MultiListVisualizer
Template_KO:
matrix = [[10, 20], [30, 40]]
print("0번 행:", matrix[0])
print("1번 행:", matrix[1])

2. 
Guide_EN: Use double indexing [row][col] to access a single cell.
Guide_KO: 이중 인덱싱 [행][열]을 사용하여 단일 셀에 접근합니다.
Template_EN:
matrix = [[1, 2], [3, 4]]
print("Element at [0][0]:", matrix[0][0])
print("Element at [1][0]:", matrix[1][0])
Template_KO:
matrix = [[1, 2], [3, 4]]
print("요소 [0][0]:", matrix[0][0])
print("요소 [1][0]:", matrix[1][0])

3. 
Guide_EN: 2D lists can be accessed like a matrix.
Guide_KO: 2차원 리스트는 행렬 방식으로 접근 가능합니다.
Visualizer: L12S3_MatrixAccessVisualizer
Template_EN:
m = [[10, 20], [30, 40]]
row0 = m[0]
print("Values:", m[0][0], m[0][1], m[1][0], m[1][1])
Template_KO:
m = [[10, 20], [30, 40]]
row0 = m[0]
print("요소들:", m[0][0], m[0][1], m[1][0], m[1][1])

4. 
Guide_EN: Modify a cell using double indexing.
Guide_KO: 이중 인덱싱을 사용하여 셀의 값을 수정합니다.
Template_EN:
matrix = [[1, 2], [3, 4]]
matrix[1][1] = 99
print("Updated matrix:", matrix)
Template_KO:
matrix = [[1, 2], [3, 4]]
matrix[1][1] = 99
print("수정된 행렬:", matrix)

5. 
Guide_EN: Rows in a 2D list can have different lengths (Jagged lists).
Guide_KO: 2차원 리스트의 각 행은 길이가 다를 수 있습니다 (지그재그 리스트).
Template_EN:
jagged = [[1, 2, 3], [4, 5]]
print("Row 0 len:", len(jagged[0]))
print("Row 1 len:", len(jagged[1]))
Template_KO:
jagged = [[1, 2, 3], [4, 5]]
print("0번 행 길이:", len(jagged[0]))
print("1번 행 길이:", len(jagged[1]))

6. 
Guide_EN: Use negative indexing to get the last item of the last row.
Guide_KO: 음수 인덱스를 사용하여 마지막 행의 마지막 항목을 가져옵니다.
Template_EN:
data = [[10, 20], [30, 40, 50]]
last_row = data[-1]
last_item = last_row[-1]
print("Last of last:", last_item)
Template_KO:
data = [[10, 20], [30, 40, 50]]
last_row = data[-1]
last_item = last_row[-1]
print("마지막 행의 마지막 요소:", last_item)

7. 
Guide_EN: Unpack a 2D list into separate row variables.
Guide_KO: 2차원 리스트를 별도의 행 변수로 언패킹합니다.
Template_EN:
matrix = [[1, 2], [3, 4]]
row1, row2 = matrix
print("Row 1:", row1, "| Row 2:", row2)
Template_KO:
matrix = [[1, 2], [3, 4]]
row1, row2 = matrix
print("1번 행:", row1, "| 2번 행:", row2)

8. 
Guide_EN: A 3x3 matrix has 3 rows and 3 columns.
Guide_KO: 3x3 행렬은 3개의 행과 3개의 열을 가집니다.
Template_EN:
grid = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
middle_row = grid[1]
middle_item = middle_row[1]
print("Middle item:", middle_item)
Template_KO:
grid = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
middle_row = grid[1]
middle_item = middle_row[1]
print("중앙 요소:", middle_item)

9. 
Guide_EN: Use variables for row and column indices.
Guide_KO: 행과 열 인덱스에 변수를 사용합니다.
Template_EN:
r, c = 2, 0
grid = [[1, 1], [1, 1], [7, 1]]
print("Selected:", grid[r][c])
Template_KO:
r, c = 2, 0
grid = [[1, 1], [1, 1], [7, 1]]
print("선택된 요소:", grid[r][c])

10. 
Guide_EN: Access diagonal elements: [0][0], [1][1], [2][2].
Guide_KO: 대각선 요소 [0][0], [1][1], [2][2]에 접근합니다.
Template_EN:
m = [[1, 0, 0], [0, 5, 0], [0, 0, 9]]
d1, d2, d3 = m[0][0], m[1][1], m[2][2]
print("Diagonal:", d1, d2, d3)
Template_KO:
m = [[1, 0, 0], [0, 5, 0], [0, 0, 9]]
d1, d2, d3 = m[0][0], m[1][1], m[2][2]
print("대각선 요소:", d1, d2, d3)

11. 
Guide_EN: A 3D list is a list containing 2D lists.
Guide_KO: 3차원 리스트는 2차원 리스트를 포함하는 리스트입니다.

Template_KO:
cube = [[[1, 2], [3, 4]], [[5, 6], [7, 8]]]

12. 
Guide_EN: Triple indexing [face][row][col] for 3D access.
Guide_KO: 삼중 인덱싱 [면][행][열]로 3차원 요소에 접근합니다.

target = cube[1][0][1]
print("Item at [1][0][1]:", target)
Template_KO:

16. 
Guide_EN: Nested lists can represent X, Y coordinates on a map.
Guide_KO: 중첩 리스트로 지도 위의 X, Y 좌표를 표현할 수 있습니다.
