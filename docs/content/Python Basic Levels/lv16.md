Lv16.
Title_EN: If-Else Control
Title_KO: 조건문 기초 (If, Else)
Description_EN: Make the computer act differently based on "if" conditions.
Description_KO: "만약 ~라면"이라는 조건을 세워 상황에 따라 컴퓨터가 다르게 행동하게 만듭니다.

1. 
Guide_EN: if runs indented code only when True. In Python, code after a colon (:) MUST be indented (usually 4 spaces).
Guide_KO: if문처럼 콜론(:)으로 끝나는 문장 다음 줄은 반드시 **들여쓰기(공백 4칸)**를 해야 합니다. 들여쓰기는 "이 코드가 if문에 속해 있다"라는 구역(Block)을 의미합니다.
Visual: L16S1_IfElseVisualizer
Template_EN:
score = 85
if score >= 60:
    print("Status: Pass")
Template_KO:
score = 85
if score >= 60:
    print("상태: 합격")

2. 
Guide_EN: if-else creates two divergent paths.
Guide_KO: if-else는 두 갈래 경로를 만듭니다.
Template_EN:

    print("Welcome, Adult")
else:
    print("Access Denied")
Template_KO:

if age >= 20:
    print("환영합니다, 성인입니다")
else:
    print("접근이 거부되었습니다")
