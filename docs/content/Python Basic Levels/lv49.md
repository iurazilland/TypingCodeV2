3. 
Guide_EN: Use a loop to write multiple lines to a file, then read and print them.
Guide_KO: 반복문(for)을 사용해 여러 줄의 텍스트를 파일에 저장한 후, 다시 읽어와 화면에 보여줍니다.
Template_EN:

12. 
Guide_EN: Import the json module, save a dictionary into a JSON file, and print it.
Guide_KO: json 모듈을 불러와 딕셔너리 형태의 데이터를 JSON 파일로 저장하고 내용을 출력해 봅니다.

20. 
Guide_EN: Parse user input, save as JSON, and verify by reloading.
Guide_KO: 사용자가 입력한 여러 개의 정수 목록을 받아 딕셔너리로 만들고, JSON 파일로 저장 후 복원하여 출력하는 종합 챌린지입니다.
Template_EN:

raw = input().split()
data = {"a": int(raw[0])}
with open("user.json", "w") as f:
    json.dump(data, f)
with open("user.json", "r") as f:
    print(json.load(f))
Template_KO:
import json
raw = input().split()
