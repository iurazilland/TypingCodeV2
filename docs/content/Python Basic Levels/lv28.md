Lv28.
Title_EN: Dictionaries Basics
Title_KO: 딕셔너리의 기초와 매핑
Description_EN: Learn how to manage data using labels with dictionaries.
Description_KO: 이름표(Key)를 붙여 데이터를 똑똑하게 관리하는 '딕셔너리'라는 서랍장을 배웁니다.

1. 
Guide_EN: Create a dictionary using curly braces {} and print it.
Guide_KO: 중괄호{}와 콜론(:)을 사용하여 간단한 딕셔너리를 만들고 출력해 봅니다.
Visual: L28S1_DictionaryConceptVisualizer
Template_EN:
user = {"name": "Alice", "age": 25}
print(user)
Template_KO:
user = {"name": "Alice", "age": 25}
print(user)

2. 
Guide_EN: Access a value using its key inside square brackets [].
Guide_KO: 리스트의 인덱스 번호 대신 '키' 이름을 사용하여 저장된 값을 가져옵니다.
Template_EN:
hero = {"power": 100, "hp": 500}
print("Power:", hero["power"])
Template_KO:
hero = {"공격력": 100, "체력": 500}
print("공격력:", hero["공격력"])

3. 
Guide_EN: Add a new key-value pair to an existing dictionary.
Guide_KO: 딕셔너리에 새로운 키를 만들고 값을 넣어서 데이터를 추가해 봅니다.
Template_EN:
stock = {"apple": 10}
stock["banana"] = 20
print(stock)
Template_KO:
stock = {"사과": 10}
stock["바나나"] = 20
print(stock)

4. 
Guide_EN: Duplicate keys are not allowed; the last value will overwrite previous ones.
Guide_KO: 딕셔너리에서 키는 중복될 수 없습니다. 같은 키를 여러 번 쓰면 마지막에 쓴 값으로 덮어씌워집니다.
Template_EN:
user = {"name": "Alice", "age": 20, "age": 30}
print(user)
Template_KO:
user = {"이름": "Alice", "나이": 20, "나이": 30}
print(user)

5. 
Guide_EN: Use input() to choose a key to display. (ex: name)
Guide_KO: 사용자가 입력한 키 이름을 통해 딕셔너리에서 해당 정보를 찾아 출력해 봅니다. (ex: 이름)
Template_EN:
key = input()
info = {"name": "Bob", "city": "Seoul"}
print(info[key])
Template_KO:
key = input()
info = {"이름": "Bob", "도시": "서울"}
print(info[key])

6. 
Guide_EN: Use the keys() method to see all keys in the dictionary.
Guide_KO: keys() 메서드를 사용하여 딕셔너리에 담긴 모든 키(이름표)의 목록을 확인합니다.
Template_EN:
car = {"brand": "Tesla", "model": "3"}
print(car.keys())
Template_KO:
car = {"brand": "Tesla", "model": "3"}
print(car.keys())

7. 
Guide_EN: Use the values() method to see all values in the dictionary.
Guide_KO: values() 메서드를 사용하여 딕셔너리의 모든 값들만 따로 모아 확인합니다.
Template_EN:
prices = {"apple": 1000, "banana": 2000}
print(prices.values())
Template_KO:
prices = {"사과": 1000, "바나나": 2000}
print(prices.values())

8. 
Guide_EN: Create a dictionary with a list as its value.
Guide_KO: 딕셔너리의 값으로 리스트를 넣어 여러 개의 데이터를 한꺼번에 관리해 봅니다.
Template_EN:
data = {"nums": [1, 2, 3]}
print(data["nums"][0])
Template_KO:
data = {"점수": [80, 90, 100]}
print(data["점수"][0])

9. 
Guide_EN: Create a dictionary with a tuple as its value.
Guide_KO: 딕셔너리의 값으로 수정이 불가능한 튜플을 넣어 안전하게 정보를 저장해 봅니다.
Template_EN:
coords = {"start": (0, 0), "end": (10, 10)}
print(coords["end"])
Template_KO:
coords = {"출발": (0, 0), "도착": (10, 10)}
print(coords["도착"])

10. 
Guide_EN: Check for key existence using the 'in' operator.
Guide_KO: 'in' 연산자를 사용하여 특정 키가 딕셔너리에 들어있는지 여부를 확인합니다.
Template_EN:
inv = {"wood": 5}
print("gold" in inv)
Template_KO:
inv = {"목재": 5}
print("금" in inv)

11. 
Guide_EN: Use a for loop to iterate through all dictionary keys.
Guide_KO: for문을 사용하여 딕셔너리에 담긴 모든 키를 하나씩 꺼내어 출력해 봅니다.
Template_EN:
scores = {"A": 90, "B": 80}
for k in scores:
    print("Key:", k, "Value:", scores[k])
Template_KO:
scores = {"수학": 90, "영어": 80}
for k in scores:
    print("과목:", k, "점수:", scores[k])

12. 
Guide_EN: Calculate the sum of all dictionary values.
Guide_KO: sum() 함수와 values()를 사용해 딕셔너리 속 모든 숫자의 합계를 구합니다.
Template_EN:
cart = {"Bread": 2500, "Milk": 3000}
total = sum(cart.values())
print("Total:", total)
Template_KO:
cart = {"빵": 2500, "우유": 3000}
total = sum(cart.values())
print("총합:", total)

13. 
Guide_EN: Check for a key's existence before accessing its value.
Guide_KO: 키가 있는지 먼저 확인하고, 있을 때만 값을 출력하여 에러를 미리 방지해 봅니다.
Template_EN:
db = {"user1": "Alice"}
target = "user2"
if target in db:
    print(db[target])
else:
    print("Not Found")
Template_KO:
db = {"user1": "Alice"}
target = "user2"
if target in db:
    print(db[target])
else:
    print("찾을 수 없음")

14. 
Guide_EN: Use the items() method to access both keys and values at once.
Guide_KO: items() 메서드를 사용해 키와 값을 한 쌍으로 묶어서 동시에 다뤄 봅니다.
Template_EN:
data = {"K": 10, "L": 20}
for k, v in data.items():
    print(k, "->", v)
Template_KO:
data = {"가": 10, "나": 20}
for k, v in data.items():
    print(k, "->", v)

15. 
Guide_EN: Build a dictionary dynamically using user input in a loop.
Guide_KO: 반복문을 돌며 사용자로부터 키와 값을 직접 입력받아 딕셔너리를 채워 봅니다.
Template_EN:
logs = {}
for i in range(2):
    k, v = input().split()
    logs[k] = v
print(logs)
Template_KO:
logs = {}
for i in range(2):
    k, v = input().split()
    logs[k] = v
print(logs)

16. 
Guide_EN: Access data inside a nested dictionary structure.
Guide_KO: 딕셔너리 안에 또 다른 딕셔너리가 들어있는 구조에서 데이터를 차례대로 꺼내 봅니다.
Template_EN:
system = {"user": {"id": "admin", "pw": "1234"}}
print(system["user"]["id"])
Template_KO:
system = {"유저": {"아이디": "admin", "비번": "1234"}}
print(system["유저"]["아이디"])

17. 
Guide_EN: Use len() to count how many key-value pairs are present.
Guide_KO: len() 함수를 사용하여 딕셔너리에 총 몇 개의 데이터 쌍이 들어있는지 확인합니다.
Template_EN:
book = {"Title": "Python", "Price": 15000}
print("Length:", len(book))
Template_KO:
book = {"제목": "Python", "가격": 15000}
print("항목 수:", len(book))

18. 
Guide_EN: Convert dictionary keys to a list and sort them.
Guide_KO: 딕셔너리의 키들을 리스트로 바꾼 뒤, 가나다순으로 정렬하여 출력해 봅니다.
Template_EN:
data = {"C": 3, "A": 1, "B": 2}
keys_l = list(data.keys())
keys_l.sort()
print(keys_l)
Template_KO:
data = {"다": 3, "가": 1, "나": 2}
keys_l = list(data.keys())
keys_l.sort()
print(keys_l)

19. 
Guide_EN: Check if a specific value exists in the dictionary's values.
Guide_KO: 'in' 연산자와 values()를 사용해 특정 '값'이 딕셔너리에 포함되어 있는지 확인합니다.
Template_EN:
codes = {"OK": 200, "Error": 404}
print(200 in codes.values())
Template_KO:
codes = {"정상": 200, "에러": 404}
print(200 in codes.values())

20. 
Guide_EN: Final practice: Calculate the average of dictionary values.
Guide_KO: 딕셔너리에 담긴 여러 점수의 평균을 sum()과 len()을 사용해 계산해 봅니다.
Template_EN:
grades = {"Math": 85, "Eng": 95, "Sci": 75}
avg = sum(grades.values()) / len(grades)
print("Average Grade:", avg)
Template_KO:
grades = {"수학": 85, "영어": 95, "과학": 75}
avg = sum(grades.values()) / len(grades)
print("평균 점수:", avg)
