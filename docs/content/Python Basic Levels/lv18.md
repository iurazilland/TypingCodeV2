Title_EN: Nested Conditionals
Title_KO: 중첩 조건문 (If inside If)
Description_EN: Master the essential 'indentation' rule when nesting conditions.
Description_KO: 조건문 안에 조건문을 넣을 때 꼭 지켜야 하는 '들여쓰기' 규칙을 완벽히 익힙니다.

1. 
Guide_EN: A nested if only runs if the outer condition is True.
Guide_KO: 중첩 if는 바깥쪽 조건이 True일 때만 안쪽 조건을 검사합니다.
Visual: L18S1_NestedIndentationVisualizer
Template_EN:
is_sunny = True
is_warm = True
if is_sunny:
    if is_warm:
        print("Perfect for a picnic!")
Template_KO:
is_sunny = True
is_warm = True
if is_sunny:
    if is_warm:
        print("소풍 가기 딱 좋은 날씨예요!")
