Title_EN: Tuple Basics
Title_KO: 튜플의 기초와 불변성
Description_EN: Learn about tuples, which are lists that cannot be changed.
Description_KO: 데이터를 바꿀 수 없게 꽉 잠가버리는 '튜플'이라는 바구니를 배웁니다.

1. 
Guide_EN: Create a tuple using parentheses () and print its content.
Guide_KO: 소괄호()를 사용하여 여러 개의 숫자를 담은 튜플을 만들고 출력해 봅니다.
Visual: L26S1_TupleConceptVisualizer
Template_EN:
nums = (10, 20, 30)
print(nums)
Template_KO:
nums = (10, 20, 30)
print(nums)

2. 
Guide_EN: Access tuple elements using the same indexing as lists.
Guide_KO: 리스트처럼 인덱스 번호[0]를 사용하여 튜플의 첫 번째 요소를 가져옵니다.
Template_EN:
point = (100, 200)
print("X:", point[0])
Template_KO:
point = (100, 200)
print("X좌표:", point[0])

3. 
Guide_EN: Verify immutability: notice that trying to change a value results in an error.
Guide_KO: 튜플은 한 번 만들면 값을 바꿀 수 없습니다. 내용을 수정하려고 하면 에러가 발생하는 것을 확인해 봅니다.
Template_EN:
data = (1, 2, 3)

print("Tuples cannot be changed.")
Template_KO:
data = (1, 2, 3)

print("튜플은 내용을 수정할 수 없습니다.")

4. 
Guide_EN: Create a single-element tuple by adding a trailing comma.
Guide_KO: 항목이 하나뿐인 튜플을 만들 때는 반드시 뒤에 쉼표(,)를 붙여야 한다는 점을 기억하세요.
Template_EN:
single = (5,)
print(type(single))
Template_KO:
single = (5,)
print(type(single))

5. 
Guide_EN: Use len() to check how many items are in a tuple.
Guide_KO: len() 함수를 사용하여 튜플에 담긴 항목이 몇 개인지 알아봅니다.
Template_EN:
colors = ("red", "green", "blue")
print("Count:", len(colors))
Template_KO:
colors = ("red", "green", "blue")
print("개수:", len(colors))

6. 
Guide_EN: Use a for loop to iterate through tuple elements.
Guide_KO: for문을 사용하여 튜플의 요소를 하나씩 꺼내어 출력해 봅니다.
Template_EN:
items = ("Apple", "Banana", "Cherry")
for item in items:
    print("Fruit:", item)
Template_KO:
items = ("사과", "바나나", "체리")
for item in items:
    print("과일:", item)

7. 
Guide_EN: Check if a specific value exists in a tuple using 'in'.
Guide_KO: 'in'을 사용하여 찾으려는 데이터가 튜플 안에 들어있는지 확인합니다.
Template_EN:
data = (10, 20, 30)
print(10 in data)
Template_KO:
data = (10, 20, 30)
print(10 in data)

8. 
Guide_EN: Assign tuple elements to multiple variables (Unpacking).
Guide_KO: 언패킹(Unpacking)을 이용해 튜플의 값을 여러 변수에 나누어 담아 봅니다.
Template_EN:
point = (3, 7)
x, y = point
print("X is", x, "Y is", y)
Template_KO:
point = (3, 7)
x, y = point
print("X는", x, "Y는", y)

9. 
Guide_EN: Unpack values received from input().split(). (ex: 10 20)
Guide_KO: 공백으로 구분된 두 입력을 받아 각각의 변수에 나누어 담습니다. (ex: 10 20)
Template_EN:
a, b = input().split()
print("A:", a, "B:", b)
Template_KO:
a, b = input().split()
print("A:", a, "B:", b)

10. 
Guide_EN: Combine tuple access with if statements.
Guide_KO: 튜플의 특정 위치 값을 확인하여 조건문(if)과 함께 사용해 봅니다.

status = (True, "System OK")

    print(status[1])
Template_KO:
status = (True, "시스템 정상")

    print(status[1])

12.

15. 
Guide_EN: Use a loop to unpack a list of tuples.
Guide_KO: 리스트 안에 담긴 여러 개의 튜플을 반복문을 돌며 변수에 나누어 담아 봅니다.

18.
