Lv19.
Title_EN: Ternary Operators
Title_KO: 삼항 연산자 (Conditional Expression)
Description_EN: Learn to shorten long conditionals into a single clean line.
Description_KO: 길고 복잡한 조건문을 한 줄로 짧고 깔끔하게 줄여서 쓰는 방법을 배웁니다.

1. 
Visual: L19S1_TernaryVisualizer
Guide_EN: Basic ternary: value if condition else other.
Guide_KO: 기본 삼항: 조건이면 값, 아니면 다른 값.
Template_EN:
score = 75
msg = "Pass" if score >= 60 else "Fail"
print("Status:", msg)
Template_KO:
score = 75
msg = "합격" if score >= 60 else "불합격"
print("상태:", msg)
