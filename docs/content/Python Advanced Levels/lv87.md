Title_EN: Generators & yield
Title_KO: 제너레이터와 yield
Description_EN: Learn how to create memory-efficient iterators using generators and the yield keyword to produce values one at a time on demand.
Description_KO: yield 키워드를 사용하여 대량의 데이터를 메모리에 한꺼번에 올리지 않고 필요할 때마다 하나씩 생성해내는 제너레이터(Generator)의 원리를 익힙니다. 메모리 효율성과 지연 평가(Lazy Evaluation)의 장점을 배웁니다.

1. 
Guide_EN: Define a basic generator function using the yield keyword.
Guide_KO: return 대신 yield를 사용하여 값을 하나씩 내보내는 기본적인 제너레이터 함수를 정의합니다.
Template_EN:
def simple_gen():
    yield 1
    yield 2
gen = simple_gen()
print("Next 1:", next(gen))
print("Next 2:", next(gen))
Template_KO:

    yield 2

3. 
Guide_EN: Observe that a generator function returns a generator object without executing its body.
Guide_KO: 제너레이터 함수를 호출하면 즉시 실행되는 것이 아니라 제너레이터 객체만 반환됨을 확인합니다.
Template_EN:
def test():
    print("Executing!")
    yield 10
g = test() # Nothing printed yet
print("Object created:", type(g))
next(g) # Now "Executing!" is printed
Template_KO:
def test():
    print("코드 실행 시작!")
    yield 10
g = test() # 아직 아무것도 출력되지 않습니다.
print("객체 타입:", type(g))
next(g) # 이제야 "코드 실행 시작!"이 출력됩니다.

11.
