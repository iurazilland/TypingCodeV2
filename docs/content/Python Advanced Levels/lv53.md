Title_EN: Lambda Functions
Title_KO: 람다 함수 (익명 함수)
Description_EN: Learn how to create small, anonymous functions in a single line using the lambda keyword for concise code.
Description_KO: def 키워드 없이 한 줄의 코드로 이름 없는 익명 함수를 빠르게 정의하고 사용하는 방법을 익히며, 코드의 간결성을 극대화합니다.

1. 
Guide_EN: Define a basic lambda function that doubles a number.
Guide_KO: 숫자를 두 배로 만드는 가장 기초적인 람다 함수를 정의하고 변수에 담아 호출합니다.
Template_EN:

print("Double 5:", double(5))
Template_KO:

print("5의 두 배:", double(5))
