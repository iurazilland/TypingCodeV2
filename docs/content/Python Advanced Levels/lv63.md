Lv63.
Title_EN: super() for Parent Calls
Title_KO: super()를 이용한 부모 호출
Description_EN: Learn how to use the super() function to call methods from a parent class within a child class, allowing you to extend existing logic rather than completely replacing it.
Description_KO: super() 함수를 사용하여 자식 클래스에서 부모 클래스의 메서드를 호출하는 방법을 익힙니다. 이를 통해 부모의 기존 로직을 재사용하면서 자식만의 기능을 추가(확장)하는 효율적인 상속 기법을 배웁니다.

1. 
Guide_EN: Use super().__init__() to initialize parent attributes within a child constructor.
Guide_KO: 자식 클래스의 생성자(__init__)에서 super().__init__()을 호출하여 부모의 속성을 먼저 초기화합니다.
Template_EN:
class Animal:
    def __init__(self, name):
        self.name = name
class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)
        self.breed = breed
my_dog = Dog("Buddy", "Poodle")
print(f"Name: {my_dog.name}, Breed: {my_dog.breed}")
Template_KO:

    def __init__(self, name):
        self.name = name
