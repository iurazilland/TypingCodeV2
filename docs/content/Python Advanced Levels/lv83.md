Title_EN: Function Decorators
Title_KO: 함수 데코레이터 (Decorators)
Description_EN: Learn how to use decorators to dynamically add functionality to existing functions or methods without modifying their source code.
Description_KO: 기존의 함수를 수정하지 않고도 새로운 기능을 추가하거나 수정할 수 있게 해주는 데코레이터(Decorator)의 개념을 익힙니다. "함수를 인자로 받아 다른 함수를 반환하는 함수"라는 고차 함수의 원리를 이해하고, 파이썬의 @ 심볼을 이용한 세련된 기능 확장 기법을 배웁니다.

1. 
Guide_EN: Understand that functions are objects and can be passed as arguments to other functions.
Guide_KO: 파이썬에서 함수는 객체이므로, 다른 함수의 인자(parameter)로 전달될 수 있음을 확인합니다.

4. 
Guide_EN: Create a basic decorator that prints a message before and after a function call.
Guide_KO: 호출될 함수를 감싸서(Wrap) 실행 전후에 메시지를 출력해주는 기본적인 데코레이터 구조를 만듭니다.
Template_EN:
def deco(f):
    def wrapper():
        print("--- Start ---")
        f()
        print("---  End  ---")
    return wrapper
def say_hi(): print("Hi!")
wrapped = deco(say_hi)
wrapped()
Template_KO:

Guide_KO: @ 심볼을 사용하여 함수 정의 바로 위에 데코레이터를 적용하는 파이썬 표준 방식을 실습합니다.

6. 
Guide_EN: Create a decorator that works with functions that accept arguments using *args and **kwargs.
Guide_KO: *args와 **kwargs를 사용하여 인자가 있는 함수에도 범용적으로 쓸 수 있는 데코레이터를 만듭니다.
Template_EN:
def deco(f):
    def wrapper(*args, **kwargs):
        print("Arguments:", args)
        return f(*args, **kwargs)
    return wrapper

9. 
Guide_EN: Use a decorator to measure the execution time of a function.
Guide_KO: 함수가 시작되고 끝날 때의 시간을 측정하여 실행 속도를 알려주는 데코레이터를 실습합니다.
Template_EN:
import time
def timer(f):
    def wrapper():
        start = time.time()
        f()
        print(f"Time: {time.time() - start:.5f}s")
    return wrapper

@timer
def heavy(): time.sleep(0.1)
heavy()

16. 
Guide_EN: Use 'functools.wraps' to preserve the metadata of the original function.
Guide_KO: 데코레이터를 써도 원본 함수의 이름(__name__)이나 설명문이 지워지지 않게 @wraps를 사용합니다.
Template_EN:

    def wrapper(): return f()
    return wrapper

@deco
def original(): """DOC"""

17. 
Guide_EN: Implement a basic decorator with arguments (Nested three levels).
Guide_KO: 데코레이터 자체에 인자(count)를 넘겨주기 위해 함수를 3단계로 중첩하여 정의해 봅니다.

20. 
Guide_EN: Complete a final task by creating a robust 'Logger' decorator for a math function.
Guide_KO: 함수가 실행될 때마다 인자와 결과값을 자동으로 기록하는 만능 로거 데코레이터를 완성하며 마무리합니다.
