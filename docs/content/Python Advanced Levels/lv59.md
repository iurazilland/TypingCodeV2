Title_EN: Variadic Args & Helpers

Description_EN: Learn how to handle a flexible number of arguments using *args and **kwargs, and master built-in tools like zip and enumerate.
Description_KO: 개수가 정해지지 않은 인자를 처리하는 *args와 **kwargs의 원리를 이해하고, zip, enumerate 등 파이썬의 생산성을 높여주는 핵심 내장 함수들을 익힙니다.

1. 
Guide_EN: Use zip() to combine two lists into pairs and iterate through them.
Guide_KO: zip()을 사용하여 두 개의 리스트를 병렬로 묶고 반복문으로 동시에 꺼내옵니다.

Guide_KO: any() 함수를 사용하여 리스트에 조건에 맞는 요소가 하나라도 있는지 확인합니다.

5. 
Guide_EN: Define a function with *args to accept any number of positional arguments.
Guide_KO: *args를 매개변수로 사용하여 인자의 개수에 상관없이 모두 받아 처리하는 함수를 만듭니다.

15.

Guide_EN: Complete a final task using a universal logger with *args and a prefix.
Guide_KO: 가변 인자와 접두사(prefix)를 받아 로그 메시지를 생성하는 함수를 완성하며 마무리합니다.
