Title_EN: Encapsulation & Private Variables
Title_KO: 캡슐화와 비공개 변수
Description_EN: Learn how to protect class data from direct external access using single (_) and double (__) underscore conventions for encapsulation.
Description_KO: 클래스 내부의 중요한 데이터를 외부에서 함부로 수정하지 못하도록 보호하는 캡슐화(Encapsulation) 기술을 익힙니다. 관례적인 보호(_)와 강제적인 비공개(__) 처리의 차이점을 이해하고 안전한 클래스를 설계하는 방법을 배웁니다.

1. 
Guide_EN: Use a single underscore (_) to indicate a variable is intended for internal use.
Guide_KO: 변수명 앞에 언더바 하나(_)를 붙여 외부 접근을 자제하라는 관례적인 표시를 남깁니다.
Template_EN:
class User:
    def __init__(self, name):
        self._name = name
u = User("Alice")
print("Internal Name:", u._name)
Template_KO:
class User:
    def __init__(self, name):
        self._name = name
u = User("Alice")
print("내부 이름:", u._name)

2. 
Guide_EN: Use double underscores (__) to make a variable private and trigger name mangling.
Guide_KO: 언더바 두 개(__)를 사용하여 외부에서 변수 이름을 직접 찾지 못하도록 비공개 처리를 합니다.

class Secret:

14. 
Guide_EN: Return a copy of a private list using slicing to prevent external mutation.
Guide_KO: 비공개 리스트를 밖으로 줄 때 슬라이싱[:]을 사용하여 원본이 아닌 복사본을 전달합니다.
