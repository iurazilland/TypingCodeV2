Title_EN: Advanced Exception Handling
Title_KO: 예외 처리 심화 (Multi-Except)
Description_EN: Master complex error handling by catching specific exceptions and using multiple except blocks to manage different failure scenarios precisely.
Description_KO: 한 번에 여러 에러를 처리하는 방법과 특정 에러 상황에 맞춰 상세하게 대응하는 기술을 익힙니다. 다중 except 블록과 예외 정보를 활용하여 더 정교하고 견고한 에러 방어 체계를 구축하는 방법을 배웁니다.

1. 
Guide_EN: Use multiple except blocks to handle different types of errors uniquely.
Guide_KO: 발생 가능한 에러의 종류(ZeroDivision, ValueError)마다 각각의 except 블록을 두어 다르게 대응합니다.
Template_EN:
try:
    n = int("10") / 0
except ZeroDivisionError: print("Division Error")
except ValueError: print("Parse Error")
Template_KO:
try:
    n = int("10") / 0
except ZeroDivisionError: print("나눗셈 에러")
except ValueError: print("변환 에러")

2. 
Guide_EN: Catch multiple related errors in a single except block using a tuple.
Guide_KO: 튜플(에러1, 에러2) 형식을 사용하여 연관된 여러 에러를 하나의 블록에서 처리합니다.
Template_EN:
try:
    data = [1, 2]
    print(data[10] + "hi")
except (IndexError, TypeError) as e:
    print(f"Error Caught: {type(e).__name__}")
Template_KO:
try:
    data = [1, 2]
    print(data[10] + "hi")
except (IndexError, TypeError) as e:
    print(f"에러 감지: {type(e).__name__}")

3. 
Guide_EN: Use a general Exception block at the end as a fallback for unknown errors.
Guide_KO: 특정 에러들을 먼저 잡고, 마지막에 일반 Exception을 두어 예상치 못한 모든 에러를 최종 방어합니다.
Template_EN:
try:
    # Trigger an unknown error
    res = unknown_func()
except NameError: print("Name error")
except Exception: print("Final fallback")
Template_KO:

    # 정의되지 않은 함수 호출

except NameError: print("이름 에러")

6. 
Guide_EN: Handle nested try-except blocks for complex operations.
Guide_KO: try 블록 안에 또 다른 try-except를 넣어 외부 에러와 내부 에러를 단계적으로 방어합니다.

9.

Guide_KO: 함수 내부에서 발생하는 에러를 잡아내고, 에러 발생 시 특정 결과값(None)을 반환하게 설계합니다.
