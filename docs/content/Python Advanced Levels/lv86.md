4. 
Guide_EN: Create a custom iterator class using __iter__ and __next__ methods.
Guide_KO: __iter__와 __next__ 메서드를 구현하여 나만의 반복자 클래스를 정의해 봅니다.

    def __init__(self, n): self.n = n; self.i = 0

        else: raise StopIteration

20. 
Guide_EN: Complete a final task by implementing a reverse iterator class.
Guide_KO: 리스트를 뒤에서부터 거꾸로 꺼내주는 역방향 반복자 클래스를 직접 구현하며 마무리합니다.
Template_EN:
class ReverseIter:
    def __init__(self, data): self.data = data; self.i = len(data)
    def __iter__(self): return self
    def __next__(self):
        if self.i > 0:
            self.i -= 1; return self.data[self.i]
        raise StopIteration
print(list(ReverseIter([1, 2, 3])))
Template_KO:
