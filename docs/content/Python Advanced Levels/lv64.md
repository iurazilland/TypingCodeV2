Title_EN: Class & Static Methods
Title_KO: 클래스 메서드와 정적 메서드
Description_EN: Learn how to define methods that belong to the class itself rather than individual instances using @classmethod and @staticmethod decorators.
Description_KO: @classmethod와 @staticmethod 데코레이터를 사용하여 개별 객체(인스턴스)가 아닌 클래스 자체에 소속된 메서드를 정의하고 사용하는 방법을 익힙니다. 인스턴스 메서드와의 차이점을 이해하고 상황에 맞는 메서드 설계를 배웁니다.

1. 
Guide_EN: Define a basic @classmethod that accesses a class-level variable using the 'cls' parameter.
Guide_KO: @classmethod를 정의하고 cls 매개변수를 통해 클래스 변수(count)에 접근하여 값을 출력합니다.
