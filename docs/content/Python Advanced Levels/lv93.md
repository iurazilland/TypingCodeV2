Title_EN: Dates & Times (datetime)
Title_KO: 날짜와 시간 (datetime 모듈)
Description_EN: Learn how to handle time-related data using the datetime module, including formatting, parsing strings, and calculating time differences.
Description_KO: 파이썬의 datetime 모듈을 사용하여 현재 시각을 구하고, 날짜와 시간 데이터를 우리가 원하는 형식으로 바꾸거나 날짜 사이의 차이를 계산하는 방법을 익힙니다. 시간 데이터를 다루는 실무적인 기술을 배웁니다.

1. 
Guide_EN: Use datetime.now() to get the current local date and time.
Guide_KO: datetime.now()를 사용하여 현재의 정확한 날짜와 시각 정보를 가져옵니다.
Template_EN:
from datetime import datetime
now = datetime.now()
print("Current:", now)
Template_KO:
from datetime import datetime
now = datetime.now()
print("현재 시각:", now)

Guide_KO: date.today()를 사용하여 시, 분, 초를 제외한 오늘 날짜 정보만 가져옵니다.

4. 
Guide_EN: Format a date object into a readable string using strftime().
Guide_KO: strftime() 메서드를 사용하여 날짜 데이터를 "2026-02-08"과 같이 원하는 형식의 문자열로 바꿉니다.
Template_EN:
from datetime import datetime
now = datetime.now()
fmt = now.strftime("%Y-%m-%d %H:%M:%S")
print("Formatted:", fmt)
Template_KO:
from datetime import datetime
now = datetime.now()
fmt = now.strftime("%Y-%m-%d %H:%M:%S")
print("포맷 변환:", fmt)

5. 
Guide_EN: Use input() to provide a date string and parse it using strptime(). (e.g. 2026-12-25)
Guide_KO: 날짜 문자열(s)을 입력받아 strptime()을 통해 실제 datetime 객체로 변환합니다. (예: 2026-12-25)
Template_EN:
s = input()
from datetime import datetime
obj = datetime.strptime(s, "%Y-%m-%d")

Template_KO:

from datetime import datetime

6. 
Guide_EN: Access individual components like year, month, and day from a date object.
Guide_KO: 날짜 객체에서 연(.year), 월(.month), 일(.day) 정보를 각각 따로 추출해 봅니다.

Template_KO:

7. 
Guide_EN: Use timedelta to add or subtract days from a date.
Guide_KO: timedelta를 사용하여 오늘로부터 며칠 뒤 혹은 며칠 전의 날짜를 계산합니다.

print("Tomorrow:", tomorrow)
Template_KO:

8. 
Guide_EN: Calculate the difference between two dates to get the number of days.
Guide_KO: 두 날짜 객체를 뺄셈(-) 연산하여 그 사이의 기간(days)이 얼마인지 확인합니다.
Template_EN:
from datetime import date
d1 = date(2026, 1, 1); d2 = date(2026, 1, 10)
diff = d2 - d1
print("Days difference:", diff.days)
Template_KO:
from datetime import date
d1 = date(2026, 1, 1); d2 = date(2026, 1, 10)
diff = d2 - d1
print("날짜 차이:", diff.days, "일")

14. 
Guide_EN: Convert a Unix timestamp (seconds since 1970) back into a datetime object.
Guide_KO: 유닉스 타임스탬프(숫자)를 datetime.fromtimestamp()를 통해 날짜 형식으로 복원합니다.

19. 
Guide_EN: Understand the concept of "Naive" vs "Aware" datetimes regarding timezones (Conceptual).
Guide_KO: (개념) 시간대(Timezone) 정보가 없는 Naive 객체와 정보가 포함된 Aware 객체의 차이를 이해합니다.

20.

Guide_KO: 특정 목표 날짜까지 남은 기간(D-Day)을 계산하여 출력하며 마무리합니다.
