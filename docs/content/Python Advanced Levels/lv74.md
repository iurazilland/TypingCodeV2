Title_EN: Custom Modules & __name__
Title_KO: 사용자 정의 모듈과 __name__
Description_EN: Learn how to organize your code into separate files and understand the special __name__ variable to distinguish between a script being run directly or imported as a module.
Description_KO: 코드를 여러 파일로 나누어 관리하는 사용자 정의 모듈의 원리를 이해하고, 특수 변수 __name__을 사용하여 파일이 직접 실행될 때와 모듈로 불러와질 때의 동작을 구분하는 방법을 배웁니다.

1. 
Guide_EN: Understand the concept of importing another Python file as a module (Conceptual).
Guide_KO: 다른 파이썬 파일(.py)을 하나의 모듈처럼 불러와서 그 안의 함수를 사용하는 원리를 이해합니다.
Template_EN:
# Imagine 'tools.py' exists with a function 'greet()'
# import tools
# tools.greet()
print("Concept: File 'tools.py' becomes module 'tools'")
Template_KO:
# 'tools.py'라는 파일에 'greet()' 함수가 있다고 가정합니다.
# import tools
# tools.greet()
print("개념: 'tools.py' 파일이 'tools' 모듈이 됩니다.")

2. 
Guide_EN: Use the __name__ variable to see the name of the current module.
Guide_KO: 특수 변수 __name__을 출력하여 현재 실행 중인 파일의 모듈 이름을 확인합니다.
Template_EN:
print("Current module name:", __name__)
Template_KO:
print("현재 모듈 이름:", __name__)

3. 
Guide_EN: Learn the common idiom to check if a script is run directly.
Guide_KO: 파일이 메인으로 직접 실행될 때만 코드가 작동하도록 하는 'if __name__ == "__main__":' 형식을 익힙니다.
Template_EN:

Template_KO:

4.

Guide_KO: 직접 실행 중인 파일에서는 __name__ 값이 항상 "__main__"으로 설정됨을 확인합니다.

Template_KO:
