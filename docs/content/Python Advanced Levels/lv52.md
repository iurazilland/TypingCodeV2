Title_EN: Nested Dictionary Access

Description_EN: Learn how to navigate and modify values within complex, nested structures involving dictionaries and lists.
Description_KO: 딕셔너리 내부에 또 다른 딕셔너리나 리스트가 얽혀 있는 복잡한 데이터 구조에서 원하는 정보를 정확히 추출하고 수정하는 기술을 익힙니다.

1. 
Guide_EN: Access a value from a two-level nested dictionary using sequential keys.
Guide_KO: 딕셔너리 안의 딕셔너리 구조에서 대괄호를 두 번 사용하여 내부의 값을 가져옵니다.

6. 
Guide_EN: Use the get() method to access nested keys safely with a fallback.
Guide_KO: get()을 단계적으로 사용하여 키가 없을 경우에도 에러 없이 기본값을 가져오게 합니다.

9. 
Guide_EN: Iterate over a nested dictionary and print its inner keys and values.
Guide_KO: 외부 딕셔너리의 아이템들을 순회하며 내부 딕셔너리의 정보(role)를 꺼내 봅니다.

16. 
Guide_EN: Deep copy a nested structure and modify it independently.
Guide_KO: deepcopy를 사용하여 중첩 딕셔너리를 복제하고, 원본에 영향을 주지 않고 값을 바꿉니다.

20. 
Guide_EN: Complete a final task to parse and sum values from a nested list of objects.
Guide_KO: 복잡한 중첩 데이터에서 핵심 리스트를 꺼내고, 값(val)들의 합계를 구하며 마무리합니다.
Template_EN:

print("Final Sum:", total)
Template_KO:
