Title_EN: Specific Imports (from ... import)
Title_KO: 특정 기능만 불러오기 (from ... import)
Description_EN: Learn how to import specific functions, constants, or classes from a module directly into your namespace for cleaner and more efficient code.
Description_KO: 모듈 전체가 아닌 필요한 함수, 상수, 클래스만 골라서 현재 소스 코드로 직접 가져오는 방법을 익힙니다. 모듈 이름을 생략하고 기능을 바로 호출할 수 있어 코드가 더 간결해지는 장점을 배웁니다.

1. 
Guide_EN: Use from ... import to load a specific constant from the math module.
Guide_KO: math 모듈 전체가 아닌 pi(원주율) 상수 하나만 직접 불러와서 사용합니다.

6. 
Guide_EN: Import all functions from a module using the wildcard (*).
Guide_KO: 애스터리스크(*)를 사용하여 모듈의 모든 공개된 기능을 한꺼번에 불러와 봅니다.

7. 
Guide_EN: Understand the potential namespace conflict risks of using import (*).
Guide_KO: import *를 사용하면 내 코드의 변수명이 모듈의 이름과 겹칠 수 있는 위험이 있음을 인지합니다.
Template_EN:
# Local variable named 'pow'
pow = "My Power"
from math import *
print("Current pow:", pow) # Might be replaced by math.pow
Template_KO:
# 'pow'라는 이름의 지역 변수
pow = "내 능력치"
from math import *
print("현재 pow:", pow) # math.pow로 덮어씌워질 수 있습니다.

13. 
Guide_EN: Use input() to choose which specific function to import via __import__. (e.g. sqrt)
Guide_KO: 함수 이름(f)을 입력받아 math 모듈에서 해당 기능만 동적으로 가져오는 고급 기법을 연습합니다. (예: sqrt)
