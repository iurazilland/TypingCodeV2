Lv62.
Title_EN: Method Overriding
Title_KO: 메서드 오버라이딩 (Overriding)
Description_EN: Learn how to redefine methods in a child class that were already defined in its parent class to change or extend their behavior.
Description_KO: 부모 클래스로부터 물려받은 메서드를 자식 클래스에서 동일한 이름으로 다시 정의하여, 자식 클래스만의 특수한 동작을 구현하는 오버라이딩 기법을 익힙니다.

1. 
Guide_EN: Override a basic parent method to change its output in the child class.
Guide_KO: 부모 클래스의 기본 기능을 무시하고 자식 클래스에서 새로운 문구를 출력하도록 재정의합니다.
Template_EN:
class Animal:
    def speak(self): print("Noise")
class Dog(Animal):
    def speak(self): print("Woof")
Dog().speak()
Template_KO:
class Animal:
    def speak(self): print("소리")
class Dog(Animal):
    def speak(self): print("멍멍")
Dog().speak()

3. 
Guide_EN: Use a list of child objects and call the same method name (Polymorphism).
Guide_KO: 서로 다른 자식 객체들을 리스트에 담고, 동일한 이름의 메서드를 호출하여 각자의 개성을 확인합니다.
