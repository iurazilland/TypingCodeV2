Title_EN: Custom Context Managers
Title_KO: 사용자 정의 컨텍스트 매니저
Description_EN: Learn how to create your own context managers using the __enter__ and __exit__ magic methods to manage setup and teardown logic within a with block.
Description_KO: with 문에서 사용할 수 있는 나만의 컨텍스트 매니저를 만드는 방법을 배웁니다. __enter__와 __exit__ 메서드를 활용하여 작업 시작 전의 설정(Setup)과 종료 후의 정리(Teardown)를 자동으로 수행하는 객체를 설계하는 기술을 익힙니다.

1. 
Guide_EN: Understand the role of __enter__ in a context manager class.
Guide_KO: 컨텍스트 매니저 클래스에서 with 문이 시작될 때 호출되는 __enter__ 메서드의 역할을 이해합니다.
Template_EN:
class Tool:
    def __enter__(self):
        print("Setup: Tool ready")
        return self
    def __exit__(self, exc_type, exc_val, exc_tb): pass

with Tool():
    print("Working with tool...")
Template_KO:

    def __enter__(self):

with Tool():
    print("도구로 작업 중...")
