20. 
Guide_EN: Complete a comprehensive data pipeline using nested generators.
Guide_KO: 대문자 변환 제너레이터와 필터 제너레이터를 연결하여 최종 결과물을 생성하며 마무리합니다.
Template_EN:

res = upper_gen(filter_gen(data))
print("Final Pipeline:", list(res))
