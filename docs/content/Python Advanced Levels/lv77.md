Title_EN: Writing & Appending Files
Title_KO: 파일 쓰기와 내용 추가
Description_EN: Learn how to create new files and modify existing ones using the write ('w') and append ('a') modes.
Description_KO: 파이썬의 write('w') 모드와 append('a') 모드를 사용하여 새로운 파일을 생성하거나 기존 파일에 내용을 덧붙이는 방법을 익힙니다. 덮어쓰기(overwrite)의 위험성과 안전하게 데이터를 기록하는 기술을 배웁니다.

1. 
Guide_EN: Use the 'w' mode to create a new file and write text to it.
Guide_KO: 'w' 모드로 파일을 열어 새로운 텍스트를 작성합니다. 기존에 파일이 있다면 내용이 모두 지워짐을 주의합니다.
Template_EN:
f = open("new.txt", "w")
f.write("Hello Python")
f.close()
print("File created and written.")
Template_KO:
f = open("new.txt", "w")
f.write("안녕 파이썬")
f.close()
print("파일 생성 및 작성 완료.")

2. 
Guide_EN: Observe that 'w' mode overwrites existing content in a file.
Guide_KO: 동일한 파일명에 'w' 모드로 다시 쓰면 기존의 데이터가 사라지고 새 내용으로 교체됨을 확인합니다.
Template_EN:

f.write("Overwritten content")
f.close()
# Read to verify
f = open("new.txt", "r")
print(f.read())
f.close()
Template_KO:

f.write("덮어씌워진 내용")

# 확인을 위해 읽기

print(f.read())
f.close()

Template_KO:

14. 
Guide_EN: Use the flush() method to force write buffer to disk without closing.
Guide_KO: 파일을 닫지 않은 상태에서 기록 중인 데이터를 즉시 저장 장치로 밀어넣는 flush() 기능을 실습합니다.

20. 
Guide_EN: Complete a final task by saving a dictionary-like data structure into a text file.
Guide_KO: 딕셔너리의 키와 값을 "키:값" 형태로 한 줄씩 파일에 저장하며 마무리합니다.
Template_EN:

f.close()
Template_KO:
