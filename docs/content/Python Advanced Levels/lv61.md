Title_EN: Class Inheritance Basics

Description_EN: Learn how to create new classes that inherit attributes and methods from existing classes to promote code reuse.
Description_KO: 기존 클래스의 속성과 메서드를 그대로 물려받아 새로운 클래스를 생성하는 상속(Inheritance)의 기본 원리를 이해하고, 중복 코드를 줄여 효율적으로 클래스를 설계하는 방법을 익힙니다.

1. 
Guide_EN: Define a parent class and a child class that inherits from it.
Guide_KO: 부모 클래스와 이를 상속받는 자식 클래스의 가장 기본적인 선언 구조를 실습합니다.
