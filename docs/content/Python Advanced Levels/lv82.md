Title_EN: Property Decorators (@property)
Title_KO: 프로퍼티 데코레이터 (@property)
Description_EN: Learn how to use the @property decorator to define methods that can be accessed like attributes, providing a clean interface for data validation and computation.
Description_KO: 메서드를 일반 변수(속성)처럼 다룰 수 있게 해주는 @property 데코레이터를 익힙니다. 데이터를 읽거나 수정할 때 내부적으로 로직을 실행하면서도 외부에서는 변수처럼 간결하게 접근할 수 있는 세련된 파이썬식 캡슐화 방법을 배웁니다.

1. 
Guide_EN: Use the @property decorator to define a getter that looks like a normal attribute.
Guide_KO: @property를 사용하여 메서드를 호출할 때 괄호() 없이 일반 변수처럼 값을 읽어옵니다.
Template_EN:
class User:
    def __init__(self, name): self.__name = name
    @property
    def name(self): return self.__name
u = User("Alice")

2. 
Guide_EN: Use the @name.setter decorator to define a method for updating a property.
Guide_KO: @이름.setter를 사용하여 프로퍼티 값을 수정할 때 실행될 로직을 정의합니다.
Template_EN:
class Unit:
    def __init__(self): self.__hp = 100
    @property

    @hp.setter

print("HP:", u.hp)
