Title_EN: Exception Handling Basics
Title_KO: 예외 처리 기초 (try-except)
Description_EN: Learn how to handle runtime errors gracefully using try and except blocks to prevent your programs from crashing unexpectedly.
Description_KO: 프로그램 실행 중 발생하는 예기치 못한 에러(Runtime Error)를 감지하고 적절히 대응하는 try-except 구문을 익힙니다. 에러로 인해 시스템이 중단되는 것을 방지하고 안정적인 프로그램을 만드는 기초를 배웁니다.

1. 
Guide_EN: Use a basic try-except block to handle division by zero.
Guide_KO: 0으로 숫자를 나누려 할 때 발생하는 ZeroDivisionError를 감지하여 프로그램 중단을 막습니다.
Template_EN:
try:
    res = 10 / 0
except ZeroDivisionError:
    print("Error: Cannot divide by zero.")
Template_KO:
try:
    res = 10 / 0
except ZeroDivisionError:
    print("에러: 0으로 나눌 수 없습니다.")

2. 
Guide_EN: Catch ValueError when converting an invalid string to an integer.

Template_EN:

    num = int("abc")
except ValueError:
    print("Error: Invalid numeric string.")
Template_KO:
try:
    num = int("abc")
except ValueError:
    print("에러: 유효한 숫자 형식이 아닙니다.")

3. 
Guide_EN: Observe that code after an error inside a try block is skipped.
Guide_KO: try 블록 내부에서 에러가 발생하면 그 아래의 코드들은 실행되지 않고 즉시 except로 넘어감을 확인합니다.
Template_EN:

    print("Step 1")
    1 / 0
    print("Step 2 (Skipped)")

Template_KO:

    print("1단계")
    1 / 0
    print("2단계 (건너뜀)")
