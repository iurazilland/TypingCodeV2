Title_EN: Else & Finally Blocks
Title_KO: Else와 Finally 블록 활용
Description_EN: Explore advanced control flow in exception handling by using the else block for success scenarios and the finally block for mandatory cleanup tasks.
Description_KO: 예외 처리의 완성도를 높여주는 else와 finally 블록을 익힙니다. 에러 없이 성공했을 때만 실행되는 else와, 성공과 실패 여부에 상관없이 항상 실행되는 finally를 통해 자원 정리와 안정적인 흐름 제어 방법을 배웁니다.

1. 
Guide_EN: Use the 'else' block to run code only when no exceptions were raised in the try block.
Guide_KO: try 블록에서 에러 없이 로직이 성공했을 때만 추가로 실행될 코드를 else 블록에 작성합니다.
Template_EN:
try:
    num = int("100")
except ValueError:
    print("Failed")
else:
    print("Success! Number is", num)
Template_KO:
try:
    num = int("100")
except ValueError:
    print("변환 실패")
else:
    print("성공! 숫자는", num)

20. 
Guide_EN: Complete a final task implementing a safe data parser with else/finally.
Guide_KO: 데이터를 파싱하여 유효하면 성공 로그(else)를, 어떤 경우든 작업 완료(finally)를 남기며 마무리합니다.

    finally:
