Title_EN: The With Statement (Context Manager)
Title_KO: With 문과 컨텍스트 매니저
Description_EN: Learn the Pythonic way to handle files using the with statement, which automatically closes files and manages resources even if errors occur.
Description_KO: 파이썬에서 파일을 다루는 가장 권장되는 방법인 with 문을 익힙니다. with 문을 사용하면 파일을 수동으로 닫을(close) 필요 없이 블록이 끝나면 자동으로 닫히며, 에러가 발생하더라도 안전하게 자원을 관리해주는 컨텍스트 매니저의 원리를 배웁니다.

1. 
Guide_EN: Use the 'with' statement to open and read a file without calling close().
Guide_KO: with 문을 사용하여 파일을 열고 내용을 읽습니다. 별도로 close()를 호출하지 않아도 됨을 배웁니다.
Template_EN:
with open("test.txt", "r") as f:
    print(f.read())
# File is automatically closed here
Template_KO:
with open("test.txt", "r") as f:
    print(f.read())
# 블록을 나가면 파일이 자동으로 닫힙니다.

6.

Guide_KO: with 블록 안에서 에러가 발생하더라도 파일은 안전하게 닫힌다는 점을 인지합니다.
