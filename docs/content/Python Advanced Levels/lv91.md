20. 
Guide_EN: Complete a final task by using Counter and defaultdict together to analyze word distributions.
Guide_KO: 여러 단어의 빈도수를 세고(Counter), 글자 수별로 단어들을 분류(defaultdict)하는 종합 응용 과제를 수행합니다.

print("Freq:", dict(freq), "| By Length:", dict(by_len))
Template_KO:
