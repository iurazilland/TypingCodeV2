Title_EN: Aliasing Modules & Names (as)
Title_KO: 모듈과 이름에 별칭 붙이기 (as)
Description_EN: Learn how to use the 'as' keyword to give modules or specific functions a shorter or more descriptive alias to avoid name conflicts and simplify your code.
Description_KO: 'as' 키워드를 사용하여 모듈이나 특정 기능에 새로운 별명(Alias)을 부여하는 방법을 배웁니다. 이름이 너무 길거나 다른 변수와 겹칠 때 짧고 명확한 별칭을 사용함으로써 코드의 가독성을 높이고 충돌을 방지하는 기술을 익힙니다.

1. 
Guide_EN: Use the 'as' keyword to give a shorter alias to a module.
Guide_KO: 모듈 이름이 길 때 'import 모듈명 as 별명' 형식을 사용하여 짧게 줄여서 호출합니다.
Template_EN:
import math as m
print("PI:", m.pi)
Template_KO:
import math as m
print("원주율:", m.pi)

2. 
Guide_EN: Alias a specific function imported via the from ... import syntax.
Guide_KO: 특정 함수를 불러올 때도 'as'를 사용하여 내가 원하는 다른 이름으로 변경할 수 있습니다.
Template_EN:
from math import sqrt as s
print("Sqrt 25:", s(25))
Template_KO:
from math import sqrt as s
print("25의 제곱근:", s(25))

Guide_KO: random 모듈을 'rd'라는 짧은 별칭으로 불러와 무작위 숫자를 생성해 봅니다.

8. 
Guide_EN: Resolve a name conflict by aliasing one of the conflicting names.
Guide_KO: 내 코드의 변수명과 겹치는 모듈 함수를 다른 이름(별칭)으로 불러와 충돌을 방지합니다.
