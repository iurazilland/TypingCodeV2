Title_EN: Reading Files Basics
Title_KO: 파일 읽기 기초
Description_EN: Learn how to open text files and read their contents using read(), readline(), and iteration methods.
Description_KO: 파이썬의 내장 함수 open()을 사용하여 텍스트 파일을 열고, 파일의 내용을 읽어오는 기본적인 방법들을 익힙니다. 파일 전체 읽기, 한 줄씩 읽기 등 상황에 맞는 읽기 기법을 배웁니다.

1. 
Guide_EN: Use the open() function with 'r' mode to open a file for reading.
Guide_KO: 'r' 모드를 사용하여 읽기 전용으로 파일을 열고, read()로 전체 내용을 가져옵니다.

print(content)
f.close()

2. 
Guide_EN: Use the close() method to release the file resource after reading.
Guide_KO: 파일을 다 읽은 후에는 반드시 close() 메서드를 호출하여 자원을 반환해야 함을 익힙니다.

19. 
Guide_EN: Read a file and find the length of the longest line.
Guide_KO: 파일의 모든 줄을 검사하여 가장 긴 줄의 글자 수(길이)를 찾아냅니다.
