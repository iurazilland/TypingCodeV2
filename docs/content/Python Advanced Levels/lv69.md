Title_EN: Raising Exceptions
Title_KO: 예외 발생시키기 (raise)
Description_EN: Learn how to manually trigger exceptions using the raise keyword and how to create custom exception classes to handle domain-specific errors.
Description_KO: raise 키워드를 사용하여 필요에 따라 의도적으로 예외를 발생시키는 방법을 배웁니다. 파이썬 내장 예외뿐만 아니라, 직접 정의한 사용자 정의 예외 클래스를 활용하여 프로그램의 논리적 오류를 더 명확하게 관리하는 기법을 익힙니다.

1. 
Guide_EN: Use the 'raise' keyword to manually trigger a built-in exception.
Guide_KO: raise 키워드를 사용하여 의도적으로 ValueError를 발생시키고 프로그램의 흐름을 중단해 봅니다.

8.
