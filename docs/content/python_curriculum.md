# 파이썬 타자 연습 커리큘럼 — Basic (8섹션 · 60레벨 완결)

이 문서는 **TypingCode V2 파이썬 베이직(`py-basic`)** 과정의 단일 마스터 로드맵(SSOT)입니다.  
입문자가 개념 점프 없이 한 걸음씩 체득할 수 있도록 **1레벨 = 1단일 개념 도입**, 각 섹션 마지막 레벨은 **종합 문제풀이**로 구성되어 있습니다.

---

## 💡 커리큘럼 표준 규격 ( 총 60레벨 · 756문항 )

1. **일반 학습 레벨 (52개 레벨 · 각 13문항)**
   - **1~10단계 (5쌍 교차 학습)**: 홀수 단계(`1, 3, 5, 7, 9`) **블록 코딩 개념 도입** ⇄ 짝수 단계(`2, 4, 6, 8, 10`) **빈칸 채우기 타이핑(`fill_blank`)**
   - **11단계 (`fix_bug`)**: 핵심 문법 오류·논리 버그 1곳을 스스로 찾아 고치기 (정답 직접 노출 금지)
   - **12단계 (`one_line`)**: 주어진 예제 아래에 **한 줄을 추가하여** 결과 완성하기
   - **13단계 (`predict_output`)**: 실행 결과를 머릿속으로 추적하는 4지선다 예측 퀴즈
2. **섹션 종합 문제풀이 레벨 (8개 레벨: `Lv 8, 15, 22, 30, 37, 46, 53, 60` · 각 10문항)**
   - `1~3단계`: 핵심 문법 빈칸 완성 (`fill_blank`)
   - `4~6단계`: 실전 버그 수정 (`fix_bug`)
   - `7~8단계`: 한 줄 코드 추가 작성 (`one_line`)
   - `9~10단계`: 복합 코드 출력 예측 4지선다 (`predict_output`)
3. **작성 및 UX 원칙**
   - 프롬프트(`prompt_ko`)는 **1~2문장 이내로 간결하고 명확하게** 작성하며, 부연 설명은 도움말(`hint_ko`)로 분리합니다.
   - 출력 문자열 검증 시 보이지 않는 공백 혼동을 피하고, `input()` 활용 문항은 2개 이상의 테스트케이스로 하드코딩을 방지합니다.

- **Lv 6**: 특수문자 이스케이프 (`\n`, `\t`, `\"`)
- **Lv 7**: `print()`의 `sep`과 `end` 옵션
